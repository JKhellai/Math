## 从「绝对值」到「距离」

[[an_valore_assoluto|绝对值]]那节,我们用 |x − y| 度量了实数轴上两点的远近,并摸清了它的全部性质。现在做一次关键的抽象。

回头看「逼近」这件事——一列数 x₀, x₁, x₂, … 越来越靠近某个值 a——它的本质是「**距离** |xₙ − a| 越来越小」。但仔细想:证明这类逼近时,我们真正用到的,是 |x − y| 的哪些性质?不是它「等于 x−y 或 y−x」这个具体定义,而是三条结构性的事实:

- 距离非负,且**仅当两点重合时为零**;
- 距离**对称**:x 到 y 与 y 到 x 一样远;
- **三角不等式**:从 x 直接到 y,不比绕道 z 更远。

只要一个「距离」满足这三条,逼近的全部理论就能在它上面展开——**不管被度量的对象是实数、复数、平面上的点、还是一个函数**。把这三条提炼成公理,就得到分析、拓扑、泛函分析共同的舞台:**度量空间**。

## 定义

**定义.** 设 X 是一个集合。函数 d : X × X → ℝ₊（ℝ₊ 表示非负实数）称为 X 上的一个**度量**(metric)，若满足:

- **(M1)** d(x, y) = 0 ⟺ x = y；
- **(M2)** d(x, y) = d(y, x)，对一切 x, y ∈ X（**对称性**）；
- **(M3)** d(x, y) ≤ d(x, z) + d(z, y)，对一切 x, y, z ∈ X（**三角不等式**）。

此时称序偶 (X, d) 为一个**度量空间**(metric space)；当度量从上下文清楚时,简记为 X。d(x, y) 称为点 x 与 y 之间的**距离**(distance)。

三条公理都是「距离」该有的自然性质。值得专门点出 (M3) 的读法:它正是「从 x 到 y 的直达路程,不超过先到 z 再到 y 的折线路程」——三角形两边之和不小于第三边。这条几何直觉,在[[an_valore_assoluto|绝对值]]那节已经以 |x+y| ≤ |x|+|y| 的形式见过;现在它升级成任意度量空间的公理。

（注意定义里**没有**要求 X 自带加法、乘法或序——度量空间的元素可以是任何东西,只要两两之间能赋一个满足三条的「距离」。这正是抽象的威力:它剥离了「数」的代数结构,只保留「远近」。）

## 例子

**(a) ℝ 的自然度量。** 取 X = ℝ，定义

d(x, y) := |x − y|。

三条公理逐一来自[[an_valore_assoluto|绝对值]]的性质:(M1) 即 |x−y| = 0 ⟺ x = y（绝对值性质 iv）；(M2) 即 |x−y| = |y−x|（绝对值性质 ii，|−t| = |t|）；(M3) 即 |x−y| ≤ |x−z| + |z−y|，把绝对值的三角不等式用在 (x−z) + (z−y) = x−y 上即得。这是我们最熟悉的度量空间,也是后面一切的原型。**今后谈到 ℝ,默认配这个自然度量。**

**(b) 离散度量。** 设 X 是任意非空集合,定义

d(x, y) := 1（若 x ≠ y）, d(x, x) := 0。

验证:(M1) 显然(按定义,距离为 0 当且仅当两点相同);(M2) 对称(x≠y 与 y≠x 同义);(M3) 三角不等式——左边 d(x,y) 至多是 1,右边 d(x,z) + d(z,y) 若 x≠y 则 z 不可能同时等于 x 和 y,故右边至少一项为 1,≥ 1 ≥ 左边;若 x=y 左边为 0,自然 ≤ 右边。这个度量把任何集合都变成度量空间——哪怕集合元素之间毫无「天然的远近」可言。它说明:**度量是附加在集合上的结构,不是集合自带的**;同一个集合可以配不同的度量。

**(c) 子空间度量。** 设 (X, d) 是度量空间,Y ⊆ X 非空。把 d 限制在 Y × Y 上,记 d_Y,它显然仍满足三条公理(公理对 Y 中的点照样成立)。于是 (Y, d_Y) 也是度量空间,称 X 的**度量子空间**(metric subspace)。例如闭区间 [0, 1] 配 ℝ 的自然度量,就是 ℝ 的一个度量子空间。这条让我们能把大空间的距离「继承」到任何子集上。

> **预告几个重要例子。** 将来会看到:平面 ℝ²、空间 ℝ³ 乃至 ℝⁿ,配欧氏距离 d(x,y) = √(Σ(xᵢ−yᵢ)²),是度量空间——这是几何直觉里「两点间直线距离」的严格版;复数 ℂ 配 d(z,w) = |z−w|（待 ℂ 构造后）也是;甚至「一段区间上的全体连续函数」配上某种「函数间的距离」,也构成度量空间——那是泛函分析的起点。**同一套极限理论,将一次性覆盖所有这些**,这正是抽象成度量空间的回报。

## 球与邻域

有了距离,就能谈「某点附近」。两个基本概念:

**定义(球).** 在度量空间 (X, d) 中,对 a ∈ X 与 r > 0：

- **开球**(open ball) B(a, r) := { x ∈ X : d(a, x) < r }（到 a 的距离**严格小于** r 的点）；
- **闭球**(closed ball) B̄(a, r) := { x ∈ X : d(a, x) ≤ r }（距离 ≤ r）。

在 ℝ 的自然度量下,开球 B(a, r) = { x : |x − a| < r } 正是开区间 (a − r, a + r)——回到[[an_valore_assoluto|绝对值]]那条 ε-带刻画。所以「球」是「区间」在一般度量空间里的推广;在 ℝ² 里它是真正的圆盘,在 ℝ³ 里是球体,名字由此而来。下图并列 ℝ 上的开球(区间)与 ℝ² 上的开球(圆盘):

虚线圆周表示「开」球——边界上的点(距离恰为 r)**不属于**球,正如开区间不含端点。图中 x 是球内一点,d(a, x) < r。

**定义(邻域).** 集合 U ⊆ X 称为点 a 的一个**邻域**(neighborhood)，若存在某个 r > 0 使 B(a, r) ⊆ U。a 的全体邻域记作 𝒰(a)。

直觉:U 是 a 的邻域,意思是「U 包含了 a 周围一整片小区域」——a 不在 U 的边缘,而是被 U 整个裹住。最基本的邻域就是球本身:对任意 ε > 0,B(a, ε) 是 a 的邻域(称 a 的 **ε-邻域**)。

邻域有两条以后常用的简单性质:**X 自己是任何点的邻域**(取任意 r 即可);**两个邻域的交仍是邻域**(若 B(a, r₁) ⊆ U₁、B(a, r₂) ⊆ U₂，取 r = min(r₁, r₂)，则 B(a, r) ⊆ U₁ ∩ U₂)。后一条以后定义极限、证明唯一性时会反复用到——它本质上是「同时满足两个『足够近』的要求,只需取更严的那个」。

## 度量的反向三角不等式

[[an_valore_assoluto|绝对值]]有反向三角不等式;一般度量也有对应版本,证明方式相同。

**命题.** 在度量空间 (X, d) 中,对一切 x, y, z：

d(x, y) ≥ | d(x, z) − d(z, y) |。

**证明.** 由三角不等式 (M3)，d(x, z) ≤ d(x, y) + d(y, z)，移项（并用对称性 d(y,z)=d(z,y)）得

d(x, z) − d(z, y) ≤ d(x, y)。

把 x 与 y 互换,同理得 d(y, z) − d(z, x) ≤ d(y, x) = d(x, y)，即 −( d(x,z) − d(z,y) ) ≤ d(x, y)。两个不等式合起来:d(x,y) 同时 ≥ ( d(x,z)−d(z,y) ) 与其相反数,即 ≥ 其绝对值。∎

它的用处与绝对值版一致:估计「两个距离之差」。在收敛理论里,证「若 xₙ → a 则 d(xₙ, b) → d(a, b)」这类连续性,一行就靠它。

## 一道激活练习

设 X = ℝ。判断下列函数是否为 ℝ 上的度量;是则验证三条公理,不是则指出违反了哪一条。

(a) d₁(x, y) := (x − y)²；
(b) d₂(x, y) := |x − y| 当 x ≠ y，d₂(x, x) := 0（提示：这其实是哪个例子？）；
(c) d₃(x, y) := | √|x| − √|y| |。（注意它在某些不同点上可能为零。）

（提示:重点查 (M1) 的「⟸ 与 ⟹ 双向」和 (M3)。(a) 试 x=0, y=2, z=1，算算三角不等式两边。(c) 找两个不同的 x、y 使 d₃(x,y)=0。）

## 参考解答

(建议先自己写完再看。)

**(a) 不是度量**，违反 (M3)。取 x = 0, z = 1, y = 2：左边 d₁(0,2) = (0−2)² = 4；右边 d₁(0,1) + d₁(1,2) = 1 + 1 = 2。4 ≤ 2 不成立，三角不等式破。（(M1)(M2) 其实满足，但一条不过即出局。这也说明「把距离平方」会破坏度量结构——根号在欧氏距离里不是可有可无的。）

**(b) 是度量**——它就是 ℝ 的**自然度量** |x−y|，只是分了段写：x ≠ y 时取 |x−y|，x = y 时取 0，而 |x−y| 在 x = y 时本来就等于 0。两种情形拼起来，d₂(x,y) = |x−y| 对一切 x, y 成立。所以 d₂ 与自然度量是**同一个函数**，三条公理同例子 (a)。（这一问的用意：换一种分段写法并不改变函数本身——别被「看起来像新定义」骗到。）

**(c) 不是度量**，违反 (M1) 的「⟹」方向。取 x = 1, y = −1：d₃(1,−1) = | √|1| − √|−1| | = |1 − 1| = 0，但 1 ≠ −1。距离为零却非同一点，(M1) 破。（根源：√|·| 把 x 与 −x 映到同一个值，抹掉了符号信息，于是「距离」分不开这两个点。(M2)(M3) 其实都满足，但 (M1) 不过即出局。）

回顾：判定度量，最易出问题的是 (M1) 的「距离为零 ⟹ 两点相同」（要求度量能**分开**任何两个不同的点）和 (M3)（三角不等式，常因「平方」「开根」之类的非线性变形而破）。这三条公理看着温和，但每一条都在拦截一类「看似距离、实则不够格」的函数——这与当初 [[num_n|Peano 公理]] 每条拦截一个赝品数系，是同一种「公理由反例划界」的思路。

## 往前看一步

舞台搭好了:度量空间给了「距离」一个统一的抽象,球与邻域给了「附近」一个精确的说法。现在可以正式定义这一切的目标——**收敛**。一列点 x₀, x₁, x₂, … 收敛到 a，直观上是「越往后,点越靠近 a」；用邻域的语言,这将被精确表述为「a 的**每一个**邻域,都包含**几乎所有**的项（即除有限个外的全部）」。这个定义一旦立起，「极限」就从模糊的直觉变成可以证明的对象，而它在 ℝ、在 ℝⁿ、在任何度量空间里都一字不变。这就是 [[an_convergenza|数列的收敛]] 的内容——我们终于抵达极限理论的正门。
