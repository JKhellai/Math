## 通往 ℝ 的第二条路

[[num_dedekind|Dedekind 分割]]那节提过,造 ℝ 有两条经典路线:分割,以及「Cauchy 列的完备化」。我们走了分割那条;[[an_cauchy|Cauchy 列]]那节又把第二条的思路说了个大概——把 ℚ 的所有 Cauchy 列收集起来,按「差为零列」归类,商出的就是 ℝ。这一节把第二条路**完整走一遍**。

它不引入任何新的实数(ℝ 已经由 Dedekind 造好了),价值在别处:**它把前面学过的好几样工具——[[fond_equivalenza|等价类]]、[[alg_anelli|理想与商环]]、[[an_cauchy|Cauchy 列]]、[[num_dedekind|完备性]]——在一个构造里汇到一起**,是对整条数系-分析主线的一次漂亮回顾。而且它揭示一件深刻的事:Dedekind 的「分割」与 Cantor 的「Cauchy 列」造出的,是**同一个** ℝ。

(本节属于可选的完整性补充;原书也标注「首次阅读可略」。它不影响后续推进。)

## 核心想法：用「逼近它的有理数列」代表一个实数

回到 [[an_cauchy|Cauchy 列]] 那节的关键反例:逼近 √2 的有理数列(如牛顿迭代 x₀=2, x_{n+1}=½(xₙ+2/xₙ))在 ℚ 中是 Cauchy 列,却在 ℚ 中**不收敛**——它要靠近的 √2 是 ℚ 的一个洞。

Cantor 的想法是把这件事**反过来当定义**:既然这个 Cauchy 列「指向」√2,那就**用这个 Cauchy 列本身去代表 √2**。每个实数(包括有理数和无理数),就是「一列逼近它的有理数」。

但同一个实数有许多列逼近它——牛顿迭代和「1.4, 1.41, 1.414, …」都指向 √2:

所以要像造 [[num_z|ℤ]]、[[num_q|ℚ]] 那样,**把「指向同一个数」的 Cauchy 列粘成一类**——而「指向同一个数」的判据是:**两列之差是零列**(差 → 0)。等价类机器又一次登场,只是这次的「材料」是 Cauchy 列。

## 构造：Cauchy 列的环,模掉零列的理想

把上面的想法落成代数。设 𝓡 是 ℚ 中**全体 Cauchy 列**构成的集合,c₀ 是 ℚ 中**全体零列**(收敛到 0 的列)构成的集合。

**第一步:𝓡 是环,c₀ 是它的理想。** Cauchy 列逐项相加、相乘仍是 Cauchy 列(用[[an_cauchy|Cauchy⟹有界]]控制乘积:|rₙsₙ − rₘsₘ| ≤ |rₙ||sₙ−sₘ| + |rₙ−rₘ||sₘ|,两个因子都被界住),所以 𝓡 在逐项运算下是一个[[alg_anelli|交换环]](含幺元——常数列 1)。而零列对加法封闭、且「零列 × Cauchy 列 = 零列」([[an_algebra_limiti|零×有界=零]]),所以 c₀ 是 𝓡 的一个[[alg_anelli|理想]]。

**第二步:商掉理想。** 既然 c₀ 是理想,就能作[[alg_anelli|商环]]

ℝ := 𝓡 / c₀。

它的元素是等价类 [r] = r + c₀,其中两个 Cauchy 列 r、s 同类 ⟺ r − s ∈ c₀ ⟺ **r − s 是零列** ⟺ 两列之差 → 0。这正是「指向同一个数的 Cauchy 列归为一类」的严格版。商环的加法、乘法自动从 𝓡 继承(理想的存在保证了运算[[alg_anelli|良定义]])——这是当初学[[alg_anelli|理想与商环]]时埋下、如今兑现的用途。

**第三步:ℚ 嵌入。** 每个有理数 a 对应**常数列** (a, a, a, …),它是 Cauchy 列;映射 a ↦ [(a,a,…)] 把 ℚ 单射地、保运算地放进 ℝ([[num_z|嵌入]]的又一次)。于是 ℚ 成为 ℝ 的子环。无理数则对应那些**不**与任何常数列同类的 Cauchy 列——比如逼近 √2 的那一类,它在 ℚ 里没有「目标」,在 ℝ 里却是一个堂堂正正的元素 [√2]。

## 序、域、完备

要让 ℝ 成为完备**有序域**,还需配上序并验证性质。这里给出框架,细节是标准的(原书逐条做过):

**序:** 称 Cauchy 列 r「严格正」,若从某项起 rₙ ≥ 1/N 对某固定 N > 0 成立(即它最终离 0 有正的距离、且在正侧)。用「严格正类」定义 [r] ≤ [s] :⟺ s − r 严格正或为零类。可验证这是与运算相容的[[num_q_ordine|全序]],且在 ℚ 上还原成 ℚ 本来的序。

**域:** 关键是非零类可逆。若 [r] ≠ 0,即 r 不是零列,则 r 最终离 0 有正距离,可以「逐项取倒数」(把开头有限项补成任意值),得到的 (1/rₙ) 仍是 Cauchy 列,其类就是 [r]⁻¹。于是 ℝ 是[[alg_campi|域]]。

**完备:** 可证 ℝ 满足[[num_estremo_superiore|上确界公理]]——每个非空有上界的子集有上确界。证明用「逐次二分逼近」构造一个 Cauchy 列,其类即为上确界(思路与 [[an_bolzano_weierstrass|Bolzano–Weierstrass]] 的二分法同源)。

## 殊途同归：它就是 ℝ

三步加序、域、完备,得到:**𝓡/c₀ 是一个完备的有序域,且包含 ℚ。** 但[[num_dedekind|Dedekind 分割]]造的也是「包含 ℚ 的完备有序域」。两个会不会不一样?

不会——因为这样的东西**本质上唯一**:

> **完备有序域的唯一性.** 任何两个完备有序域都[[fond_iniettive_suriettive|同构]](存在保运算、保序的双射)。

(这条唯一性定理我们承认——它的证明要点是:有序域里 ℚ 总能嵌入,完备性把 ℚ 的嵌入「连续地延拓」到整个域,而稠密性保证延拓唯一。属于略深的内容,这里引用结论。)

于是 **Cantor 的 𝓡/c₀ 与 Dedekind 的分割域,作为完备有序域必定同构——它们是同一个 ℝ。** 两条看起来毫不相干的路——「数轴的一刀切」与「逼近的有理数列」——造出了同一个对象。这不是巧合,而是「完备有序域」这个概念**只有一个模型**的体现:无论你怎么填 ℚ 的洞,填出来的都是 ℝ。

回头看这件事的圆满:[[num_radice2|√2 不是有理数]]揭示 ℚ 有洞;[[num_estremo_superiore|上确界]]把洞表述成「无上确界」;[[num_dedekind|Dedekind]]用分割填洞;[[an_cauchy|Cauchy]]用「内部收拢」重新刻画完备;而本节用 Cauchy 列再造一次 ℝ,并证明它与分割版是同一个。**ℝ 的存在与唯一,从两个方向被彻底坐实了。**

## 一道激活练习

(a) 验证「零列 × Cauchy 列 = 零列」,从而 c₀ 在乘法下吸收 𝓡（这是 c₀ 为理想的核心）。(提示:Cauchy 列有界,设 |sₙ| ≤ B;零列 rₙ → 0;估计 |rₙsₙ|。)

(b) 说明为什么常数列 (a, a, …) 与 (b, b, …)（a, b ∈ ℚ）同类 ⟺ a = b。（这保证 ℚ 真的单射地嵌入,不同有理数不会被粘成一类。)

(c) 逼近 √2 的牛顿迭代列 (xₙ) 与常数列 (1, 1, 1, …) 是否同类?为什么?（提示:看它们的差是否为零列。）

## 参考解答

(建议先自己写完再看。)

**(a)** 设 (sₙ) 是 Cauchy 列,由[[an_cauchy|Cauchy⟹有界]]存在 B > 0 使 |sₙ| ≤ B 对一切 n。设 (rₙ) 是零列,rₙ → 0。则 |rₙsₙ| = |rₙ|·|sₙ| ≤ B·|rₙ|。给定 ε > 0,因 rₙ → 0 取 N 使 n ≥ N 时 |rₙ| < ε/B,则 |rₙsₙ| < B·(ε/B) = ε。故 (rₙsₙ) 是零列。∎（这正是[[an_algebra_limiti|零×有界=零]]在 ℚ 上的应用。）

**(b)** 两常数列同类 ⟺ 其差 (a−b, a−b, …) 是零列。但这是个**常数**列:它收敛到 0 当且仅当这个常数本身就是 0,即 a − b = 0,即 a = b。（常数列的极限就是那个常数——零列只有常数 0 这一种常数列。）故 a = b 时同类、a ≠ b 时不同类,嵌入是单射。∎

**(c)** **不同类。** 它们的差是 (xₙ − 1)。牛顿迭代 xₙ → √2(在 ℝ 中),故 xₙ − 1 → √2 − 1 ≈ 0.414 ≠ 0。差不是零列(它收敛到一个非零的数),所以两列不同类。直观上:牛顿列指向 √2,常数列 1 指向 1,√2 ≠ 1,自然不是同一类。∎

回顾:判断两个 Cauchy 列是否同类,永远归结为**看它们的差是不是零列**(差 → 0)。这和[[num_z|ℤ]]、[[num_q|ℚ]] 构造里「判断两个有序对是否同类」一脉相承——只是那里的判据是一个代数等式,这里的判据是一个极限(差 → 0)。等价类机器的形式始终如一,变的只是「材料」和「相同的判据」。
