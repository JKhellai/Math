## 用「一刀切」定义实数

上一节把 ℝ 的使命锁定成一句话:造一个**完备**的有序域——每个非空有上界的子集都有上确界。现在动手。

Dedekind 的想法朴素得惊人。看 ℚ 的数轴:在任意一点把它切成左右两半。如果切口落在某个有理点上(比如在 3/2 处下刀),左半是「所有小于 3/2 的有理数」;但如果切口落在 √2「本该在」的位置——那里没有 ℚ 的点——左半就是「所有平方小于 2 的正有理数,连同全体非正有理数」,而**这一刀并不切到任何有理数身上**。关键的观察是:**无论切口处有没有有理数,左半这个集合本身总是完全确定的**。于是把因果倒过来:不再说「先有实数、再切出左半」,而是**直接用左半这个 ℚ 的子集去定义那个实数**。每一个可能的「左半」就是一个实数;有理点处的切口给出有理数,无理点处的切口给出新的数。所有这些子集收集起来,就是 ℝ。

剩下的全部工作,是把「左半」这个直觉用纯粹的集合语言刻画清楚,然后验证如此定义的对象确实构成一个完备有序域。

## 分割的定义

什么样的 ℚ 子集配当「数轴左半」?它该满足三条:不空也不满、向左封闭、右端不含最大者。

**定义.** ℚ 的一个子集 α 称为一个**分割**(Dedekind cut),若:

- **(C1)** α ≠ ∅ 且 α ≠ ℚ(非平凡:左半既非空、也没吞掉整条轴);
- **(C2) 向下封闭**:若 p ∈ α 且 q < p,则 q ∈ α(左半里一个点的左边全在左半里);
- **(C3) 无最大元**:α 中不存在最大的有理数(切口处是「开」的——左半一路逼近切口但不含它)。

记 **ℝ** 为全体分割之集。ℝ 的元素就是分割;一个「实数」从此就是一个满足 (C1)–(C3) 的有理数集合。

(C3) 是个约定性的选择:切口处既可以把它归左、也可以归右,我们统一归右,于是左半"无最大元"。这避免了"3/2 处的切口"产生两个不同表示的麻烦,让每个实数对应唯一的分割。

**有理数的分割.** 对每个 r ∈ ℚ,令

r* := { p ∈ ℚ : p < r }。

验它是分割:非空(r−1 ∈ r*)、非满(r ∉ r*,因 r < r 假)——(C1) 成立;若 p < r 且 q < p,则 q < r,(C2) 成立;无最大元——任取 p ∈ r*,即 p < r,由稠密性存在 p′ 满足 p < p′ < r,故 p′ ∈ r* 且 p′ > p,(C3) 成立。这样的分割称**有理分割**。映射 r ↦ r* 就是 ℚ 到 ℝ 的嵌入(下节验证它保序、保运算)。

**一个不是有理分割的分割.** 这正是关键:令

γ := { p ∈ ℚ : p ≤ 0 } ∪ { p ∈ ℚ : p > 0 且 p² < 2 }。

它就是上一节那个集合 A 添上全体非正有理数。验证它是分割:非空(0 ∈ γ)非满(2 ∉ γ,因 2² = 4 > 2);向下封闭(若 q < p ∈ γ:p ≤ 0 时 q < 0 ∈ γ;p > 0 且 p² < 2 时,若 q ≤ 0 则 q ∈ γ,若 q > 0 则 q < p 给 q² < p² < 2);无最大元——这恰是上一节关键引理 (i)「平方小于 2 的正有理数总能再变大一点而不出界」,它保证 γ 的正数部分没有最大者,而非正部分显然更小。所以 γ 是分割。**但它不是任何有理分割**:若 γ = r*,则 r 恰好把"平方小于 2"和"平方大于 2"分开,这样的 r 满足 r² = 2(下面会精确说明),而上一节证过这样的有理数不存在。γ 就是即将名为 √2 的那个新实数——它在 ℚ 中找不到对应的点,却是一个完全合法的分割。

## 序:就是集合的包含

现在给 ℝ 装上序。Dedekind 构造最漂亮的地方在于:序不需要新定义,**包含关系 ⊆ 直接就是它**。直觉显然——左半越大,切口越靠右,数就越大。

**定义.** 对分割 α, β,规定 α ≤ β :⟺ α ⊆ β。

**定理.** ≤ 是 ℝ 上的全序。

**证明.** 自反、传递就是 ⊆ 的自反、传递(集合论里的现成事实)。反对称:α ⊆ β 且 β ⊆ α 给 α = β(外延原则),正是反对称。**全序性**是唯一需要动脑的一条:任两个分割必有一个包含另一个。设 α ⊄ β,则存在 p ∈ α 而 p ∉ β。往证 β ⊆ α:任取 q ∈ β,因 p ∉ β 而 β 向下封闭,**不可能** q ≥ p(否则 p ≤ q ∈ β 迫使 p ∈ β),故 q < p;而 p ∈ α、α 向下封闭,得 q ∈ α。所以 β ⊆ α,即 β ≤ α。∎

包含即序,这个选择的回报马上揭晓:它让完备性公理几乎不证自明。

## 高潮:完备性公理成立

上一节我们要求 ℝ 满足「每个非空有上界的子集都有上确界」。在 Dedekind 的框架里,这条公理的证明短得惊人——因为上确界就是**并集**。

**定理(完备性 / 上确界公理).** 设 𝒜 ⊆ ℝ 非空,且有上界。则 𝒜 有上确界,且

sup 𝒜 = ⋃_{α ∈ 𝒜} α

(所有这些分割作为集合的并)。

**证明.** 记 s := ⋃_{α∈𝒜} α。分三步:s 是分割、s 是上界、s 是最小上界。

**s 是分割.** 设 β 是 𝒜 的上界(分割),即每个 α ∈ 𝒜 满足 α ⊆ β。
*(C1)* 非空:𝒜 非空,取一个 α₀ ∈ 𝒜,它非空,故 s ⊇ α₀ 非空。非满:每个 α ⊆ β,故 s ⊆ β ≠ ℚ,于是 s ≠ ℚ。
*(C2)* 向下封闭:设 q < p ∈ s。p ∈ s 意味着 p 属于某个 α ∈ 𝒜;α 向下封闭,故 q ∈ α ⊆ s。
*(C3)* 无最大元:设 p ∈ s,则 p ∈ 某个 α;α 无最大元,存在 p′ ∈ α, p′ > p,而 p′ ∈ α ⊆ s。故 s 无最大元。
三条齐备,s ∈ ℝ。

**s 是上界.** 对每个 α ∈ 𝒜,显然 α ⊆ ⋃ = s,即 α ≤ s。

**s 是最小上界.** 设 β 是任一上界,即 ∀α ∈ 𝒜, α ⊆ β。则它们的并也含于 β:s = ⋃ α ⊆ β,即 s ≤ β。

故 s = sup 𝒜。∎

停下来体会这件事的分量。在上一节,「ℚ 没有上确界」是一条需要费力反证的定理;而在 ℝ 里,「上确界存在」竟然只是「一族向下封闭集合的并仍然向下封闭」——几乎是集合论的自动事实。**这就是 Dedekind 构造的全部意图**:把「序」设计成包含、把实数设计成左半集合,正是为了让完备性变成并集的平凡性质。ℝ 之所以无洞,是因为我们用「能并起来的东西」来定义它的每一个点。

## 加法

ℝ 已是完备的全序集;要成为完备有序**域**,还得装上加法与乘法,并验证有序域公理。先看加法——它同样落在集合层面。

**定义.** α + β := { p + q : p ∈ α, q ∈ β }。

**它是分割.** *(C1)* 非空(各取一元相加);非满:取 p₀ ∉ α、q₀ ∉ β,则对任何 p∈α,q∈β 有 p < p₀、q < q₀(因 α,β 向下封闭,集合外的数大于集合内一切),故 p+q < p₀+q₀,即 p₀+q₀ ∉ α+β。*(C2)* 设 r < p + q(p∈α,q∈β)。则 r − q < p,故 r − q ∈ α(向下封闭),而 r = (r−q) + q ∈ α + β。*(C3)* 任取 p+q ∈ α+β,α 无最大元给 p′ > p, p′∈α,则 p′+q > p+q 仍在 α+β。∎

**(ℝ, +) 是交换群.** 加法的交换、结合直接继承自 ℚ 的对应定律(逐元素验证)。**零元是 0\***（有理分割 0* = {p∈ℚ : p<0}，即全体负有理数）：验 α + 0* = α 需两个包含方向，是本节加法最需要小心的一处验证，留给读者按定义展开（提示用 (C3)：α 中任一元素都不是最大的，故可写成"α 中更大元 + 负数"）。**逆元** −α 的构造也有一个需要当心的小手术（不能简单取 {−p : p∉α}，要避开切口那一点）：

−α := { p ∈ ℚ : 存在 r > 0 使 −p − r ∉ α }。

（直觉：−α 的左半，是「把 α 的右半取相反数、再往左缩一点」，那个"缩一点"正是为了满足无最大元。）验证它是分割、且 α + (−α) = 0*，是一道扎实的练习,路数与上面相同,此处不再逐字展开。

**序与加法相容 (O1)**:α ≤ β ⟹ α + γ ≤ β + γ。证明:α ⊆ β 时,{p+r : p∈α, r∈γ} ⊆ {q+r : q∈β, r∈γ},即 α+γ ⊆ β+γ。一行可了——包含即序,相容性几乎是自动的。

## 乘法:同样的思路,多一道符号关卡

乘法本应同法:α · β := { p·q : p∈α, q∈β }。但这里有个 ℚ 上没遇到的障碍:若 α、β 含有大量负数(它们向下封闭,一定含全体足够小的负数),两个很小的负数相乘得到很大的正数,{p·q} 会向右炸开,根本不是分割。

解决办法是**先对正数定义,再用符号规则补全**——这正是有序域结构派上用场之处。先定义「正分割」:α > 0* 即 0* ⊊ α(α 严格大于零)。对两个正分割,定义

α · β := 0* 的元素,连同 { p·q : p∈α, q∈β, p>0, q>0 }

(只取正的部分相乘,再把负有理数全部补进左半)。验证它是正分割,与加法同法。然后对一般的 α、β,借符号定理把乘法**定义**出来:利用每个非零实数恰是某个正分割或其相反数(三歧性,由全序得到),令

α·β := 视 α、β 的符号,等于 ±(|α|·|β|),

其中 |α| 取 α 与 −α 中的非负者,符号按「负负得正」的规则确定——与 [[alg_anelli|环]] 那节的符号定理完全一致。这套定义虽然分情形,但每一支都化归到「两个正分割相乘」,而那个是干净的。

逐条验证乘法结合律、交换律、分配律、幺元 1*、非零元的逆,以及相容性 (O2),都是同一种「在集合层面展开、化归到 ℚ 的对应定律」的工作,篇幅可观但无新意。**结论**(我们承认这部分的例行验证):

> **(ℝ, +, ·, ≤) 是一个完备有序域。**

这就是上一节锁定的目标。需要强调的是:完备性——那个真正区分 ℝ 与 ℚ 的性质——的证明是干净利落的(并集那一段);繁琐的只是域公理的例行核验,而它们没有概念上的难点,Amann–Escher 也只在习题中布置。

## √2 落位

回到本节开头那个分割 γ。它现在是 ℝ 的一个堂堂正正的元素;我们证明它的平方恰是 2*——也就是有理数 2 对应的实数。

**命题.** γ · γ = 2*(在上面的乘法意义下)。

**证明思路.** γ 是正分割(0 ∈ γ 且含正数),按正分割的乘法,γ·γ 的正数部分是 { p·q : p,q∈γ, p,q>0 } 向下封闭化。

「⊆ 2*」:任取这样的 p, q,均正且 p² < 2、q² < 2。要证 pq < 2……这一步需要 p, q 中较大者的平方控制,细节用上一节的引理可补全;核心是 γ 里的正数平方都 < 2,其两两乘积可被 2 控制。

「⊇ 2*」:任取 t < 2,要找 p ∈ γ 正且 p² > t(从而 t 落入 γ·γ)。若 t ≤ 0 显然(取任意正 p∈γ);若 0 < t < 2,由上一节关键引理 (i) 反复逼近,γ 中存在正有理数 p 使 p² 任意接近 2、从而超过 t。

两个方向合起来,γ·γ = 2*。∎(完整细节是 §I.10 的标准习题,这里给出骨架。)

于是:**γ 是一个实数,满足 γ² = 2。** 记号 √2 至此获得严格定义——它就是分割 γ,数轴上「平方小于 2 的左半」所标定的那个切口。从九节之前在单射满射一节第一次提到「√b 的存在留待完备性」,到上一节把缺口表述成「无上确界」,再到此刻 γ 落位——这条线终于闭合。ℚ 数轴上那个看不见的空,被一个明确构造出的集合填上了。

## 一道激活练习

设 𝒜 ⊆ ℝ 是一族分割,且有上界 β(即每个 α ∈ 𝒜 满足 α ⊆ β)。直接证明:**并集 s := ⋃_{α∈𝒜} α 满足 (C2) 向下封闭与 (C3) 无最大元。**(这是完备性定理证明的核心两步,请独立把它写严格——不要回看正文,自己推一遍。)

(提示:两条都用「p ∈ 并集 ⟺ p 属于某个成员分割」这一事实,把问题转回单个分割已有的性质。)

## 参考解答

(建议先自己写完再看。)

**(C2) 向下封闭.** 设 q < p 且 p ∈ s。由并集定义,存在某个 α ∈ 𝒜 使 p ∈ α。α 是分割,满足 (C2),故由 q < p 得 q ∈ α。而 α ⊆ s,所以 q ∈ s。∎

**(C3) 无最大元.** 设 p ∈ s,往证 s 中有比 p 更大的元素。由并集定义,p ∈ 某个 α ∈ 𝒜。α 满足 (C3),故存在 p′ ∈ α 使 p′ > p。又 α ⊆ s,故 p′ ∈ s。于是 p 不是 s 的最大元;p 任意,s 无最大元。∎

回顾:两条的证明是同一个套路——并集里的任何成员资格,都来自某个具体分割,于是该分割已有的性质（向下封闭、无最大元）自动传给并集。这正是为什么"分割之并仍是分割",也正是为什么把序定义成包含、能让完备性变得如此轻巧。(非空、非满两条需要用到"有上界 β"这个前提——非满由 s ⊆ β ≠ ℚ 得到——本练习聚焦的 (C2)(C3) 则连前提都不需要,纯靠单个分割的性质。)

## 数系构造完成

从五条 Peano 公理出发,我们一步步走到了这里:ℕ(归纳)→ ℤ(等价类,补出负数与减法)→ ℚ(等价类,补出除法)→ ℝ(Dedekind 分割,补出完备性)。每一级都用纯粹的集合语言、从前一级的材料中构造出来,每一条运算律、每一个性质都有明确的证明,没有任何"显然"或"约定俗成"。那条曾经布满缺口的数轴,如今是一个完备的有序域——连续、无洞、四则齐备、大小分明。

这条数轴,正是**分析学**的舞台。有了完备性,极限才能存在、连续函数才有介值性质、导数与积分才谈得上。数系构造在此交棒:下一支是 [[an_analisi|分析]] 主干——它将站在这条刚刚建成的实数轴上,重新定义"无限逼近"这件事,把高中那些关于极限、连续、微积分的模糊直觉,逐一锻造成严格的定理。我们造好了地面;接下来在上面盖楼。
