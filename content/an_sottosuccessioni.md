## 从一列里挑一串

[[an_convergenza|上一节]]说 (−1)ⁿ「显然发散」,却把严格证明欠了下来。这一节补上——而补它的工具,本身就是分析里极重要的一个概念:**子列**。

直觉很简单:从一个数列里,按原顺序挑出无穷多项,组成一个新数列。比如从 (x₀, x₁, x₂, x₃, …) 里只挑偶数项,得到 (x₀, x₂, x₄, …)。挑的时候有一条铁规矩——**下标必须严格递增**,既不能回头也不能停留。

**定义(子列).** 设 (xₙ) 是数列,ψ : ℕ → ℕ 是一个**严格递增**函数（k < l ⟹ ψ(k) < ψ(l)）。则复合 (x_{ψ(k)})_{k∈ℕ} 称 (xₙ) 的一个**子列**(subsequence)。记 n_k := ψ(k),子列写作 (x_{n_k})_{k∈ℕ}，其中 n₀ < n₁ < n₂ < ⋯。

「严格递增」这条有一个一用再用的小推论:**n_k ≥ k 对一切 k 成立**（从 n₀ ≥ 0 出发,每步至少加 1,归纳即得）。意思是「子列的第 k 项,在原数列里的位置不早于 k」——挑选只会让下标走得更快,不会更慢。

## 收敛数列的子列：都去同一个地方

子列的第一条、也是最有用的一条定理:

**定理.** 若 (xₙ) 收敛到 a，则它的**每一个**子列都收敛到 a。

**证明.** 设 (x_{n_k}) 是子列,U 是 a 的任意邻域。因 xₙ → a,存在 N 使 n ≥ N 时 xₙ ∈ U。而 n_k ≥ k,所以只要 k ≥ N,就有 n_k ≥ k ≥ N,于是 x_{n_k} ∈ U。即除前 N 个外,子列的项全在 U 里。故 x_{n_k} → a。∎

一句话:**整列去哪,每串挑出来的子列就去哪。** 这听着平淡,却是一件锋利的武器——因为它的**逆否**给了判断发散的利器:**如果能从一个数列里挑出两个子列、收敛到不同的值,那么原数列必定发散**(否则两个子列都该收敛到同一个极限)。

## (−1)ⁿ 发散：一击即中

现在还上一节的债。

**命题.** 实数列 ((−1)ⁿ) 发散。

**证明.** 看它的两个子列。偶数项子列 ((−1)^{2k})_k = (1, 1, 1, …) 是常数列,收敛到 **1**;奇数项子列 ((−1)^{2k+1})_k = (−1, −1, −1, …) 也是常数列,收敛到 **−1**。

两个子列收敛到不同的极限 1 ≠ −1。若原数列收敛,由上面的定理两个子列都该收敛到同一极限——矛盾。故 ((−1)ⁿ) 发散。∎

对比上一节那个含糊的「显然不收敛」,这里是一行干净的逻辑。**「找两个去向不同的子列」是证明发散的标准手法**,以后遇到振荡型数列都用它。

## 聚点：无穷多项靠近的地方

收敛要求「几乎所有项」靠近一个值;放松一档,只要求「无穷多项」靠近,就得到一个更宽松的概念。

**定义(聚点).** 点 a 称数列 (xₙ) 的一个**聚点**(cluster point)，若 a 的**每一个**邻域都包含 (xₙ) 的**无穷多**项。

把它和收敛并排看,差别只在一个词:

- **收敛到 a**:每个邻域含**几乎所有**项(至多有限个例外);
- **a 是聚点**:每个邻域含**无穷多**项(但允许无穷多项在外面)。

收敛强,聚点弱:极限必是聚点(几乎所有 ⟹ 无穷多),反之不然。最能说明差别的就是 ((−1)ⁿ):它不收敛(没有极限),却有**两个**聚点 +1 和 −1——任何一个的小邻域里都有无穷多项。一个发散的数列可以有多个聚点,而收敛数列([[an_convergenza|上一节]]证过)只有唯一聚点,就是它的极限。

## 聚点 = 某个收敛子列的极限

聚点和子列之间有一座漂亮的桥——它把「无穷多项靠近」翻译成「挑得出一串真正收敛过去的子列」。

**定理.** a 是 (xₙ) 的聚点 当且仅当 (xₙ) 有一个子列收敛到 a。

**证明.** （⟸）设子列 x_{n_k} → a。任取 a 的邻域 U,则除有限个 k 外 x_{n_k} ∈ U——这已经是无穷多项落在 U 里。故 a 是聚点。

（⟹）设 a 是聚点。要**造**一个收敛到 a 的子列,用[[num_ricorsione|递归]]逐个挑选,每次把精度收紧一档:

令 n₀ := 0。已选定 n_{k−1} 后,令

n_k := min{ m ∈ ℕ : m > n_{k−1} 且 x_m ∈ B(a, 1/k) }。

这个 min 存在吗?要点正是「聚点」:B(a, 1/k) 是 a 的邻域,含**无穷多**项,所以「下标 > n_{k−1} 且落进 B(a,1/k)」的项必然还有(无穷多项里只排除了有限个前置下标),这样的 m 组成 ℕ 的非空子集,由[[num_radici_n|良序原理]]有最小元。于是 n_k 有定义,且 n_k > n_{k−1}（下标严格递增,确是子列）。

收敛性:对一切 k ≥ 1,x_{n_k} ∈ B(a, 1/k),即 d(x_{n_k}, a) < 1/k。给定 ε > 0,由[[num_archimede|阿基米德性质]]取 K 使 1/K < ε,则 k ≥ K 时 d(x_{n_k}, a) < 1/k ≤ 1/K < ε。故 x_{n_k} → a。∎

这条定理的份量在于它的**构造**:聚点不只是「附近有无穷多项」的静态描述,它保证你能**主动挑出**一条收敛的路径走过去。「每次把邻域半径收到 1/k、在剩下的无穷多项里挑下一个」——这个递归挑选的手法,以后证 Bolzano–Weierstrass 定理(有界数列必有收敛子列)时还会用到,是分析里"从聚集提取收敛"的标准动作。

> 顺带澄清一个易错点:「有唯一聚点」**不**等于「收敛」。数列 (½, 2, ⅓, 3, ¼, 4, …) ——奇数位置趋于 0、偶数位置趋于无穷——只有一个聚点 0(任何 0 的邻域含无穷多个 1/n),却发散(偶数位的项跑向无穷,不可能几乎所有项都靠近 0)。收敛 = 有唯一聚点 **且** 数列有界,缺一不可。

## 一道激活练习

(a) 写出数列 (xₙ)，xₙ := (−1)ⁿ + 1/n 的所有聚点,并各指出一个收敛到它的子列。

(b) 证明数列 xₙ := sin(nπ/2)（即 0, 1, 0, −1, 0, 1, 0, −1, …）发散,并列出它的全部聚点。

(c) 证明:若 (xₙ) 收敛到 a，而 (y_k) 是 (xₙ) 的任意子列,则 (xₙ) 与 (y_k) 有**完全相同**的聚点集（都是 {a}）。（这说明对收敛数列,取子列不改变聚点——但对发散数列,子列可能丢掉聚点。）

## 参考解答

(建议先自己写完再看。)

**(a)** xₙ = (−1)ⁿ + 1/n。偶子列 x_{2k} = 1 + 1/(2k) → 1;奇子列 x_{2k+1} = −1 + 1/(2k+1) → −1。所以聚点是 **1 和 −1**:偶下标子列收敛到 1,奇下标子列收敛到 −1。（没有别的聚点:任何远离 ±1 的点,其小邻域只含有限项。）

**(b)** 数列循环为 0, 1, 0, −1, 0, 1, 0, −1, …(周期 4)。下标 n = 4k+1 的子列恒为 1 → 1;下标 n = 4k+3 的子列恒为 −1 → −1。两个子列收敛到不同值,故原数列**发散**。全部聚点:**0, 1, −1**——下标 ≡ 0,2 (mod 4) 的项恒为 0(子列 → 0),≡1 的恒为 1,≡3 的恒为 −1;这三个值的邻域各含无穷多项,而其余任何点的小邻域只含有限项(实际为零项)。

**(c)** 因 (xₙ) 收敛到 a,由[[an_convergenza|唯一聚点定理]]它的聚点集是 {a}。而 (y_k) 作为 (xₙ) 的子列,由本节定理也收敛到 a(收敛数列的子列同极限),所以 (y_k) 也收敛,其聚点集同样是 {a}。两者聚点集都是 {a},相同。∎（注:对发散数列这会失败——如从 ((−1)ⁿ) 取偶子列,聚点集从 {−1,+1} 缩成 {+1},子列丢掉了一个聚点。）

回顾:求聚点的通用套路是**按下标的周期或奇偶把数列拆成几个子列,看每个子列各自趋于什么**——每个收敛子列的极限是一个聚点,反过来每个聚点也来自某个收敛子列(本节的桥)。振荡数列的聚点,基本都靠这种「拆子列」找出来。

## 往前看一步

子列与聚点补全了收敛理论的「定性」一面：极限唯一、发散可判、聚集可提取。但我们验证收敛仍然只能逐个回到 ε–N 定义,手动找 N——太笨重。下一节转入「定量」的便利:**极限的运算法则**。若 xₙ → a、yₙ → b,则它们的和、差、积、商的极限,就是 a、b 的和、差、积、商。有了这套法则,复杂数列的极限可以像代数式一样**逐步拆解计算**,不必每次回到定义。而证明这些法则,用的正是[[an_valore_assoluto|绝对值]]那节反复练习的「拆项 + 三角不等式 + 控制因子」——那些静态的估计技巧,即将在动态的极限里全部派上用场。这就是 [[an_algebra_limiti|极限的运算法则]] 的内容。
