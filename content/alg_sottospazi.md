## 空间里的空间

[[alg_spazio_vettoriale|向量空间]]往往很大——全体函数、全体多项式、整个 ℝ³。研究它时,常关心其中**自身也构成向量空间**的子集。比如 ℝ³ 里**过原点的一条直线**或**过原点的一个平面**:在上面取两个向量相加、或乘个标量,结果仍落在这条线/这个平面里——它们各自是一个小一号的向量空间,嵌在 ℝ³ 中。这种「空间里的空间」称**子空间**。

**定义(子空间).** 设 V 是 𝕂 上的向量空间。V 的子集 U 称 V 的一个**子空间**(subspace)，若 U 在 V 的同一套加法、数乘下,自身也构成 𝕂 上的向量空间(且共用同一个零向量)。

## 判定只需三条

直接按定义验证一个子集是子空间,要核对全部[[alg_spazio_vettoriale|八条公理]],很繁。好在大部分公理是「免费」的——它们在大空间 V 里已经成立,自动遗传给子集。真正需要查的,只有**封闭性**和**含零**:

**定理(子空间判据).** V 的子集 U 是子空间,**当且仅当**满足三条:

- **(S1)** 0 ∈ U（含零向量）;
- **(S2)** 对加法封闭:u, w ∈ U ⟹ u + w ∈ U;
- **(S3)** 对数乘封闭:a ∈ 𝕂,u ∈ U ⟹ a·u ∈ U。

**证明.** （⟹）若 U 是子空间,它自身是向量空间,自然含零、且加法数乘不越出 U——三条必然成立。

（⟸）设三条成立,验 U 是向量空间。(S2)(S3) 保证加法、数乘确实是 U 上的运算(结果不跑出 U);(S1) 给了零向量。**加法逆**:任取 u ∈ U,由[[alg_spazio_vettoriale|(−1)·v = −v]],−u = (−1)·u,而 (S3) 说标量 (−1) 乘 u 仍在 U,故 −u ∈ U——逆元自动在 U 里。至于交换、结合、分配、幺元等剩余公理,它们是关于「等式」的,在大空间 V 里对**所有**向量成立,自然对 U 中的向量也成立,无需重验。故 U 是向量空间,即子空间。∎

证明的关键洞察:**绝大多数公理是「普遍等式」,大空间成立则子集白白继承;只有「封闭」和「存在性」(零、逆)需要单独保证——而逆又能由数乘封闭 + (−1)·v=−v 推出**。所以三条足矣。注意 (S1) 还可换成「U 非空」(非空则取 u∈U,由 (S3) 乘标量 0 得 0∈U)——但实践中验「0∈U」通常最快,且能顺手排除空集。

> 一个常用的小判据:三条可以合并成**一条**——U 非空,且对**任意 a,b ∈ 𝕂 与 u,w ∈ U,有 a·u + b·w ∈ U**(对「线性组合」封闭)。取 a=b=1 得加法封闭,取 b=0 得数乘封闭,取 u=w、a=b=0 配非空得含零。这个「线性组合封闭」是子空间的精髓,以后会反复用。

## 例子与反例

**(a) 平凡子空间.** {0}（只含零向量）与 V 自身,都是 V 的子空间(三条显然)。这是两个边界情形。

**(b) 过原点的直线 / 平面.** 在 ℝ³ 中,{ t·v : t ∈ ℝ }（一条过原点的直线,v 是方向向量）是子空间:两个倍数相加 t₁v + t₂v = (t₁+t₂)v 仍是倍数,标量乘亦然,含 0(t=0)。过原点的平面同理。**「过原点」是关键**——

不过原点的直线**不是**子空间:它不含 0（违反 (S1)）;而且两个向量相加会「跑偏」离开这条线。任何子空间**必须过原点**——这是 (S1) 的几何意义,一眼可判。

**(c) 次数有界的多项式.** 𝕂[X]_{≤n}（次数 ≤ n 的多项式）是 𝕂[X] 的子空间:两个次数 ≤ n 的多项式相加、数乘,次数仍 ≤ n,封闭。(对照[[alg_spazio_vettoriale|上一节练习]]:次数**恰为** n 的多项式**不**封闭、不是子空间——「≤」保持封闭,「恰等于」破坏封闭,这个区别在这里再次出现。)

**(d) 齐次线性方程的解集.** 形如 { (x₁,…,xₙ) ∈ 𝕂ⁿ : a₁x₁ + ⋯ + aₙxₙ = 0 } 的解集是 𝕂ⁿ 的子空间(两个解相加仍满足方程,因右边是 0;数乘亦然;零解显然)。**关键是右边为 0(齐次)**——若右边是非零常数 b,解集不含零、不是子空间(这与「过原点」是同一回事)。这个例子是线性代数与线性方程组的连接点,以后会反复出现。

## 子空间的和

两个子空间能「拼」成更大的子空间。

**定义(和).** 设 U, W 是 V 的子空间。它们的**和**(sum)定义为

U + W := { u + w : u ∈ U, w ∈ W }，

即「一个 U 中向量加一个 W 中向量」的全体。

**命题.** U + W 也是 V 的子空间,而且是**包含 U 和 W 的最小子空间**。

**证明(子空间).** 含零:0 = 0 + 0;加法封闭:(u₁+w₁) + (u₂+w₂) = (u₁+u₂) + (w₁+w₂),前括号 ∈ U、后 ∈ W(各自封闭);数乘封闭:a(u+w) = au + aw,au ∈ U、aw ∈ W。三条齐备。**最小性**:任何同时包含 U 和 W 的子空间,必须(由加法封闭)包含所有 u + w,即包含 U + W;故 U + W 是最小的。∎

直觉:U + W 是「由 U 和 W 一起张出来」的空间。例如 ℝ³ 中两条过原点的不同直线,它们的和是这两条线张成的过原点平面。

## 直和：拼接无重叠

和有一种特别干净的情形——**拼接时没有「重叠」,每个向量的分解方式唯一**。

**定义(直和).** 和 U + W 称为**直和**(direct sum)，记 U ⊕ W，若 U + W 中**每个**向量写成 u + w（u∈U, w∈W）的方式**唯一**。

**判据.** U + W 是直和 ⟺ **U ∩ W = {0}**（两个子空间只交于零向量）。

**证明.** （⟸）设 U ∩ W = {0}。若某向量有两种分解 u₁ + w₁ = u₂ + w₂,移项 u₁ − u₂ = w₂ − w₁。左边 ∈ U、右边 ∈ W,故这个公共向量 ∈ U ∩ W = {0},于是 u₁ − u₂ = 0、w₂ − w₁ = 0,即 u₁ = u₂、w₁ = w₂——分解唯一。

（⟹）设和是直和。任取 x ∈ U ∩ W。则 0 = x + (−x),其中 x ∈ U、−x ∈ W(因 x∈W 而 W 是子空间);但 0 = 0 + 0 也是一种分解。由唯一性,x = 0。故 U ∩ W = {0}。∎

直觉:U ⊕ W 意味着 U 和 W「方向上完全无关」,除了不得不共享的零向量。最熟悉的例子:ℝ² = (x 轴) ⊕ (y 轴)——每个向量 (a, b) = (a, 0) + (0, b) 唯一分解成「横分量 + 纵分量」,而两轴只交于原点。直和分解是线性代数后续(投影、特征空间分解)的核心工具。

> 注意「U ∩ W = {0}」这个判据**只对两个子空间的直和成立**;三个以上子空间的直和需要更强的条件(两两交于零**不**够),那是后话。这里先掌握两个的情形。

## 一道激活练习

(a) 判断 ℝ³ 的下列子集是否为子空间,是则验证三条,不是则指出违反哪条:
   ① { (x, y, z) : x + y + z = 0 }；
   ② { (x, y, z) : x + y + z = 1 }；
   ③ { (x, y, z) : x = y = z }；
   ④ { (x, y, z) : xy = 0 }（即 x、y 至少一个为 0）。

(b) 设 U = { (x, 0) : x ∈ ℝ }（x 轴）、W = { (0, y) : y ∈ ℝ }（y 轴）是 ℝ² 的子空间。证明 ℝ² = U ⊕ W。

## 参考解答

(建议先自己写完再看。)

**(a)**
① **是子空间**(齐次方程解集):0+0+0=0 含零;两个解 (x,y,z)、(x',y',z') 之和的分量和 = (x+x')+(y+y')+(z+z') = 0+0 = 0,封闭;数乘同理。三条齐备。

② **不是**:违反 (S1)。(0,0,0) 代入得 0 ≠ 1,零向量不在集合里。(非齐次方程,右边非零。)

③ **是子空间**:{(t,t,t):t∈ℝ},含零(t=0);(t,t,t)+(s,s,s)=(t+s,t+s,t+s) 仍是该形式;a(t,t,t)=(at,at,at) 亦然。(这其实是过原点的一条直线,方向 (1,1,1)。)

④ **不是**:违反 (S2) 加法封闭。(1,0,0) 满足 xy=0(在集合里),(0,1,0) 也满足(在集合里),但它们的和 (1,1,0) 有 xy=1≠0,**不在**集合里。(几何上这是「两条坐标轴的并」,并集一般不是子空间。)

**(b)** 验两件事。**和是整个 ℝ²**:任取 (a,b) ∈ ℝ²,写 (a,b) = (a,0) + (0,b),其中 (a,0) ∈ U、(0,b) ∈ W。故 ℝ² = U + W。**是直和**:U ∩ W 中的向量既形如 (x,0) 又形如 (0,y),要同时成立需 x=0 且 y=0,即只有 (0,0);故 U ∩ W = {0},和为直和。综上 ℝ² = U ⊕ W。∎

回顾:(a) 集中体现「子空间 ⟺ 齐次/过原点」——①③是(齐次约束、过原点),②不是(非齐次,不含零),④不是(「乘积为零」不是线性约束,破坏加法封闭)。判子空间的快速直觉:**线性的齐次约束(形如「某些线性组合 = 0」)给出子空间;非齐次(=非零)或非线性(含乘积、平方)的约束通常不给**。(b) 是直和的最简范例,两步——「和填满」+「交为零」。

## 往前看一步

子空间告诉我们 V 内部有哪些「小空间」,以及如何用和/直和拼接它们。但还有个更基本的问题没回答:**一个向量空间(或子空间)到底有「多大」?** ℝ² 和 ℝ³ 都是无穷集合(有无穷多个向量),但直觉上 ℝ³「比」ℝ² 大一维——这个「维数」该如何精确定义?答案要从「用少数几个向量,通过加法和数乘,能生成出多少向量」入手:**张成**(span)与**线性无关**(linear independence)。一组向量能否张成整个空间、它们之间是否「冗余」,将引出**基**与**维数**——刻画向量空间大小的终极工具。这就是 [[alg_span_indipendenza|张成与线性无关]] 的内容。
