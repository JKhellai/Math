## 极限与序的关系

[[an_algebra_limiti|运算法则]]让我们能算和、差、积、商的极限,但它们对**实数列**漏掉了一件事:序。两个数列若处处有 xₙ ≤ yₙ,它们的极限之间也有这个关系吗?反过来更有用——若一个数列被两个收敛到同一处的数列夹住,它是不是也被迫收敛到那里?

这两个问题只对**实数列**有意义(ℂ 没有序,问"复数谁大谁小"无意义),所以本节专属实数列,依赖 ℝ 的[[num_q_ordine|全序]]。而第二个问题的答案——**夹逼定理**——是实分析里求极限最锋利的工具,尤其当数列复杂到运算法则拆不开时。

## 极限保持「≤」

**命题(序的保持).** 设 (xₙ)、(yₙ) 是收敛实数列,且 xₙ ≤ yₙ 对**无穷多** n 成立。则

lim xₙ ≤ lim yₙ。

**证明.** 记 a := lim xₙ,b := lim yₙ,反设 a > b。则 ε := a − b > 0。因 xₙ → a,几乎所有项满足 xₙ > a − ε/4;因 yₙ → b,几乎所有项满足 yₙ < b + ε/4。这两个"几乎所有"合起来仍是几乎所有,而题设 xₙ ≤ yₙ 对无穷多 n 成立——无穷多与几乎所有必有公共下标 n,在该处

a − ε/4 < xₙ ≤ yₙ < b + ε/4，

即 a − ε/4 < b + ε/4,移项 a − b < ε/2,即 ε < ε/2,矛盾。故 a ≤ b。∎

直觉:数列的极限继承了数列的「不大于」关系——如果 (xₙ) 总在 (yₙ) 下方(哪怕只是无穷多次),它们逼近的目标也满足同样的高下。

## 但严格「<」不被保持

一个**重要的陷阱**:把上面的 ≤ 换成严格的 <,结论**不成立**。即使 xₙ < yₙ 对一切 n 成立,也只能得到 lim xₙ ≤ lim yₙ,**不能**保证严格小于。

反例:取 xₙ := −1/n,yₙ := 1/n。则对一切 n ∈ ℕˣ 有 xₙ < yₙ(负数 < 正数),但两者都收敛到 0:

两条数列始终严格分开(一条全正、一条全负),却在极限处**并拢到同一个点** 0。教训:**取极限会把严格不等式「软化」成 ≤**——逼近的过程中,原本的间隙可以缩到零。以后用到「xₙ < yₙ 推出极限严格小于」时,务必警惕:这一步是错的。

## 夹逼定理

现在是主角。它的形状像三明治:中间的数列被上下两片夹住,而两片若收敛到同一处,中间的也别无选择。

**定理(夹逼 squeeze theorem).** 设 (xₙ)、(yₙ)、(zₙ) 是实数列,满足

xₙ ≤ yₙ ≤ zₙ  对几乎所有 n，

且 lim xₙ = lim zₙ = a。则 (yₙ) 也收敛,且 lim yₙ = a。

**证明.** 设 m₀ 使 n ≥ m₀ 时 xₙ ≤ yₙ ≤ zₙ。给定 ε > 0。因 xₙ → a,存在 m₁ 使 n ≥ m₁ 时 xₙ > a − ε；因 zₙ → a,存在 m₂ 使 n ≥ m₂ 时 zₙ < a + ε。取 N := max(m₀, m₁, m₂)。则对一切 n ≥ N:

a − ε < xₙ ≤ yₙ ≤ zₙ < a + ε，

即 a − ε < yₙ < a + ε,也就是 yₙ ∈ B(a, ε)。故几乎所有 yₙ 落在 a 的 ε-邻域里,yₙ → a。∎

证明的关键一步是那条**串起来的不等式** a − ε < xₙ ≤ yₙ ≤ zₙ < a + ε:左端被下片顶住、右端被上片压住,中间的 yₙ 被锁死在 (a−ε, a+ε) 里。两片合拢到 a,缝隙归零,yₙ 无处可逃。

夹逼的威力在于:**它不要求你算出 yₙ 本身的任何信息**,只要找到两个会算的、且收敛到同一处的「夹板」。当 yₙ 复杂到无法用运算法则拆解时,这往往是唯一的出路。

## 夹逼怎么用：两个例子

**例 1.** 求 lim (sin n)/n。

直接算无从下手——sin n 在 ℝ 上不规则地振荡,既不收敛也没有简单公式。但它有界:−1 ≤ sin n ≤ 1。于是

−1/n ≤ (sin n)/n ≤ 1/n。

下片 −1/n → 0,上片 1/n → 0(都由 1/n → 0 与数乘),两片同极限 0。由夹逼,lim (sin n)/n = 0。∎ 注意我们**从未**分析 sin n 的行为,只用了「它被 ±1 框住」——夹逼把那个棘手的振荡完全绕过去了。

**例 2.** 求 lim ⁿ√n（即 n^(1/n)）。

这个极限不显然(底数 n 在涨、指数 1/n 在缩,两股力气方向相反)。答案是 1,可以用夹逼证。对 n ≥ 1 显然 ⁿ√n ≥ 1。另一边需要一个上界:写 ⁿ√n = 1 + hₙ(其中 hₙ ≥ 0),则 n = (1 + hₙ)ⁿ。由[[alg_binomio|二项式定理]],当 n ≥ 2,

n = (1 + hₙ)ⁿ ≥ C(n,2)·hₙ² = [n(n−1)/2]·hₙ²，

(只保留二项展开里第 k=2 项,其余非负项全丢掉)。于是 hₙ² ≤ 2/(n−1),即 0 ≤ hₙ ≤ √(2/(n−1))。从而

1 ≤ ⁿ√n = 1 + hₙ ≤ 1 + √(2/(n−1))。

上片 1 + √(2/(n−1)) → 1(因 2/(n−1) → 0,根号连续——这点以后严格化,现在直观接受),下片恒 1。由夹逼,lim ⁿ√n = 1。∎ 这个例子展示了夹逼的典型配合:**先用二项式定理造出一个能算的上界,再夹**——和当初[[num_radici_n|n 次根]]、[[alg_binomio|Bernoulli 不等式]]里"展开后丢掉同号项作界"是同一种手法。

## 一道激活练习

用夹逼定理求下列极限(先找夹板,再说明两片同极限):

(a) lim (cos(n²))/(n+1)；
(b) lim ( 1/(n²+1) + 1/(n²+2) + ⋯ + 1/(n²+n) )（提示:n 个正项求和;每项都介于最小项与最大项之间,放大成 n·(最大项)、缩小成 n·(最小项)）；
(c) lim ⁿ√(2ⁿ + 3ⁿ)（提示:夹在 ⁿ√(3ⁿ) 与 ⁿ√(2·3ⁿ) 之间）。

## 参考解答

(建议先自己写完再看。)

**(a)** cos 有界:−1 ≤ cos(n²) ≤ 1。故 −1/(n+1) ≤ cos(n²)/(n+1) ≤ 1/(n+1)。两片 ±1/(n+1) 都 → 0（由 1/(n+1) → 0,见[[an_convergenza|收敛]]例与运算法则）。夹逼给 **lim = 0**。

**(b)** 记和为 Sₙ,它有 n 个加项,每项形如 1/(n²+k),1 ≤ k ≤ n。最大项是 k=1 时的 1/(n²+1),最小项是 k=n 时的 1/(n²+n)。于是

n · 1/(n²+n) ≤ Sₙ ≤ n · 1/(n²+1)，

即 n/(n²+n) ≤ Sₙ ≤ n/(n²+1)。下片 n/(n²+n) = 1/(n+1) → 0;上片 n/(n²+1) → 0（分子分母同除 n²:(1/n)/(1+1/n²) → 0/1 = 0,运算法则）。两片同极限 0,夹逼给 **lim Sₙ = 0**。

**(c)** 因 3ⁿ ≤ 2ⁿ + 3ⁿ ≤ 3ⁿ + 3ⁿ = 2·3ⁿ,开 n 次方(根保序,[[num_radici_n|n 次根]]递增):

ⁿ√(3ⁿ) ≤ ⁿ√(2ⁿ+3ⁿ) ≤ ⁿ√(2·3ⁿ)。

左片 ⁿ√(3ⁿ) = 3。右片 ⁿ√(2·3ⁿ) = ⁿ√2 · 3 → 1·3 = 3（因 ⁿ√2 → 1,这是 ⁿ√n → 1 同型的基本极限,可同法证或直接引用）。两片同极限 3,夹逼给 **lim = 3**。

回顾:夹逼的通用策略是**把不会算的量,放大和缩小成两个会算的、且收敛到同一处的式子**。常见的"造夹板"手法有三种,本题各见一种:用有界因子的界(a：cos∈[−1,1])、用求和项的最大最小(b：n 项夹在 n×max 与 n×min 之间)、用主导项的提取(c：3ⁿ 是 2ⁿ+3ⁿ 的主导)。认出"谁主导、谁有界、怎么放缩",是用好夹逼的关键。

## 往前看一步

到这里,求极限的两大工具都备齐了:[[an_algebra_limiti|运算法则]](拆解能算的)与夹逼(围堵不能算的)。但有一类极其重要的数列,这两样工具都难直接对付——**单调数列**:一个一直增(或一直减)、但不知道增向何方的数列,比如 (1 + 1/n)ⁿ。它显然在"往上爬",可极限是多少、甚至到底收不收敛,运算法则拆不开、也找不到现成的夹板。回答它需要回到 ℝ 最根本的性质——**完备性**:一个单调递增且有上界的数列,必定收敛(收敛到它的上确界)。这是完备性在极限理论里的第一次正面登场,也是通向 e、通向无穷级数的门。这就是 [[an_monotone|单调收敛定理]] 的内容。
