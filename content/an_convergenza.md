## 终于到极限

地基铺了这么久,现在抵达分析的核心问题:一列数 x₀, x₁, x₂, … 「趋于」某个值 a,到底是什么意思?

中学里的说法是「n 越大,xₙ 越接近 a」——但这句话经不起推敲:「接近」到什么程度?「越来越」是多快?数学需要一个不含糊的定义,而[[an_spazio_metrico|度量空间]]那节已经备好了全部材料:距离、球、邻域。这一节把「趋于」一次说死,然后立起极限理论的三块基石——定义、唯一性、有界性。

定义将在任意度量空间里给出,所以它对 ℝ、对 [[alg_complessi|ℂ]]、对将来的 ℝⁿ 一字通用。

## 数列

**定义.** 集合 X 中的一个**数列**(sequence)，就是一个函数 ϕ : ℕ → X。把 ϕ(n) 记作 xₙ（称第 n **项**），整个数列记作 (xₙ) 或 (x₀, x₁, x₂, …)。

数列不过是「以自然数为定义域的函数」——又一次,新概念建在[[fond_funzioni|函数]]这块老地基上。X = ℝ 时称**实数列**,X = ℂ 时称**复数列**。

> 一个容易混淆的区分:数列 (xₙ) 与它的**值域** {xₙ : n ∈ ℕ} 不是一回事。常数列 (a, a, a, …) 有无穷多项,但值域只是单元素集 {a}。数列记着「顺序与重复」,值域把这些信息抹掉了。

## 收敛的定义

直觉是「项最终都挤进 a 附近的任意小范围」。用邻域把「任意小范围」和「最终」都说精确:

**定义(收敛).** 数列 (xₙ) **收敛**(converges)到 **a**，若 a 的**每一个**邻域都包含 (xₙ) 的**几乎所有**项——即除有限个外的全部项。此时 a 称 (xₙ) 的**极限**(limit)，记

lim_{n→∞} xₙ = a   或   xₙ → a (n → ∞)。

不收敛的数列称**发散**(divergent)。

「几乎所有」(almost all)是这里的关键术语,意思是「至多有限个例外」。把定义里的邻域换成最基本的 ε-球,得到日常使用的形式:

**命题(ε–N 刻画).** lim xₙ = a 当且仅当:**对每个 ε > 0，存在 N ∈ ℕ，使得对一切 n ≥ N 都有 d(xₙ, a) < ε。**

**证明.** 这只是把定义换种说法。(⟸)给定 a 的邻域 U,存在 r > 0 使 B(a, r) ⊆ U;取 ε = r,由条件存在 N 使 n ≥ N 时 d(xₙ,a) < r,即 xₙ ∈ B(a,r) ⊆ U——除前 N 个外全部落入 U。(⟹)给定 ε > 0,B(a, ε) 是 a 的邻域,由收敛定义除有限个外的项都在其中,取 N 为这些例外下标的最大值加一即可。∎

这就是分析的招牌句式——「**任给 ε，存在 N，使 n ≥ N 时距离 < ε**」。读法:ε 是对手开出的「精度挑战」（要多接近）,N 是你的回应（从第几项起能保证）。ε 越小,N 通常越大,但只要对**每个** ε 都答得出 N,数列就收敛。下图把这个过程画出来:

## 几个例子

**(a) lim (1/n) = 0。** 这是最基本的收敛,它就是[[num_archimede|阿基米德性质]]的推论穿上了极限的外衣。

**证明.** 给定 ε > 0。由[[num_archimede|阿基米德推论]],存在 N ∈ ℕˣ 使 1/N < ε。则对一切 n ≥ N,有 1/n ≤ 1/N < ε,即 |1/n − 0| < ε。∎

看清这里发生了什么:当初在 `num_archimede` 里,「1/N 可以任意小」是一条静态定理;现在它直接兑现成「1/n → 0」。**ε–N 定义里那个 N,正是阿基米德性质替我们找到的。** 这是「先建静态工具、再穿上极限外衣」的第一个范例。

**(b) 常数列 (a, a, a, …) 收敛到 a。** 对任意 ε > 0,每一项都满足 d(a, a) = 0 < ε,取 N = 0 即可。极限就是那个常数。

**(c) 实数列 ((−1)ⁿ) 发散。** 它在 +1 与 −1 之间反复跳,不向任何单一的值靠拢:

直觉上它「显然不收敛」,但要**证明**发散,得有判据。最利落的方式是借用下面就要证的唯一性:假如它收敛到某个 a,那么它的项最终都该挤进 a 的小邻域;可它有无穷多项等于 +1、又有无穷多项等于 −1,这两拨不可能同时挤进一个半径 < 1 的邻域。矛盾。（严格论证留到[[an_sottosuccessioni|子列]]那节,用「不同子列收敛到不同值」一击即中——那正是为这种数列量身打造的工具。）

## 极限唯一

定义说「收敛到 a」,可会不会一个数列同时收敛到两个不同的值?直觉上不可能——但这需要证明,而证明本身很能说明问题。

**定理(极限唯一).** 若 xₙ → a 且 xₙ → b,则 a = b。

**证明.** 反设 a ≠ b。由 (M1),它们的距离 d(a, b) > 0。取

ε := d(a, b) / 2 > 0。

关键是这个 ε 选得让 a、b 两个球**互不相交**:B(a, ε) 与 B(b, ε) 没有公共点（若 x 同属两球,则 d(a,b) ≤ d(a,x) + d(x,b) < ε + ε = d(a,b)，矛盾——三角不等式不容许）。

现在两边夹击。因 xₙ → a,从某个 N₁ 起所有项落进 B(a, ε)；因 xₙ → b,从某个 N₂ 起所有项落进 B(b, ε)。取 N = max(N₁, N₂),则第 N 项 x_N **同时**在两个球里——可两球不相交,不可能有公共点。矛盾。故 a = b。∎

这个证明的核心思想叫「**分离**」:两个不同的点,总能用两个不相交的小球分开（这条性质叫 Hausdorff 性，度量空间天然具备）。一旦分开,数列的项不可能最终同时挤进两边,所以极限至多一个。「极限唯一」这件看似显然的事,本质是「不同点可被邻域分离」。

## 收敛蕴含有界

最后一块基石。先说「有界」在度量空间里的意思:

**定义.** X 的子集 Y 称**有界**(bounded)，若存在 M > 0 使 d(x, y) ≤ M 对一切 x, y ∈ Y 成立（任意两点距离有统一上界）。数列 (xₙ) 称有界,若其值域 {xₙ : n ∈ ℕ} 有界。

（在 ℝ 或 ℂ 中,这等价于存在 M 使 |xₙ| ≤ M 对一切 n——所有项被同一个 M 框住。）

**定理.** 收敛数列必有界。

**证明.** 设 xₙ → a。取 ε = 1:存在 N 使 n ≥ N 时 d(xₙ, a) < 1。于是对 m, n ≥ N,由三角不等式

d(xₙ, xₘ) ≤ d(xₙ, a) + d(a, xₘ) < 1 + 1 = 2，

即「尾部」的项两两距离 < 2。而开头的有限项 x₀, …, x_{N−1} 只有有限个,它们之间(以及与尾部)的距离有一个最大值 M₀。取 M := M₀ + 2,则全体项两两距离 ≤ M。故数列有界。∎

直觉:收敛数列的尾巴挤在极限附近的一个小球里(自然有界),前面只有有限项（有限个点总是有界的）,两段合起来仍有界。**「有限 + 有界 = 有界」**,这个朴素的拼接以后会反复出现。

注意这个蕴含**不可逆**:有界**不**保证收敛——((−1)ⁿ) 就有界(全在 [−1,1] 里)却发散。有界是收敛的必要条件,不是充分条件。「补上什么才够充分」是后面单调收敛、Cauchy 收敛要回答的问题。

## 一道激活练习

(a) 用 ε–N 定义证明 lim (n / (n+1)) = 1。（提示:算 |n/(n+1) − 1| = 1/(n+1)，再用阿基米德性质找 N。）

(b) 用 ε–N 定义证明 lim ( (2n+1)/n ) = 2。

(c) 证明:若 xₙ → a，则 |xₙ| → |a|（实数列;提示用[[an_valore_assoluto|反向三角不等式]]）。反过来对吗？即 |xₙ| → |a| 是否一定有 xₙ → a？举例说明。

## 参考解答

(建议先自己写完再看。)

**(a)** 给定 ε > 0。计算距离:

| n/(n+1) − 1 | = | (n − (n+1))/(n+1) | = 1/(n+1)。

由[[num_archimede|阿基米德性质]]取 N 使 1/N < ε。则对一切 n ≥ N,1/(n+1) < 1/n ≤ 1/N < ε,即 |n/(n+1) − 1| < ε。故极限为 1。∎

**(b)** 给定 ε > 0。距离:| (2n+1)/n − 2 | = | (2n+1 − 2n)/n | = 1/n。取 N 使 1/N < ε,则 n ≥ N 时 1/n ≤ 1/N < ε。故极限为 2。∎

**(c)** 由[[an_valore_assoluto|反向三角不等式]],| |xₙ| − |a| | ≤ |xₙ − a|。给定 ε > 0,因 xₙ → a,存在 N 使 n ≥ N 时 |xₙ − a| < ε;则同样 n ≥ N 时 | |xₙ| − |a| | ≤ |xₙ − a| < ε。故 |xₙ| → |a|。

**反过来不对。** 取 xₙ = (−1)ⁿ:则 |xₙ| = 1 → 1,收敛;但 xₙ = (−1)ⁿ 本身发散(它在 ±1 间跳)。所以 |xₙ| 收敛不能推出 xₙ 收敛——绝对值抹掉了符号,把发散的振荡「拉平」成了收敛的常数。∎

回顾:(a)(b) 的套路完全一样——**先把 |xₙ − 极限| 化简成一个明显趋于 0 的式子（通常是 c/n 形状）,再用阿基米德性质兑出 N**。这是从定义证收敛的标准三步:算距离、化简、找 N。几乎所有「直接按定义」的收敛证明都是这个模子。

## 往前看一步

三块基石就位:收敛有了精确定义(ε–N),极限唯一,收敛必有界。但目前我们只会**逐个**验证收敛——每次都要回到定义、手动找 N。这太笨重了。下一步要建**运算法则**:若 xₙ → a、yₙ → b,那么 xₙ + yₙ → a + b、xₙ·yₙ → a·b、xₙ/yₙ → a/b(b≠0)。有了这些,复杂数列的极限就能像搭积木一样,由简单数列的极限拼出来,不必每次回到 ε–N。而它们的证明,用的正是[[an_valore_assoluto|绝对值]]那节练熟的「拆项 + 三角不等式」估计。这就是 [[an_algebra_limiti|极限的运算法则]] 的内容。
