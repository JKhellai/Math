## 有界数列里总能挑出收敛的一串

[[an_convergenza|收敛蕴含有界]]告诉我们「收敛 ⟹ 有界」,反过来不成立——((−1)ⁿ) 有界却发散。但「有界」也不是一无所获:虽然整个数列可能不收敛,**从里面总挑得出一个收敛的子列**。这就是 Bolzano–Weierstrass 定理,实分析里一条核心的存在性定理。

它的用处马上会显现:下一节判定 Cauchy 列收敛,靠的正是它。而它本身,又是 ℝ 完备性的一个面孔——在不完备的 ℚ 里,有界数列可能挑不出在 ℚ 中收敛的子列(那串逼近 √2 的有理数,任何子列都收敛到 √2 ∉ ℚ)。

**定理(Bolzano–Weierstrass).** ℝ 中每个有界数列都有收敛子列。等价地([[an_sottosuccessioni|聚点 ⟺ 收敛子列]]),每个有界实数列都有**聚点**。

## 二分法：把聚点套出来

证明的思路很几何:有界数列被关在一个闭区间里,无穷多项挤在有限长度内,必然在某处「堆积」。怎么找到堆积点?**反复把区间对半切,每次保留装着无穷多项的那一半**——区间越切越短,套向一个点,那个点就是聚点。

**证明.** 设 (xₙ) 有界,即存在区间 [a, b] 使所有 xₙ ∈ [a, b]。

**构造区间套。** 记 I₀ := [a, b]。它含有数列的**全部**项,当然是无穷多项。已得到含无穷多项的闭区间 I_k = [a_k, b_k] 后,取中点 m := (a_k + b_k)/2,把它切成左右两半 [a_k, m] 与 [m, b_k]。这两半至少有一半含无穷多项(否则两半各只有有限项,合起来 I_k 只有有限项,矛盾)。**选含无穷多项的那一半**作 I_{k+1}(若两半都含无穷多项,随便选左边)。

这样得到一串**嵌套**的闭区间 I₀ ⊇ I₁ ⊇ I₂ ⊇ ⋯,每个含无穷多项,且长度 b_k − a_k = (b−a)/2ᵏ → 0。

**套出聚点。** 左端点列 (a_k) 递增有上界(被 b 界住),右端点列 (b_k) 递减有下界。由[[an_monotone|单调收敛定理]],a_k → ξ(其上确界),b_k → ξ′;而 b_k − a_k → 0,由[[an_algebra_limiti|差的极限]] ξ′ − ξ = 0,即 a_k 与 b_k 收敛到**同一个点** ξ。这个 ξ 落在每个 I_k 里。

**ξ 是聚点。** 任取 ξ 的邻域 B(ξ, ε)。因区间长度 (b−a)/2ᵏ → 0、且 ξ ∈ I_k,只要 k 足够大,整个 I_k ⊆ B(ξ, ε)。而 I_k 含无穷多项——所以 B(ξ, ε) 也含无穷多项。故 ξ 是 (xₙ) 的聚点。

由[[an_sottosuccessioni|聚点 ⟺ 收敛子列]],存在子列收敛到 ξ。∎

证明的引擎是**单调收敛定理**(套出 ξ)和**聚点的递归挑选**(从聚点得到子列)——两者都已在前面备好,这里只是把它们组装起来。而最核心的「每次保留无穷多项的一半」用的是一个朴素却关键的事实:**有限 + 有限 = 有限**,所以无穷多项对半分,必有一半仍是无穷多。

## 推广一句

定理对 ℝᵐ 和 ℂ 同样成立:**Kᵐ 中每个有界数列都有收敛子列**。证明对维数归纳——先在第一个坐标上用一维的 B–W 挑出收敛子列,再在这个子列上对第二个坐标用 B–W 挑子列的子列,逐个坐标收紧,最后所有坐标同时收敛([[an_succ_complesse|按坐标收敛]])。ℂ 视作 ℝ² 即归入此列。细节是标准的归纳,这里点到为止——眼下我们只需要一维的版本。

## 为什么它叫「完备性的面孔」

把 Bolzano–Weierstrass 和[[an_monotone|单调收敛]]并排:两者都是「有界 + 某种附加条件 ⟹ 收敛」,且都靠完备性。单调收敛要求数列**单调**;B–W 不要求单调,代价是只保证**子列**收敛(而非整列)。它们其实是完备性的两种等价表述——在 ℚ 里两者都失败(逼近 √2 的递增有理数列,既不在 ℚ 收敛,也挑不出在 ℚ 收敛的子列)。可以证明:对有序域,「单调有界必收敛」「有界必有收敛子列」「上确界存在」「Cauchy 列必收敛」彼此等价,都是「完备」的不同说法。我们以上确界为出发公理,其余都作为定理导出;下一节的 Cauchy 判据是这组等价里最后、也最实用的一个。

## 一道激活练习

(a) 数列 xₙ := (−1)ⁿ·(1 + 1/n) 有界。找出它的全部聚点,并对每个聚点指出一个收敛到它的子列。(这印证 B–W:有界数列确实有收敛子列——而且这里有不止一个。)

(b) 说明为什么「**无界**数列也可能有收敛子列」并不与 B–W 矛盾,举一个无界但有收敛子列的数列。(B–W 说有界 ⟹ 有收敛子列,它没说无界 ⟹ 没有。)

(c) 构造一个数列,它的聚点集恰好是 {0, 1, 2}(提示:让三个值各被无穷多项取到)。

## 参考解答

(建议先自己写完再看。)

**(a)** xₙ = (−1)ⁿ(1 + 1/n)。偶子列 x_{2k} = 1 + 1/(2k) → 1;奇子列 x_{2k+1} = −(1 + 1/(2k+1)) → −1。聚点是 **1 和 −1**:偶下标子列 → 1,奇下标子列 → −1。(数列有界:|xₙ| ≤ 1 + 1/n ≤ 2;B–W 保证有收敛子列,这里恰有两个去向。)

**(b)** B–W 是单向蕴含「有界 ⟹ 有收敛子列」,其逆否是「无收敛子列 ⟹ 无界」,但它**不**断言「无界 ⟹ 无收敛子列」。反例:xₙ := (0, 1, 0, 2, 0, 3, 0, 4, …)——偶数位置恒为 0、奇数位置为 1,2,3,…。它无界(奇数位跑向无穷),但偶数位子列恒为 0,收敛到 0。所以无界数列照样可以有收敛子列,与 B–W 不矛盾。

**(c)** 把 0,1,2 轮流排开,每个出现无穷多次:xₙ := (0, 1, 2, 0, 1, 2, 0, 1, 2, …)(周期 3)。下标 ≡0 (mod 3) 的子列恒为 0 → 0,≡1 的 → 1,≡2 的 → 2,故 0,1,2 都是聚点;而其余任何点的小邻域只含有限项(实为零项),不是聚点。故聚点集恰为 {0,1,2}。∎

回顾:这三问围绕同一个区分——**聚点是「无穷多项靠近」,与「有界」「收敛」都不同**。有界保证聚点存在(B–W),但聚点可以有多个(发散数列);无界不排除聚点(只要某个子列收敛);聚点集可以是任意指定的有限集(让每个值被无穷多项取到)。把「聚点 / 有界 / 收敛」三者的关系彻底厘清,是这一串练习的目的。

## 往前看一步

Bolzano–Weierstrass 给了我们一台「从有界数列提取收敛子列」的机器。它最重要的应用,是回答一个比单调收敛更普遍的收敛判据问题。单调收敛只管单调数列;可很多数列并不单调,却明显在「自我收拢」——项与项之间越来越靠近。Cauchy 把这种「内部收拢」精确化为一个判据:**对每个 ε,存在 N,使 m, n ≥ N 时 d(xₙ, xₘ) < ε**(Cauchy 列)。下一节将证明:在 ℝ 和 ℂ 中,**一个数列收敛当且仅当它是 Cauchy 列**——而证明「Cauchy ⟹ 收敛」的关键一步,正是用 B–W 从 Cauchy 列里提取一个收敛子列。这就是 [[an_cauchy|Cauchy 列与完备性]] 的内容。
