## 从「数」到「函数」

第二章把「一列点如何趋于一个点」彻底厘清了——[[an_convergenza|数列收敛]]、[[an_cauchy|完备性]]、[[an_serie|级数]]、[[an_serie_potenze|幂级数]]。现在分析的对象从「数列」升级到「函数」。第一个、也是最基本的函数性质,是**连续性**。

直觉上,连续函数是「图像不断开、可以一笔画成」的函数;反过来,不连续是「图像有跳跃、有洞」。但「一笔画成」是图形语言,不能作严格定义。严格的想法是:**当自变量 x 靠近 x₀ 时,函数值 f(x) 也靠近 f(x₀)**——输入的微小变化只引起输出的微小变化,没有突变。这一节把这个直觉用 ε–δ 精确化,并接上第二章的数列理论。

## 用邻域定义连续

设 f : X → Y 是两个[[an_spazio_metrico|度量空间]]之间的函数。「f(x) 靠近 f(x₀)」用[[an_spazio_metrico|邻域]]表述最干净:

**定义(连续).** f 在点 x₀ ∈ X **连续**(continuous)，若对 f(x₀) 的**每个**邻域 V,都存在 x₀ 的某个邻域 U,使得

f(U) ⊆ V，

即「U 中的点全被 f 映进 V」。若 f 在 X 的每一点都连续,就称 f **连续**。

读法:**无论你要求 f(x) 落在 f(x₀) 周围多小的范围 V 里,总能找到 x₀ 周围一个范围 U,使得 U 里的 x 都满足要求**。输出要多准,输入就收多紧——这正是「微小输入变化 ⟹ 微小输出变化」的精确版。

## ε–δ 表述

邻域定义简洁,但具体计算时,用[[an_spazio_metrico|球]]把邻域写成 ε、δ 更顺手。

**命题(ε–δ 判据).** f : X → Y 在 x₀ 连续 **当且仅当**:对每个 **ε > 0**,存在 **δ = δ(x₀, ε) > 0**,使得

d(f(x₀), f(x)) < ε，  对一切满足 d(x₀, x) < δ 的 x。

（记号 δ = δ(x₀, ε) 强调 δ 一般同时依赖于点 x₀ 和精度 ε。）

**证明.** 把上面邻域定义里的 V 取成球 B(f(x₀), ε)、U 取成球 B(x₀, δ) 即可:邻域定义说「每个 V 有 U 使 f(U)⊆V」,翻译成球就是「每个 ε 有 δ 使 d(x,x₀)<δ ⟹ d(f(x),f(x₀))<ε」。两者等价。∎

图示:给定 f(x₀) 周围宽 2ε 的水平带,要找 x₀ 周围宽 2δ 的竖直带,使曲线在竖直带内的部分**整个落进水平带**。函数越「陡」,达到同样 ε 所需的 δ 越小——但只要不突变,总能找到。

**例(平方根连续).** f : ℝ₊ → ℝ₊,x ↦ √x 连续。**验证(在 x₀ > 0)**:给定 ε > 0,取 δ := min(ε√x₀, x₀)。当 |x − x₀| < δ 时,用[[num_radici_n|根式]]的有理化:

|√x − √x₀| = |x − x₀| / (√x + √x₀) ≤ |x − x₀| / √x₀ < δ/√x₀ ≤ ε。

(分母 √x + √x₀ ≥ √x₀ 给了第一个不等号。)故 √x 在每点连续。∎ 这是 ε–δ 定义的典型用法:**从目标 |f(x)−f(x₀)| < ε 倒推出需要多小的 δ**。

## 序列判据：连续 = 尊重极限

连续性与第二章的桥梁,是下面这条定理——它把「连续」翻译成「保持数列极限」,从而让**整套[[an_convergenza|数列收敛]]理论瞬间可用于函数**。

**定理(序列判据).** f : X → Y 在 x₀ 连续 **当且仅当** f 在 x₀ **序列连续**:对**每个**收敛到 x₀ 的数列 (xₙ)(xₙ → x₀),都有 f(xₙ) → f(x₀)。

**证明.** （⟹）设 f 在 x₀ 连续,xₙ → x₀。任取 f(x₀) 的邻域 V,由连续性有 x₀ 的邻域 U 使 f(U) ⊆ V。因 xₙ → x₀,存在 N 使 n ≥ N 时 xₙ ∈ U,于是 f(xₙ) ∈ V。这说明 f(xₙ) → f(x₀)。

（⟸）反证。设 f 序列连续但在 x₀ **不**连续。则有 f(x₀) 的某个邻域 V,使**任何** x₀ 的邻域都装不进 V——特别地,对每个 k,球 B(x₀, 1/k) 里都有点 xₖ 使 f(xₖ) ∉ V。这样构造的 (xₖ) 满足 d(x₀,xₖ) < 1/k → 0,即 xₖ → x₀,但 f(xₖ) 始终在 V 外,不收敛到 f(x₀)——与序列连续矛盾。故 f 在 x₀ 连续。∎

由此立刻得到连续函数最常用的一条性质——**连续函数与取极限可交换**:对任何收敛数列 (xₙ),

lim_{n→∞} f(xₙ) = f( lim_{n→∞} xₙ )。

一句话:**连续函数「尊重极限」**(respects limits)——先取极限再作用 f,与先作用 f 再取极限,结果相同。这是连续性最实用的刻画,也是「连续」一词在分析中真正的操作含义。

## 连续函数的运算

序列判据的最大红利,是把[[an_algebra_limiti|数列极限的运算法则]]直接搬成连续函数的运算法则——证明几乎是「翻译」。

**命题.** 设 f, g 在 x₀ 连续(值在赋范空间 F,或 F = 𝕂)。则:

(i) f + g 与 λf（λ ∈ 𝕂）在 x₀ 连续;
(ii) 若 F = 𝕂,f · g 在 x₀ 连续;
(iii) 若 F = 𝕂 且 g(x₀) ≠ 0,f / g 在 x₀ 连续。

**证明.** 全部经由[[an_continuita|序列判据]]化归到[[an_algebra_limiti|数列运算法则]]。以 (ii) 为例:任取 xₙ → x₀。由 f, g 序列连续,f(xₙ) → f(x₀)、g(xₙ) → g(x₀);由数列[[an_algebra_limiti|积的极限]],f(xₙ)g(xₙ) → f(x₀)g(x₀),即 (f·g)(xₙ) → (f·g)(x₀)。故 f·g 序列连续,从而连续。(i)(iii) 同理,分别用和、商的极限法则(商需 g(x₀)≠0 保证分母不为零)。∎

**这正是序列判据的威力:连续函数的运算,无需重新做 ε–δ,只要调用第二章数列极限的对应法则。** 一次建立的数列理论,在这里第二次收获。

由这条命题,一大批函数的连续性「免费」得到:

- **多项式连续**:常函数和恒等函数 x↦x 显然连续,由加法、乘法封闭,任何多项式 aₙxⁿ+⋯+a₀ 连续。
- **有理函数连续**:两个多项式之商 p(x)/q(x),在 q(x)≠0 处连续(由 (iii))。
- 由 √x 连续 + 复合(连续函数的复合仍连续,易由序列判据证)、四则运算,√(x²+1)、(x+1)/(x²−2) 等都连续。

## 一道激活练习

(a) 用 ε–δ 定义证明 f(x) = 3x + 1 在任意点 x₀ ∈ ℝ 连续。(提示:|f(x)−f(x₀)| = 3|x−x₀|,要它 < ε,取 δ = ε/3。)

(b) 用**序列判据**证明:若 f 在 x₀ 连续且 f(x₀) > 0,则存在 x₀ 的一个邻域,f 在其上恒正。(提示:反证——若每个邻域里都有 f ≤ 0 的点,构造 xₙ → x₀ 使 f(xₙ) ≤ 0,用序列连续 + [[an_confronto|极限保序]]推出 f(x₀) ≤ 0,矛盾。)

(c) 考虑**Dirichlet 函数** D(x) = 1（x 有理）、D(x) = 0（x 无理）。用序列判据说明 D 在**每一点**都不连续。(提示:任何实数 x₀ 附近既有[[num_q_ordine|有理数]]也有[[an_rappresentazioni|无理数]]逼近它,构造两列都→x₀ 但 D 值不同的数列。)

## 参考解答

(建议先自己写完再看。)

**(a)** 给定 ε > 0,取 δ := ε/3。当 |x − x₀| < δ 时:

|f(x) − f(x₀)| = |(3x+1) − (3x₀+1)| = 3|x − x₀| < 3δ = 3·(ε/3) = ε。

故 f 在 x₀ 连续。∎(线性函数的 δ 与 x₀ 无关,只依赖 ε——这种「δ 不依赖点」的性质以后叫**一致连续**。)

**(b)** 反证。设 f(x₀) > 0,但**每个** x₀ 的邻域里都有使 f ≤ 0 的点。特别地,对每个 n,球 B(x₀, 1/n) 里有点 xₙ 使 f(xₙ) ≤ 0。则 d(x₀, xₙ) < 1/n → 0,即 xₙ → x₀。由 f 在 x₀ [[an_continuita|序列连续]],f(xₙ) → f(x₀)。而 f(xₙ) ≤ 0 对所有 n,由[[an_confronto|极限保序]](≤ 在取极限下保持),f(x₀) = lim f(xₙ) ≤ 0——与 f(x₀) > 0 矛盾。故存在某邻域 f 恒正。∎(这条「连续函数在正值点附近保持正」是常用的局部性质。)

**(c)** 取任意 x₀ ∈ ℝ。因[[num_q_ordine|有理数稠密]],存在有理数列 (aₙ) 使 aₙ → x₀,此时 D(aₙ) = 1 → 1;因无理数也稠密([[an_rappresentazioni|无理数充满数轴]]),存在无理数列 (bₙ) 使 bₙ → x₀,此时 D(bₙ) = 0 → 0。两列都收敛到 x₀,但 D 沿它们的极限不同(1 ≠ 0)——若 D 在 x₀ 连续,序列判据要求 D 沿**任何**→x₀ 的数列都趋于同一个 D(x₀),矛盾。故 D 在 x₀ 不连续。x₀ 任意,故 D 处处不连续。∎

回顾:三题覆盖连续性的两套工具。(a) 是 **ε–δ 直接验证**(从 ε 倒推 δ)。(b)(c) 是 **序列判据**的应用:(b) 用「构造逼近数列 + 极限保序」证局部正性,(c) 用「两列不同极限」证不连续——**证不连续最有力的办法,就是找两个都收敛到 x₀ 但函数值趋于不同极限的数列**。Dirichlet 函数处处不连续,生动展示了有理/无理数在数轴上「犬牙交错」的稠密性,也展示了序列判据判定不连续的威力。

## 往前看一步

连续性建立起来了,且经由序列判据与第二章的数列理论完全打通——连续函数「尊重极限」,其四则运算自动连续,多项式、有理函数、根式等一大批函数的连续性随之到手。

但连续函数最深刻的力量,体现在它的**整体定理**上——这些定理把「局部的连续」放大成「整体的结构性结论」:
- **介值定理**(Bolzano):连续函数若在两点取异号值,中间必有零点——「连续曲线从负到正必穿过零」。这是求根、存在性证明的基石。
- **最值定理**:闭区间上的连续函数必取到最大值和最小值——保证优化问题有解。

这两条定理的根基,是 ℝ 的[[an_cauchy|完备性]]与两个深刻的拓扑概念——**紧性**(compactness,「闭且有界」的本质)与**连通性**(connectedness,「不可分割」的本质)。第三章接下来会建立这套拓扑语言(开集、闭集、紧集),然后用它证明介值定理与最值定理。而这些,又都是通向**微分**的准备——可微比连续更强,而导数,正是你那条暂停的[[物理线]]等待已久的汇合点。连续函数是分析这座大厦从「数」迈向「函数」的第一层,拾级而上,微积分在望。
