[[num_n|Peano 公理]]只给出了三样东西：集合 ℕ、元素 0、后继函数 ν。加法、乘法、大小比较都还不存在。本节把它们定义出来，并说明通常的算术律全部可由公理推出。

## 一条必须先立的规矩

**在本节中，0 与 1 只是集合 ℕ 中两个被指定的元素，与我们平常认识的数字 0、1 没有任何关系。**

这句话来自 A–E，是初学者最容易违反的一点：证明中途不自觉地用上「显然 2+3=5」「加法当然可交换」这类日常算术事实。**凡是还没从公理推出来的性质，一律不得使用。** 本节的每一步都只能依据：

(N0) ν 单射<br>
(N1) 归纳<br>
以及本节已经定义、已经证明的内容

## 定理 5.3

**定理（A–E 定理 5.3）** ℕ 上存在加法 **+**、乘法 **·** 与偏序 **≤**，它们由下列条件唯一确定：

**(i)** 加法结合、交换，以 0 为单位元。

**(ii)** 乘法结合、交换，以 **1 := ν(0)** 为单位元。

**(iii)** 分配律成立：(ℓ + m) · n = ℓ · n + m · n，  ℓ, m, n ∈ ℕ。

**(iv)** 0 · n = 0，且 ν(n) = n + 1，  n ∈ ℕ。

**(v)** ℕ 被 ≤ [[fond_ordine|全序化]]，且 0 = min(ℕ)。

**(vi)** 对每个 n ∈ ℕ，不存在 k ∈ ℕ 使 n < k < n + 1。

**(vii)** 对一切 m, n ∈ ℕ：

m ≤ n ⟺ ∃d ∈ ℕ : m + d = n<br>
m < n ⟺ ∃d ∈ ℕ<sup>×</sup> : m + d = n

其中 d 唯一，称 n 与 m 的**差**，记 d := n − m。

**(viii)** 对一切 m, n ∈ ℕ：

m ≤ n ⟺ m + ℓ ≤ n + ℓ，  ℓ ∈ ℕ<br>
m < n ⟺ m + ℓ < n + ℓ，  ℓ ∈ ℕ

**(ix)** 对一切 m, n ∈ ℕ<sup>×</sup>，m · n ∈ ℕ<sup>×</sup>。

**(x)** 对一切 m, n ∈ ℕ：

m ≤ n ⟺ m · ℓ ≤ n · ℓ，  ℓ ∈ ℕ<sup>×</sup><br>
m < n ⟺ m · ℓ < n · ℓ，  ℓ ∈ ℕ<sup>×</sup>

**注 (iv) 的后半句很要紧**：ν(n) = n + 1。它说明后继函数不是另一种独立的运算——**取后继就是加 1**。这把公理里的 ν 与日常的「+1」对上了号。

**（A–E 说明）** 原书只证加法的存在唯一性，其余各条推荐读者参阅 Landau 的专著。那些证明是初等的，但篇幅可观。下面按原书处理：完整给出加法部分，其余标明出处。

## 加法的递归定义

加法由下面两条规定：

n + 0 := n<br>
n + ν(m) := ν(n + m)

第一条说「加 0 不变」；第二条说「加上一个后继，等于先加原来那个数、再取一次后继」。

**这是一个递归定义**：等号右边的 n + m 比左边的 n + ν(m) 「小一步」，于是可以一步步退回到 n + 0，而 n + 0 已由第一条直接给出。

写成一条链：

2 + 3<br>
= 2 + ν(2)　（3 = ν(2)）<br>
= ν(2 + 2)　（第二条）<br>
= ν(2 + ν(1))　（2 = ν(1)）<br>
= ν(ν(2 + 1))　（第二条）<br>
= ν(ν(2 + ν(0)))　（1 = ν(0)）<br>
= ν(ν(ν(2 + 0)))　（第二条）<br>
= ν(ν(ν(2)))　（第一条，递归触底）<br>
= ν(ν(3))　（ν(2) = 3）<br>
= ν(4)　（ν(3) = 4）<br>
= 5　（ν(4) = 5）

**这就是加法在公理层面的全部内容**：「加 3」就是「连取三次后继」。日常的加法表在这里是被**算出来**的，不是被假定的。

## 唯一性

先证：满足条件的加法**至多有一个**。以下把待定的运算记作 ⊡（暂不写成 +，以免不自觉地套用日常加法的性质）。

设 ⊡ 是 ℕ 上的**交换**运算，满足

0 ⊡ 0 = 0，  n ⊡ 1 = ν(n)，  n ⊡ ν(m) = ν(n ⊡ m)，  n, m ∈ ℕ  ……(★)

**第一步：0 ⊡ n = n 对一切 n 成立。**

令 N := { n ∈ ℕ ; 0 ⊡ n = n }，用 [[num_n|(N1)]]。

0 ∈ N：由 (★) 的第一式 0 ⊡ 0 = 0。

n ∈ N ⟹ ν(n) ∈ N：设 0 ⊡ n = n，则

0 ⊡ ν(n) = ν(0 ⊡ n)　（(★) 第三式）<br>
= ν(n)　（归纳假设）

故 ν(n) ∈ N。由 (N1)，N = ℕ。∎

**第二步：满足 (★) 的交换运算至多一个。**

设 ⊟ 是另一个满足 (★) 的交换运算。固定任意 n ∈ ℕ，令

M := { m ∈ ℕ ; m ⊡ n = m ⊟ n }

0 ∈ M：对 ⊟ 重复第一步的论证得 0 ⊟ n = n；由第一步 0 ⊡ n = n。故 0 ⊡ n = n = 0 ⊟ n。

m ∈ M ⟹ ν(m) ∈ M：设 m ⊡ n = m ⊟ n，则

ν(m) ⊡ n = n ⊡ ν(m)　（⊡ 交换）<br>
= ν(n ⊡ m)　（(★) 第三式）<br>
= ν(m ⊡ n)　（⊡ 交换）<br>
= ν(m ⊟ n)　（归纳假设）<br>
= ν(n ⊟ m)　（⊟ 交换）<br>
= n ⊟ ν(m)　（(★) 第三式，对 ⊟）<br>
= ν(m) ⊟ n　（⊟ 交换）

故 ν(m) ∈ M。由 (N1)，M = ℕ。

因 n 任意，得 m ⊡ n = m ⊟ n 对一切 m, n 成立，即 ⊡ = ⊟。∎

## 存在性

再证：这样的运算**确实存在**。难点在于「递归定义是否合法」——上面那两条规定看起来定义了加法，但严格说来，我们还没有证明真有这样一个函数存在。

### 先看清要造的是什么

思路是：对每个固定的 n，造一个函数 φ<sub>n</sub> : ℕ → ℕ，让它承担「n 加上某数」的职责。

**φ<sub>n</sub> 应该是什么？** 按我们想要的加法，φ<sub>n</sub> 将满足 φ<sub>n</sub>(m) = n + ν(m)，也就是「先加 n，再加 1」。取 n = 2 具体看一遍：

φ₂(0) = 3，  φ₂(1) = 4，  φ₂(2) = 5，  φ₂(3) = 6，  …

即 φ₂ 是「加 3」这个函数。

**但不能这样定义它。** 「加 3」这句话本身就用到了加法，而加法正是我们要造的东西——直接说「令 φ<sub>n</sub> 为加 n+1 的函数」是循环论证。

出路是**不说它是什么，只说它怎么走**：规定起点，再规定每一步如何由上一步得到。对 φ₂：

**起点** φ₂(0) = 3　（即 ν(2)）<br>
**步进** φ₂(下一个) = 下一个(φ₂(当前))　（即 φ₂(ν(m)) = ν(φ₂(m))）

照这两条走一遍：

φ₂(0) = ν(2) = 3<br>
φ₂(1) = φ₂(ν(0)) = ν(φ₂(0)) = ν(3) = 4<br>
φ₂(2) = φ₂(ν(1)) = ν(φ₂(1)) = ν(4) = 5<br>
φ₂(3) = φ₂(ν(2)) = ν(φ₂(2)) = ν(5) = 6

这两条规定把 φ₂ 的每一个值都逼了出来，且没有用到加法。剩下要做的是证明：**对每个 n，这样的 φ<sub>n</sub> 确实存在**。

### 构造

令

N := { n ∈ ℕ ; 存在 φ<sub>n</sub> : ℕ → ℕ 使 φ<sub>n</sub>(0) = ν(n) 且 φ<sub>n</sub>(ν(m)) = ν(φ<sub>n</sub>(m)) 对一切 m ∈ ℕ }

即「那些已经配好了 φ 的 n」。用 (N1) 证 N = ℕ。

**0 ∈ N**：取 φ<sub>0</sub> := ν。验证两个条件：

φ<sub>0</sub>(0) = ν(0) ✓<br>
φ<sub>0</sub>(ν(m)) = ν(ν(m)) = ν(φ<sub>0</sub>(m)) ✓

**n ∈ N ⟹ ν(n) ∈ N**：设 φ<sub>n</sub> 已存在。定义

ψ : ℕ → ℕ，  m ↦ ν(φ<sub>n</sub>(m))

则

ψ(0) = ν(φ<sub>n</sub>(0)) = ν(ν(n))　（即 ν 作用于 ν(n)，符合要求）<br>
ψ(ν(m)) = ν(φ<sub>n</sub>(ν(m))) = ν(ν(φ<sub>n</sub>(m))) = ν(ψ(m)) ✓

故 ψ 可充当 φ<sub>ν(n)</sub>，即 ν(n) ∈ N。

由 (N1)，N = ℕ：**每个 n 都有这样一个 φ<sub>n</sub>**。

**φ<sub>n</sub> 唯一**：设 φ<sub>n</sub> 与 ψ<sub>n</sub> 都满足条件，令 M<sub>n</sub> := { m ; φ<sub>n</sub>(m) = ψ<sub>n</sub>(m) }。则 0 ∈ M<sub>n</sub>（两者在 0 处都等于 ν(n)）；若 m ∈ M<sub>n</sub>，则

φ<sub>n</sub>(ν(m)) = ν(φ<sub>n</sub>(m)) = ν(ψ<sub>n</sub>(m)) = ψ<sub>n</sub>(ν(m))

故 ν(m) ∈ M<sub>n</sub>。由 (N1)，M<sub>n</sub> = ℕ，即 φ<sub>n</sub> = ψ<sub>n</sub>。

**定义加法**：

n + m := n，  若 m = 0<br>
n + m := φ<sub>n</sub>(m′)，  若 m = ν(m′)

这个分情形是完备且无歧义的：由[[num_n|注 5.1(a)]]，每个 m 要么是 0、要么恰是唯一一个 m′ 的后继。

可验证它满足 n + ν(m) = ν(n + m)，并且 n + 0 = n、n + 1 = ν(n)。∎

**注** 上面为构造 φ<sub>n</sub> 所做的工作，实质上是**递归定理**的一个特例：它保证「用前一步定义后一步」这种定义方式确实产生一个函数。一般形式的递归定理将在[[num_ricorsione|递归定义]]一节给出。

## 一条性质的证明示范：结合律

其余各条的证法都类似——**把待证等式中的一个变元设为归纳变元，对它用 (N1)**。以结合律为例。

固定任意 ℓ, m ∈ ℕ，令

N := { n ∈ ℕ ; (ℓ + m) + n = ℓ + (m + n) }

**0 ∈ N**：(ℓ + m) + 0 = ℓ + m = ℓ + (m + 0)（三处都用 n + 0 = n）。

**n ∈ N ⟹ ν(n) ∈ N**：

(ℓ + m) + ν(n) = ν((ℓ + m) + n)　（递归式第二条）<br>
= ν(ℓ + (m + n))　（归纳假设）<br>
= ℓ + ν(m + n)　（递归式第二条，反向用）<br>
= ℓ + (m + ν(n))　（递归式第二条，反向用）

故 ν(n) ∈ N。由 (N1)，N = ℕ。因 ℓ, m 任意，结合律对一切 ℓ, m, n 成立。∎

## 乘法与序

**乘法**同样递归定义：

n · 0 := 0<br>
n · ν(m) := n · m + n

即「乘以一个后继，等于先乘原来那个数、再加一个 n」。存在唯一性的论证与加法同型。

**例** 算 2 · 3：

2 · 3 = 2 · ν(2) = 2 · 2 + 2 = (2 · ν(1)) + 2 = (2 · 1 + 2) + 2<br>
= ((2 · ν(0)) + 2) + 2 = ((2 · 0 + 2) + 2) + 2 = ((0 + 2) + 2) + 2<br>
= (2 + 2) + 2 = 4 + 2 = 6

**序**由加法定义（定理 5.3(vii)）：

m ≤ n  :⟺  ∃d ∈ ℕ : m + d = n

即「m 不超过 n」意思是「从 m 出发再加上某个自然数能到达 n」。相应地

m < n  :⟺  ∃d ∈ ℕ<sup>×</sup> : m + d = n

（要求 d ≠ 0，故 m ≠ n。）由 (vii)，这个 d 唯一，记 d = n − m。

**注（减法的局限）** n − m 只在 m ≤ n 时有定义。ℕ 中不存在 0 − 1 这样的元素——**减法在 ℕ 内不封闭**。这正是下一步要构造 ℤ 的动因。

## 定理 5.3 中未证部分的出处

原书只给出加法的存在唯一性证明（即上面两节），(i)–(x) 的其余部分推荐参阅：

E. Landau, *Grundlagen der Analysis*（1930）

那里的证明都是初等的，逐条用 (N1) 归纳，与上面结合律的证法同型。

## 练习

(a) 完全按递归定义计算 3 + 2，写出每一步及其依据（不得使用日常算术）。

(b) 用归纳法证明：∀n ∈ ℕ，0 + n = n。（注意：递归定义给出的是 n + 0 = n，两者不是同一条——交换律尚未证明，不得直接调换。）

(c) 用序的定义证明：∀n ∈ ℕ，0 ≤ n。（提示：按 m ≤ n :⟺ ∃d : m + d = n 找出这个 d。）

## 参考解答

**(a)**

3 + 2<br>
= 3 + ν(1)　（2 = ν(1)）<br>
= ν(3 + 1)　（递归式第二条）<br>
= ν(3 + ν(0))　（1 = ν(0)）<br>
= ν(ν(3 + 0))　（递归式第二条）<br>
= ν(ν(3))　（递归式第一条）<br>
= ν(4)　（ν(3) = 4）<br>
= 5　（ν(4) = 5）∎

（与正文的 2 + 3 = 5 对照：两者结果相同，但这**不能**用「加法交换」来解释——交换律要单独证明。这里是两次独立计算恰好得到同一结果。）

**(b)** 令 N := { n ∈ ℕ ; 0 + n = n }。

**0 ∈ N**：0 + 0 = 0，由递归式第一条（取 n = 0）。

**n ∈ N ⟹ ν(n) ∈ N**：设 0 + n = n，则

0 + ν(n) = ν(0 + n)　（递归式第二条）<br>
= ν(n)　（归纳假设）

故 ν(n) ∈ N。由 (N1)，N = ℕ。∎

**注** 这道题正是唯一性证明里的「第一步」。它之所以需要单独证明，是因为递归定义只规定了**第二个**加数为 0 的情形（n + 0 = n），第一个加数为 0 的情形（0 + n = n）必须另行推出。

**(c)** 要证 0 ≤ n，按定义需找到 d ∈ ℕ 使 0 + d = n。

取 d := n。由练习 (b)，0 + n = n。故 d = n 满足要求，得 0 ≤ n。∎

因 n 任意，0 是 ℕ 的最小元，这正是定理 5.3(v) 中 0 = min(ℕ) 的内容。

## 前瞻

加法、乘法与序都已定义，(N1) 是推出全部算术律的唯一工具。下一步是把归纳原理本身加强：允许从任意 n₀ 起步，允许在归纳步骤中使用此前**所有**情形的结论。这两种形式的陈述需要 + 与 ≤，现在已经具备。见 [[num_induzione|归纳原理与良序原理]]。
