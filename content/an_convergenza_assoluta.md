## 一个更强、更好用的收敛概念

[[an_serie|级数]]的框架立起来了,但判定敛散的工具还很少(项趋于 0、几何级数、伸缩)。这一节建立**系统的判别法**——不必求出级数的值,仅凭项的大小或比值就判断收不收敛。

关键起点是一个比「收敛」更强的概念。回想[[an_serie|级数]]里令人头疼的现象:1 − 1 + 1 − 1 + ⋯ 这种级数,正负项的加法次序一变,「和」就变(甚至发散)——收敛很「脆弱」。如果**连每一项的绝对值加起来都收敛**,情况就稳健得多。

**定义(绝对收敛).** 级数 Σaₖ 称**绝对收敛**(absolutely convergent)，若由各项绝对值构成的级数 Σ|aₖ| 收敛(即 Σ|aₖ| < ∞)。

(本节 aₖ 可取在 ℝ、[[alg_complessi|ℂ]],或更一般的[[an_cauchy|Banach 空间]]里;|·| 相应地是绝对值、模或[[an_norma|范数]]。)

「绝对收敛」名副其实——它确实蕴含收敛:

**命题.** 每个绝对收敛的级数都收敛。

**证明.** 设 Σ|aₖ| 收敛。由[[an_serie|级数的 Cauchy 判据]](部分和是 Cauchy 列),对每个 ε > 0 存在 N,使

Σ_{k=n+1}^{m} |aₖ| < ε，  对一切 m > n ≥ N。

而由三角不等式,Σaₖ 的部分和之差被它控制:

|Σ_{k=n+1}^{m} aₖ| ≤ Σ_{k=n+1}^{m} |aₖ| < ε，  m > n ≥ N。

所以 Σaₖ 的部分和也是 Cauchy 列;由 ℝ(或 ℂ、Banach 空间)的[[an_cauchy|完备性]],Σaₖ 收敛。∎

证明的核心:**三角不等式让「绝对值级数的 Cauchy 性」传递给原级数**。这里[[an_cauchy|完备性]]再次是关键——Cauchy 判据要靠它把「部分和收拢」兑现成「真的收敛」。

> **逆命题不成立**:收敛**不**蕴含绝对收敛。下面的交错调和级数 Σ(−1)ᵏ⁺¹/k 收敛,但其绝对值级数是[[an_serie|发散]]的调和级数 Σ1/k。这种「收敛但不绝对收敛」的级数称**条件收敛**(conditionally convergent)——它的收敛依赖正负项的抵消,是「脆弱」的那一类。

## 交错级数：条件收敛的典型

先处理一类常见的、往往只条件收敛的级数——正负号交替出现的**交错级数**。

**定理(Leibniz 判别法).** 设 (bₖ) 是**递减**的、趋于 0 的**非负**数列。则交错级数

Σ_{k} (−1)ᵏ bₖ = b₀ − b₁ + b₂ − b₃ + ⋯

收敛。

**证明.** 看部分和 sₙ。偶数下标部分和递减:s_{2n+2} − s_{2n} = −b_{2n+1} + b_{2n+2} ≤ 0(因 bₖ 递减);奇数下标部分和递增:s_{2n+1} − s_{2n−1} = b_{2n} − b_{2n+1} ≥ 0。又 s_{2n+1} ≤ s_{2n}(差一个非负的 b_{2n+1})。于是 (s_{2n}) 递减有下界、(s_{2n+1}) 递增有上界,由[[an_monotone|单调收敛]]两者都收敛,设 s_{2n}→s、s_{2n+1}→t。而

t − s = lim(s_{2n+1} − s_{2n}) = lim(−b_{2n+1}) = 0，

故 s = t,奇偶部分和收敛到同一极限,从而 (sₙ) 整体收敛。∎

直观:部分和在极限两侧来回跳,跳幅 bₖ 越来越小,被夹向中间。**误差估计**也随之而来:用第 n 个部分和近似级数值,误差不超过「第一个被丢掉的项」|b_{n+1}|(因为极限被夹在相邻两个部分和之间)。

**例(交错调和级数).** Σ_{k=1}^∞ (−1)^{k+1}/k = 1 − 1/2 + 1/3 − 1/4 + ⋯ 收敛(因 1/k 递减趋 0,Leibniz 适用)。它的值是 log 2(留待对数函数严格化后证)。但它**只条件收敛**:绝对值级数 Σ1/k 是发散的[[an_serie|调和级数]]。这是「收敛但不绝对收敛」最经典的例子。

## 比较判别法（优级数判别法）

回到绝对收敛。判定绝对收敛最灵活的工具,是和一个已知收敛的级数「比大小」。

**定义.** 设 Σaₖ 是级数,Σcₖ 是**非负项**级数。若存在 K 使 |aₖ| ≤ cₖ 对一切 k ≥ K,则称 Σcₖ 是 Σaₖ 的一个**优级数**(majorant)。

**定理(比较判别法).** 若级数有一个**收敛的优级数**,则它绝对收敛。

**证明.** 设 |aₖ| ≤ cₖ（k ≥ K）,Σcₖ 收敛。由 Σcₖ 的 [[an_serie|Cauchy 判据]],对 ε > 0 存在 N ≥ K 使 Σ_{k=n+1}^m cₖ < ε（m > n ≥ N）。则

Σ_{k=n+1}^{m} |aₖ| ≤ Σ_{k=n+1}^{m} cₖ < ε，

故 Σ|aₖ| 满足 Cauchy 判据,收敛,即 Σaₖ 绝对收敛。∎

**例:** Σ 1/kᵐ 当 m ≥ 2 收敛——因 1/kᵐ ≤ 1/k²,而 [[an_serie|Σ1/k² 收敛]],它是优级数。又如 |z| < 1 时 Σzᵏ 绝对收敛——|zᵏ| = |z|ᵏ,而几何级数 Σ|z|ᵏ 收敛,作优级数。比较判别法把「新级数的敛散」化归到「已知级数」,几何级数和 Σ1/kᵖ 是最常用的比较对象。

## 根值判别法：lim sup 上场

从比较判别法(以几何级数为优级数)能导出两个极其常用的判别法。第一个看「项的 k 次方根」——这里[[an_limsup|上极限]]正式派上用场。

**定理(根值判别法 root test).** 设 Σaₖ 是级数,令

α := lim sup_{k→∞} ᵏ√|aₖ|（即 [[an_limsup|上极限]]）。

则:(i) α < 1 时 Σaₖ **绝对收敛**;(ii) α > 1 时 Σaₖ **发散**;(iii) α = 1 时**判别法失效**(可能收敛也可能发散)。

**证明.** (i) 设 α < 1。取 q 满足 α < q < 1。因 α 是 ᵏ√|aₖ| 的[[an_limsup|最大聚点]],只有有限多项能超过 q,故存在 K 使 ᵏ√|aₖ| < q 对一切 k ≥ K,即 **|aₖ| < qᵏ**。几何级数 Σqᵏ（q<1）收敛,作优级数,由比较判别法 Σaₖ 绝对收敛。

(ii) 设 α > 1。因 α 是最大聚点,有**无穷多**个 k 使 ᵏ√|aₖ| ≥ 1,即 |aₖ| ≥ 1。这样项 aₖ 不趋于 0,由[[an_serie|项趋于 0 必要条件]]的反面,级数发散。

(iii) α = 1 失效:交错调和级数 Σ(−1)ᵏ⁺¹/k 有 ᵏ√|aₖ| = ᵏ√(1/k) = 1/ᵏ√k → 1(因 [[an_confronto|ⁿ√n → 1]]),故 α = 1,而它收敛;调和级数 Σ1/k 同样 α = 1,却发散。同一个 α=1,两种结局,故失效。∎

**为什么必须用 lim sup 而非 lim**:数列 ᵏ√|aₖ| 一般**不收敛**(没有普通极限),但它的 lim sup [[an_limsup|总存在]]。所以根值判别法的精确表述,绕不开上极限——这正是[[an_limsup|当时补上极限]]时说的「为幂级数和根值判别法预备」的兑现。

根值判别法的精髓:**把任意级数的项,和一个几何级数比**——ᵏ√|aₖ| < q 等价于 |aₖ| < qᵏ,即项最终被一个公比 < 1 的几何级数压住,故收敛。

## 比值判别法：看相邻项之比

根值判别的思路(比几何级数)还导出一个更易计算的判别法——看相邻项的比值。

**定理(比值判别法 ratio test).** 设 Σaₖ 的项最终非零。

(i) 若存在 q ∈ (0,1) 和 K,使 |a_{k+1}|/|aₖ| ≤ q 对一切 k ≥ K,则 Σaₖ **绝对收敛**;

(ii) 若 |a_{k+1}|/|aₖ| ≥ 1 对一切充分大的 k,则 Σaₖ **发散**。

特别地,若极限 L := lim |a_{k+1}|/|aₖ| 存在,则 L < 1 时绝对收敛,L > 1 时发散,L = 1 时失效。

**证明(i).** 设 |a_{k+1}|/|aₖ| ≤ q（k ≥ K）。则 |a_{K+1}| ≤ q|a_K|,|a_{K+2}| ≤ q|a_{K+1}| ≤ q²|a_K|,归纳得 |a_{K+j}| ≤ qʲ|a_K|。所以从第 K 项起,|aₖ| 被几何级数 |a_K|·Σqʲ（q<1，收敛）压住,作优级数,绝对收敛。(ii) 若比值 ≥ 1,则 |aₖ| 不减,不趋于 0,级数发散。∎

比值判别法在实践中常比根值判别更好算(求比值比求方根容易),尤其当项含阶乘或幂时。

**例(指数级数 Σ zᵏ/k! 绝对收敛).** 对任意 z ∈ ℂ,看比值:

|a_{k+1}|/|aₖ| = (|z|^{k+1}/(k+1)!)/(|z|ᵏ/k!) = |z|/(k+1) → 0  （k → ∞）。

极限 L = 0 < 1,由比值判别法,**Σ zᵏ/k! 对一切 z 绝对收敛**。这个级数极其重要——它的和定义了**指数函数** exp(z)，下一阶段(幂级数)会正式展开。注意 z = 1 时它就是 [[an_numero_e|e = Σ1/k!]]:e 是指数函数在 1 处的值。比值判别法在这里一举证明了「指数级数处处收敛」,为指数函数的定义扫清障碍。

> **根值 vs 比值**:根值判别法更强(适用范围更广,凡比值判别能判的它都能判),但比值判别法通常更易算。两者 α=1 或 L=1 时都失效,此时要回到比较判别法或更精细的工具。

## 一道激活练习

用适当的判别法判定下列级数是否(绝对)收敛:

(a) Σ_{k=1}^∞ k²/2ᵏ（提示:比值判别法,算 a_{k+1}/aₖ 的极限）;

(b) Σ_{k=1}^∞ (−1)ᵏ/√k（提示:先看绝对值级数 Σ1/√k 是否收敛——和 Σ1/k 比;再用 Leibniz 判别法看原级数;结论是绝对还是条件收敛?）;

(c) Σ_{k=1}^∞ (k/(k+1))^{k²}（提示:根值判别法,算 ᵏ√|aₖ| = (k/(k+1))ᵏ = 1/(1+1/k)ᵏ 的极限,回忆 [[an_numero_e|(1+1/k)ᵏ → e]]）。

## 参考解答

(建议先自己写完再看。)

**(a)** 比值判别法:

a_{k+1}/aₖ = ((k+1)²/2^{k+1})/(k²/2ᵏ) = ((k+1)²/k²)·(2ᵏ/2^{k+1}) = (1+1/k)²·(1/2) → 1²·(1/2) = 1/2。

极限 L = 1/2 < 1,故级数**绝对收敛**(项非负,即收敛)。∎（这也顺带说明 k²/2ᵏ → 0:收敛级数的项必趋于 0——指数 2ᵏ 压倒多项式 k²，正是审计里提到的「增长速度」结论的一个实例。）

**(b)** 先看绝对值级数 Σ1/√k = Σk^{−1/2}。因 1/√k ≥ 1/k 对 k ≥ 1（√k ≤ k），而调和级数 Σ1/k 发散,由比较判别法(这次反向:更大的项发散则……更精确地,Σk^{−p} 当 p ≤ 1 发散,p=1/2 ≤ 1 故发散)Σ1/√k **发散**——所以原级数**不绝对收敛**。再用 Leibniz:1/√k 递减趋 0,故交错级数 Σ(−1)ᵏ/√k **收敛**。结论:**条件收敛**(收敛但不绝对收敛)。∎

**(c)** 根值判别法:

ᵏ√|aₖ| = ᵏ√((k/(k+1))^{k²}) = (k/(k+1))ᵏ = 1/((k+1)/k)ᵏ = 1/(1 + 1/k)ᵏ → 1/e。

(用了 [[an_numero_e|(1+1/k)ᵏ → e]]。)极限 α = 1/e ≈ 0.368 < 1,故级数**绝对收敛**。∎

回顾:选判别法的经验——**项含阶乘或 k 次幂(如 2ᵏ、k!)用比值或根值;项形如 (⋯)^{k 的函数} 优先根值(方根能消掉外层幂);交错级数先查绝对收敛(绝对值级数),不绝对收敛再用 Leibniz 判条件收敛**。(b) 示范了完整的两步判定:先否掉绝对收敛、再用 Leibniz 确认条件收敛。(c) 则展示根值判别法与 e 的极限的漂亮配合。

## 往前看一步

收敛判别法成套就位:绝对收敛、比较、根值(用[[an_limsup|lim sup]])、比值,加上交错级数的 Leibniz。我们现在能判定绝大多数级数的敛散——而且在 (b) 的指数级数 Σzᵏ/k! 那里,已经瞥见了下一站的主角。

把级数的项换成**含一个变量 z 的幂** cₖzᵏ,得到的 Σcₖzᵏ 称**幂级数**(power series)。它对某些 z 收敛、对另一些 z 发散,而「收敛的 z 的范围」是一个以原点为心的圆盘,其半径(**收敛半径**)由根值判别法 + lim sup 给出——这就是 Cauchy–Hadamard 公式,[[an_limsup|上极限]]在此第二次大显身手。幂级数是把函数表示成「无穷次多项式」的工具,**指数函数、三角函数、对数**都将由幂级数严格定义。这就是 A–E 第二章的收官、也是通向初等函数严格化的门:幂级数与收敛半径。
