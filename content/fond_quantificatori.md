[[fond_proposizioni|上一节]]处理的是整句的真假。但数学中大量陈述含有变元，例如「x > 3」——它本身没有真值，要等 x 取定才有。本节引入处理这类陈述的工具。

## 谓词

**谓词**(property, predicate)是一个表达式 E(x)，当 x 被某个指定范围内的对象代入后，它成为一个[[fond_proposizioni|命题]]。

「x > 3」是谓词：代入 x = 5 得真命题，代入 x = 1 得假命题。**谓词本身不是命题**，因为它没有确定的真值。

「x 具有性质 E」意即「E(x) 为真」。

**选取记号** 设 X 是一个范围，E 是谓词。则

{ x ∈ X ; E(x) }

表示 X 中一切具有性质 E 的元素所构成的类。例如取 X 为本书的全体读者、E(x) 为「x 戴眼镜」，则该记号表示本书戴眼镜的读者全体。这个记号在[[fond_insiemi|集合]]一节会正式使用。

## 两个量词

把谓词变成命题的办法，是指明「有多少个 x 使它成立」。

**存在量词** ∃

∃ x ∈ X : E(x)

意为「X 中**至少存在一个**对象 x 具有性质 E」。

**全称量词** ∀

∀ x ∈ X : E(x)

意为「X 中**每个**对象 x 都具有性质 E」。

一旦加上量词，变元 x 被**绑定**，整个式子成为有确定真值的命题。

**唯一存在量词** ∃!

∃! x ∈ X : E(x)

意为「恰好存在一个这样的 x」。它是两件事的合取：

∃! x : E(x)  :⟺  ∃x ( E(x) ∧ ∀y ( E(y) ⟹ y = x ) )<br>
（前一项是存在性，后一项是唯一性：凡满足 E 的都等于这个 x）

证明形如 ∃! 的命题照例分两步：先造出一个，再证只此一个。这个记号在定义[[fond_funzioni|函数]]时是关键。

**记号变体** 以下三种写法意思相同：

∀ x ∈ X : E(x)<br>
E(x)，∀ x ∈ X<br>
E(x)，x ∈ X

第三种省去了 ∀。当上下文不致误解时，A–E 常用这种简写。

## 量词的否定

否定量词有一条**机械的规则**，不需要每次重新思考。

**规则** 

¬ ( ∀ x ∈ X : E(x) )  =  ∃ x ∈ X : ¬E(x)<br>
¬ ( ∃ x ∈ X : E(x) )  =  ∀ x ∈ X : ¬E(x)

用日常语言读第一式：「**并非所有** x 都具有性质 E」等价于「**至少有一个** x 不具有性质 E」。

例（A–E）：「本书的每位读者都戴眼镜」的否定是「**至少有一位**读者不戴眼镜」——**不是**「本书没有读者戴眼镜」。这是最常见的错误：否定「所有」得到的是「至少一个不」，而非「所有都不」。

第二式的例：「伦敦有一个秃头的人」的否定是「伦敦**没有**人是秃头的」，即「伦敦每个人都不秃头」。

**这是[[fond_proposizioni|德摩根律]]的推广。** 对照如下：

| 有限情形 | 任意情形 |
|---|---|
| ¬(A ∧ B) = ¬A ∨ ¬B | ¬∀x E(x) = ∃x ¬E(x) |
| ¬(A ∨ B) = ¬A ∧ ¬B | ¬∃x E(x) = ∀x ¬E(x) |

∀ 相当于把所有情形用 ∧ 连起来，∃ 相当于用 ∨ 连起来。否定把 ∧ 换成 ∨，相应地把 ∀ 换成 ∃。

## 嵌套量词：顺序要紧

一个谓词可以含两个变元，此时需要两个量词，而**它们的顺序改变含义**。

比较：

∀ x ∈ X : ( ∃ y ∈ Y : E(x, y) )<br>
∃ y ∈ Y : ( ∀ x ∈ X : E(x, y) )

第一式：对每个 x，都能找到某个 y 使 E(x,y) 成立。**这里的 y 可以依赖于 x**——换一个 x，可能要换一个 y。

第二式：存在一个 y，它对所有 x 都好用。**这里的 y 是固定的一个**，与 x 无关。

第二式比第一式**强**：若有一个通用的 y，那对每个 x 当然都能找到 y（就用那个通用的）。反过来不成立。

**例（A–E）** 设 E(x, y) 为「读者 x 认为数学概念 y 是平凡的」。

∀x ∃y : E(x,y) —— 本书每位读者都认为**某个**数学概念平凡（各人认为平凡的概念可以不同）。

∃y ∀x : E(x,y) —— 存在**某一个**数学概念，本书**所有**读者都认为它平凡。

两句话显然不是一回事。

**注** 这个区别在分析里至关重要。后面讲[[an_continuita|连续]]时，「对每个 ε 存在 δ」中的 δ 可以依赖于点；若要求「存在一个 δ 对所有点通用」，那是更强的一致连续。两者的差别就是这里的量词顺序。

## 嵌套式的否定

否定嵌套量词，只需**逐个交换 ∀ 与 ∃、保持顺序不变、最后否定内层谓词**。

¬ ( ∀x ∃y : E(x,y) )  =  ∃x ∀y : ¬E(x,y)<br>
¬ ( ∃x ∀y : E(x,y) )  =  ∀x ∃y : ¬E(x,y)

更长的也一样机械：

¬ ( ∀x ∃y ∀z : E(x,y,z) )  =  ∃x ∀y ∃z : ¬E(x,y,z)

**例（A–E）**「本书每位读者都能在第一章找到至少一个平凡的句子」的否定是「**至少有一位**读者认为第一章的**每个**句子都不平凡」。

**例（A–E）**「有一个伦敦人是每个纽约人的朋友」的否定是「对每个伦敦人，都至少有一个纽约人不是他的朋友」。

## 练习

(a) 写出下列命题的否定（用量词形式，并用日常语言说一遍）：

① ∀x ∈ ℝ : x² ≥ 0<br>
② ∃n ∈ ℕ : n > 100<br>
③ ∀ε > 0 ∃δ > 0 : E(ε, δ)

(b) 设 E(x, y) 为「x < y」，X = Y = ℕ。判断下列两命题的真假：

① ∀x ∈ ℕ ∃y ∈ ℕ : x < y<br>
② ∃y ∈ ℕ ∀x ∈ ℕ : x < y

(c) 用 ∃! 的定义展开：∃! x ∈ X : E(x)，并说明证明这类命题需要做哪两件事。

## 参考解答

**(a)**

① ¬(∀x ∈ ℝ : x² ≥ 0) = ∃x ∈ ℝ : x² < 0<br>
「存在一个实数，它的平方为负。」（这个否定为假，因为原命题为真。）

② ¬(∃n ∈ ℕ : n > 100) = ∀n ∈ ℕ : n ≤ 100<br>
「每个自然数都不超过 100。」

③ ¬(∀ε > 0 ∃δ > 0 : E(ε,δ)) = ∃ε > 0 ∀δ > 0 : ¬E(ε,δ)<br>
「存在某个 ε > 0，使得对一切 δ > 0，E(ε,δ) 都不成立。」

（③ 这个形式此后会频繁出现：它正是否定「连续」「收敛」这类定义时得到的东西。）

**(b)** ① **真**：任给 x ∈ ℕ，取 y := x + 1，则 x < y。注意这里的 y 依赖于 x。

② **假**：它断言存在一个自然数 y 大于**所有**自然数，特别地要 y < y，矛盾。（也可以说：取 x := y 即得 y < y，不可能。）

这一对正是嵌套顺序造成差别的最简例子：①②只差量词次序，一真一假。∎

**(c)**

∃! x ∈ X : E(x)  ⟺  ∃x ∈ X ( E(x) ∧ ∀y ∈ X ( E(y) ⟹ y = x ) )

要证这类命题，需做两件事：

**存在性**——具体造出（或论证存在）一个 x₀ ∈ X 使 E(x₀) 成立。

**唯一性**——设 y ∈ X 也满足 E(y)，推出 y = x₀。

两步缺一不可。只证存在性，不排除有多个；只证唯一性，可能一个都没有（此时命题为假而唯一性空洞地成立）。∎

## 前瞻

命题、联结词、谓词、量词构成了表述数学陈述的全部记号。剩下的问题是：怎样**证明**一个陈述为真。常用的证明结构（直接证明、反证法、逆否证法）以及「定理、引理、推论」这些术语的分别，见 [[fond_dimostrazioni|证明的方法]]。
