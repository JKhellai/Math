## 一个本质上是极限的常数

[[an_monotone|单调收敛定理]]最著名的用武之地,是给一个数学中无处不在的常数一个严格的出生证明。这个常数就是**欧拉数 e**(自然对数的底,微积分里几乎处处出现),而它的特别之处在于:**e 不是任何简单运算的结果**——它不像 √2 是某个方程的解,也不像 π 最初是几何比值。e 从一开始就**是一个极限**:

e := lim_{n→∞} (1 + 1/n)ⁿ。

但这个定义有个前提——必须先证明这个极限**存在**。而 (1 + 1/n)ⁿ 正是[[an_monotone|上一节]]开头那个「拆不开也夹不住」的数列:运算法则对付不了(项数随 n 变),也找不到现成的夹板。唯一的出路是单调收敛定理。这一节就用它,完成两步——证 (1+1/n)ⁿ **递增**、证它**有上界**——从而保证极限存在,e 由此诞生。

记 eₙ := (1 + 1/n)ⁿ。

## 第一步：(eₙ) 递增

要证 eₙ ≤ eₙ₊₁,看比值 eₙ₊₁/eₙ 是否 ≥ 1。

eₙ₊₁/eₙ = (1 + 1/(n+1))^{n+1} / (1 + 1/n)ⁿ。

把两个底数通分整理:1 + 1/(n+1) = (n+2)/(n+1),1 + 1/n = (n+1)/n。代入并把指数拆开(把 (n+1) 次方写成 n 次方乘一次):

eₙ₊₁/eₙ = ((n+2)/(n+1))^{n+1} · (n/(n+1))ⁿ = [ (n+2)·n / (n+1)² ]^{n+1} · (n+1)/n。

中括号里 (n+2)n = n²+2n = (n+1)² − 1,所以 (n+2)n/(n+1)² = 1 − 1/(n+1)²。于是

eₙ₊₁/eₙ = ( 1 − 1/(n+1)² )^{n+1} · (n+1)/n。

现在对第一个因子用 [[alg_binomio|Bernoulli 不等式]] (1+x)^m ≥ 1 + mx（这里 x = −1/(n+1)² ≥ −1,m = n+1）:

( 1 − 1/(n+1)² )^{n+1} ≥ 1 − (n+1)·1/(n+1)² = 1 − 1/(n+1) = n/(n+1)。

代回:

eₙ₊₁/eₙ ≥ [ n/(n+1) ] · [ (n+1)/n ] = 1。

故 eₙ₊₁ ≥ eₙ,数列递增。∎ 注意这一步的关键是把那个看着无从下手的比值,**整理成「1 减一个小量」的幂,再用 Bernoulli 不等式一压**——又一次「展开/放缩成可控的形状」,与[[num_radici_n|n 次根]]、[[an_confronto|夹逼例 2]]里的手法同源。

## 第二步：(eₙ) 有上界 3

用[[alg_binomio|二项式定理]]展开 eₙ：

eₙ = (1 + 1/n)ⁿ = Σ_{k=0}^{n} C(n,k)·(1/n)ᵏ = 1 + Σ_{k=1}^{n} C(n,k)/nᵏ。

关键是估计每一项 C(n,k)/nᵏ。把二项式系数写开：

C(n,k)/nᵏ = [n(n−1)(n−2)⋯(n−k+1)] / (k! · nᵏ) = (1/k!)·[ n/n · (n−1)/n · ⋯ · (n−k+1)/n ]。

方括号里是 k 个**不超过 1** 的因子相乘(每个 (n−j)/n ≤ 1),所以整体 ≤ 1/k!。再把阶乘往下压:k! = 1·2·3⋯k ≥ 1·2·2⋯2 = 2^{k−1}(从第二个因子起每个 ≥ 2),故 1/k! ≤ 1/2^{k−1}。合起来：

C(n,k)/nᵏ ≤ 1/k! ≤ 1/2^{k−1}，  1 ≤ k ≤ n。

代回 eₙ 的展开式,并把求和放大成完整的几何级数：

eₙ ≤ 1 + Σ_{k=1}^{n} 1/2^{k−1} = 1 + (1 + 1/2 + 1/4 + ⋯ + 1/2^{n−1})。

括号里是公比 1/2 的有限几何和,等于 (1 − (1/2)ⁿ)/(1 − 1/2) = 2(1 − (1/2)ⁿ) < 2。所以

eₙ < 1 + 2 = 3，  对一切 n。

数列有上界 3。∎ 这一步把每项用「1/k! ≤ 1/2^{k−1}」换成几何级数的项,是处理「阶乘在分母」的标准放缩——以后讨论 e 的级数、指数函数时还会反复用到。

## e 诞生

两步齐备:(eₙ) 递增、有上界 3。由[[an_monotone|单调收敛定理]],极限存在。**定义**

e := lim_{n→∞} (1 + 1/n)ⁿ = sup{ eₙ : n ∈ ℕˣ }。

界也立刻有了:e₁ = (1+1)¹ = 2,而数列递增,所以 e ≥ e₂ = (3/2)² = 9/4 = 2.25 > 2;另一方面每项 eₙ < 3,取极限保号([[an_confronto|序的保持]])得 e ≤ 3。故

2 < e ≤ 3。

注意 e 落在 2 与 3 之间,但数列**收敛得很慢**:e₁₀ ≈ 2.594,e₁₀₀ ≈ 2.705,e₁₀₀₀ ≈ 2.717,到 n = 1000 误差还有约 0.0014。e 的精确值是无理数(甚至超越数,但这些性质的证明属于更后面的内容):

e ≈ 2.71828 18284 59045 …

## 一个收敛快得多的表示

(1+1/n)ⁿ 虽然定义了 e,却不适合实际计算 e 的值——太慢。第二步证明里的估计其实暗示了一个收敛快得多的公式。可以证明(留待级数那部分严格展开):

e = lim_{n→∞} Σ_{k=0}^{n} 1/k! = 1 + 1/1! + 1/2! + 1/3! + 1/4! + ⋯

这个级数收敛极快:取到 1/10! 误差就小于百万分之一。它和第二步里「C(n,k)/nᵏ ≤ 1/k!」的估计是同一个 1/k! ——那个上界,正是这个快速级数的项。两个看似不同的 e 的表示,根子上是连着的;它们相等的严格证明,要等无穷级数的工具,这里先记住结论与联系。

## 一道激活练习

(a) 证明 lim_{n→∞} (1 + 1/n)^{n+1} = e。（提示:把它写成 (1+1/n)ⁿ · (1+1/n),两个因子各求极限,用[[an_algebra_limiti|积法则]];第二个因子 1 + 1/n → 1。）

(b) 证明 lim_{n→∞} (1 − 1/n)ⁿ = 1/e。（提示:(1 − 1/n) = (n−1)/n = 1/(n/(n−1)) = 1/(1 + 1/(n−1))。把整个表达式凑成 1 / (1 + 1/(n−1))ⁿ,再调整指数逼近 e。）

## 参考解答

(建议先自己写完再看。)

**(a)** 直接拆:

(1 + 1/n)^{n+1} = (1 + 1/n)ⁿ · (1 + 1/n)。

第一个因子 → e（e 的定义）;第二个因子 1 + 1/n → 1（1/n → 0 与和法则）。两者都收敛,由[[an_algebra_limiti|积法则]],极限 = e · 1 = **e**。∎（这也说明 (1+1/n)ⁿ 与 (1+1/n)^{n+1} 同极限——前者递增、后者其实递减,从两侧夹住 e。）

**(b)** 改写底数:1 − 1/n = (n−1)/n,取倒数 = n/(n−1) = 1 + 1/(n−1)。所以

(1 − 1/n)ⁿ = 1 / (1 + 1/(n−1))ⁿ = 1 / [ (1 + 1/(n−1))^{n−1} · (1 + 1/(n−1)) ]。

令 m = n−1（n → ∞ 时 m → ∞）:分母 = (1 + 1/m)^m · (1 + 1/m) → e · 1 = e（前者是 e 的定义,后者 → 1,积法则）。故整个表达式 → 1/e。∎

回顾:这两道题都是「把变体凑回标准的 (1+1/m)^m 形状,再用积法则微调指数」。e 的这类变形(指数加减常数、底数取倒数)在以后处理指数函数、复利、连续增长模型时极常见,核心永远是**还原成定义的标准形式**。

## 往前看一步

我们已经能判定单调有界数列收敛,并由此造出了 e。但单调收敛定理有个局限:它只管**单调**数列。很多重要数列并不单调(比如振荡着衰减的),却明显在「收拢」——项与项之间越来越靠近。能不能不依赖「单调」、也不需要事先知道极限,就判定这种数列收敛?答案是 Cauchy 的一个深刻洞察:**一个数列收敛,当且仅当它的项最终彼此任意接近**(Cauchy 列)。这个判据把「收敛」从「需要一个外部的极限点」改写成「数列内部的自我聚拢」,是完备性的又一个等价面孔,也是分析中判定收敛最通用的工具。这就是 [[an_cauchy|Cauchy 列与完备性]] 的内容。
