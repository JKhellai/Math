## 为整体定理准备语言

[[an_continuita|连续函数]]那节结尾预告了两条整体定理——介值定理、最值定理。它们要说的是「连续函数在**整个区间上**的结构性质」,而证明它们需要一套描述「集合形状」的语言:哪些集合是「敞开的」、哪些是「封闭的」、一个集合的「边界」在哪里。这套语言就是**拓扑**(topology)。它从[[an_spazio_metrico|度量空间]]的球出发,却最终能脱离度量、只保留「开集」这一概念——这是现代数学最基础的抽象之一。

## 开集

回忆[[an_spazio_metrico|开球]] B(a, r) = { x : d(x,a) < r }。用它定义「内点」与「开集」:

**定义(内点、开集).** 设 A ⊆ X。点 a ∈ A 称 A 的**内点**(interior point)，若存在 r > 0 使 B(a, r) ⊆ A（a 周围一整个小球都在 A 里）。若 A 的**每个**点都是内点,称 A 为**开集**(open set)。

直觉:开集是「没有边缘、每点都有活动余地」的集合——站在开集里任何一点,都能向四周挪动一点点而不出界。典型例子:ℝ 中的**开区间** (a, b) 是开集(每点左右都留有空隙);而闭区间 [a, b] **不是**开集——端点 a 处,任何小球都会探出到 a 左边、跑出 [a,b]。

**开集的运算——三条公理.** 开集在集合运算下有三条基本性质,它们是整个拓扑的基石:

**命题.** 设 X 是度量空间,𝒯 = { 开集 }。则:
- **(O1)** ∅ 与 X 是开集;
- **(O2)** **任意多个**开集的并仍是开集;
- **(O3)** **有限多个**开集的交仍是开集。

**证明.** (O1) 显然(∅ 无点可验,X 中每点的任何球都在 X 里)。
(O2) 设 x 在并集 ⋃Oα 中,则 x 属于某个 Oα₀;因 Oα₀ 开,有球 B(x,r) ⊆ Oα₀ ⊆ ⋃Oα。故并集每点是内点,是开集。
(O3) 设 x 在有限交 ⋂_{k=0}^n Oₖ 中,则对每个 k 有 rₖ > 0 使 B(x,rₖ) ⊆ Oₖ。取 **r := min(r₀,…,rₙ) > 0**（有限个正数的最小值仍为正),则 B(x,r) 同时含于每个 Oₖ,故含于交集。∎

**关键的不对称:交只能是有限个。** (O3) 里若允许无限交,会失效——因为「取最小 r」对无限个 rₖ 可能得到 r = 0(它们的下确界是 0),就框不住球了。一个反例:

⋂_{n=1}^{∞} B(0, 1/n) = {0}（ℝ 中）,

每个 B(0,1/n) 是开区间(开集),但它们的无限交是单点集 {0}——**不是**开集(0 处没有任何小球留在 {0} 内)。**并无限制、交只限有限**,这个不对称是拓扑的核心特征,务必记住。

## 抽象一步：拓扑空间

三条公理 (O1)–(O3) 里,**只用到集合的并、交,完全没用到距离 d**。这提示一个深刻的抽象:与其从「距离」出发,不如**直接把「哪些集合是开集」当作原始数据**,只要它们满足这三条。

**定义(拓扑空间).** 设 M 是集合,𝒯 ⊆ 𝒫(M) 是 M 的一族子集,满足 (O1)–(O3)(∅、M 属于 𝒯;任意并封闭;有限交封闭)。则称 𝒯 是 M 上的一个**拓扑**(topology)，𝒯 中的元素称**开集**,(M, 𝒯) 称**拓扑空间**(topological space)。

度量空间是拓扑空间的特例——度量诱导出的开集族(称**度量拓扑**)自动满足三条公理。但拓扑空间更一般:有些拓扑空间的开集不来自任何距离。**这是从「度量」到「拓扑」的关键抽象:剥离距离,只保留开集结构。** 许多概念(连续、收敛、紧、连通)其实只依赖开集,不依赖具体距离——用拓扑语言表述它们,更本质也更通用。

> 一个印证:[[an_norme_equivalenti|等价范数]]给出**相同的开集**(当时证过它们邻域相同),从而**相同的拓扑**。所以在 ℝⁿ 上,欧氏、sup、1-范数虽是不同的距离,却诱导**同一个拓扑**——「开集是谁」这件事不依赖你选哪把(等价的)尺。这正说明:拓扑比度量更「上层」,是距离之上不变的结构。

## 闭集

与开集对偶的是闭集——它「包含自己的边缘」。

**定义(闭集).** A ⊆ X 称**闭集**(closed set)，若它的补集 Aᶜ = X \ A 是开集。

由开集三公理取补,立刻得到闭集的对偶三公理(并↔交互换):

**命题.** (C1) ∅、X 是闭集;(C2) **任意多个**闭集的交是闭集;(C3) **有限多个**闭集的并是闭集。(证明:对开集公理取补,用 [[fond_insiemi|De Morgan 律]] 把并变交、交变并。)注意不对称也对偶地翻转:**交无限制、并只限有限**。

**重要警告:开与闭不是非此即彼。** 「不是开集」**不**等于「是闭集」——一个集合可以既不开也不闭,也可以既开又闭。经典例子:ℝ 中的半开区间 **[0, 1) 既不是开集也不是闭集**——它在 0 处不开(0 的左边探出界),在 1 处不闭(1 是它「边缘」却不在集合里,补集在 1 处不开)。而 ∅ 和 X 则既开又闭。

## 闭集的序列刻画：接上收敛理论

闭集有一个用**数列**表述的等价定义——这正是它与第二章[[an_convergenza|收敛理论]]的桥梁,也是实际中判定闭集最常用的方式。

**定理(闭集的序列判据).** A ⊆ X 是闭集 **当且仅当**:A 中任何收敛数列的极限仍在 A 中。即:若 (xₙ) ⊆ A 且 xₙ → x,则 x ∈ A。

**证明.** （⟹）设 A 闭,(xₙ) ⊆ A,xₙ → x。反设 x ∉ A,则 x ∈ Aᶜ,而 Aᶜ 开,故有球 B(x,r) ⊆ Aᶜ。但 xₙ → x 意味着最终 xₙ ∈ B(x,r) ⊆ Aᶜ,与 xₙ ∈ A 矛盾。故 x ∈ A。
（⟸）设 A 含其一切数列极限。要证 Aᶜ 开:任取 x ∈ Aᶜ,反设 x 不是 Aᶜ 内点,则每个球 B(x,1/n) 都碰到 A,取 xₙ ∈ B(x,1/n) ∩ A,则 xₙ → x 且 (xₙ) ⊆ A,由假设 x ∈ A——与 x ∈ Aᶜ 矛盾。故 Aᶜ 开,A 闭。∎

一句话:**闭集 = 对「取极限」封闭的集合**——数列在里面收敛,极限跑不出去。这个刻画极其好用:要证某集合闭,只需验「任取其中收敛数列,极限还在里面」。例如 [a,b] 闭(区间内数列的极限仍满足 a ≤ · ≤ b,由[[an_confronto|极限保序]]);单点集、有限集都闭。

## 内部、闭包、边界

对任意集合 A(不必开也不必闭),可以「修正」出与它最接近的开集和闭集。

**定义.** 
- **内部** int(A):A 中最大的开子集——把 A 「向内削」到开为止(= 所有含于 A 的开集之并,= A 的内点全体)。
- **闭包** cl(A)(或 Ā):包含 A 的最小闭集——把 A 「向外补」到闭为止(= 所有含 A 的闭集之交)。
- **边界** ∂A := cl(A) \ int(A):闭包去掉内部剩下的「壳」。

关系:**int(A) ⊆ A ⊆ cl(A)**,而 ∂A 是二者之差。A 开 ⟺ A = int(A);A 闭 ⟺ A = cl(A)。

**闭包的序列刻画**(呼应上面):x ∈ cl(A) ⟺ 存在 A 中数列 xₙ → x。即闭包 = A 的点,加上「能被 A 中数列逼近的所有极限点」。例:ℝ 中 int((a,b]) = (a,b),cl((a,b]) = [a,b],∂((a,b]) = {a, b}——内部把闭的那端 b 削开,闭包把开的那端 a 补上,边界是两个端点。

这三个概念以后无处不在:闭包描述「一个集合能逼近到哪些点」(稠密性就是 cl = 全空间),内部描述「有活动余地的核心」,边界描述「里外交界」。

## 一道激活练习

(a) 判断 ℝ 中下列集合是开、是闭、既开又闭、还是既不开也不闭:
   ① (0, 1)；② [0, 1]；③ {1/n : n ∈ ℕ×}（不含 0）；④ ℤ（全体整数）；⑤ ℚ（全体有理数）。

(b) 用闭集的**序列判据**证明:ℝ 中集合 A = { x : x ≥ 0 }（非负实数,即 [0,∞)）是闭集。

(c) 求 ℝ 中集合 A = {1/n : n ∈ ℕ×} = {1, 1/2, 1/3, …} 的闭包 cl(A)。(提示:A 中有没有数列收敛到某个不在 A 里的点?)

## 参考解答

(建议先自己写完再看。)

**(a)**
① (0,1) **开**(每点有余地,端点不含);非闭。
② [0,1] **闭**(补集 (−∞,0)∪(1,∞) 开);非开(端点无余地)。
③ {1/n} **既不开也不闭**。不开:每个点 1/n 是孤立点,但单点不含小球(小球会含进别的实数),故非内点——其实它连一个内点都没有,不开。不闭:数列 1/n → 0,但 0 ∉ 该集合,极限跑出去了,由序列判据非闭。
④ ℤ **闭**:任何收敛的整数列最终必为常数(整数间距 ≥ 1,要收敛只能最终不变),极限是那个整数 ∈ ℤ,故闭;非开(整数点无余地)。
⑤ ℚ **既不开也不闭**。不开:任何含有理数的小区间都含无理数,故有理数不是 ℚ 的内点。不闭:无理数可被有理数列逼近([[an_rappresentazioni|无理数是有理数列的极限]]),极限跑出 ℚ,故非闭。

**(b)** 设 (xₙ) ⊆ A（即 xₙ ≥ 0 对所有 n）且 xₙ → x。要证 x ∈ A,即 x ≥ 0。由[[an_confronto|极限保序]]:xₙ ≥ 0 对所有 n,取极限得 x = lim xₙ ≥ 0。故 x ∈ A。由[[an_topologia|序列判据]],A = [0,∞) 是闭集。∎（关键是极限保持「≥ 0」这个闭条件——「≥」在取极限下保持,「>」则不一定,这也是为什么 (0,∞) 不闭而 [0,∞) 闭。)

**(c)** cl(A) = A ∪ {0} = {0, 1, 1/2, 1/3, …}。理由:A 中数列 1/n → 0,故 0 是 A 的极限点,必在闭包里(闭包含 A 的一切数列极限);而 A 的每个点 1/n 是孤立点(附近没有 A 的其它点聚集),不产生新的极限点。所以只需给 A 添上唯一的极限点 0。cl(A) = A ∪ {0}。∎（这也印证 (a)③:A 不闭正因它漏了极限 0;补上 0 后 A ∪ {0} 就闭了。）

回顾:(a) 系统演练开/闭判定——**开看「每点有无余地」,闭看「极限跑不跑得出去」**。③⑤展示「既不开也不闭」的常见情形(有孤立点或稠密但有洞)。(b) 是序列判据的标准用法(闭条件在极限下保持)。(c) 是闭包的典型计算(找出所有「能被逼近但自己不在集合里」的极限点补进去)。**判闭的黄金法则:一个集合闭 ⟺ 它「抓得住」自己所有收敛数列的极限**——这个数列语言的刻画,是连接拓扑与第二章收敛理论的关键。

## 往前看一步

拓扑的基本词汇——开集、闭集、内部、闭包、边界——齐备了,而且都用数列语言接上了第二章。这套语言即将用来刻画连续函数最深刻的两类整体行为所依赖的集合性质。

其中最要紧的是**紧性**(compactness)。ℝ 上的**闭区间 [a,b]** 有一种特殊的「有限性」:它闭且有界,而由此可以推出——**其上的连续函数必有界、必取到最大最小值(最值定理)**,并且[[an_bolzano_weierstrass|Bolzano–Weierstrass]] 保证其中每个数列都有收敛子列(收敛到区间内)。这种性质的抽象,就是紧集。紧性是分析中「化无限为有限」的关键武器,也是最值定理的根基。下一站,我们用刚建立的开集语言,给出紧性的定义(开覆盖有有限子覆盖),并证明它与「闭且有界」在 ℝⁿ 中的等价。这就是 [[an_compattezza|紧性]] 的内容。
