## 给发散数列也配一个「极限」

[[an_sottosuccessioni|聚点]]那节我们见过:发散数列可以有多个聚点,比如 ((−1)ⁿ) 有 +1 和 −1。普通极限对这种数列无能为力——它根本没有极限。但能不能退一步,给**任何**有界实数列都配上两个总是存在的「边界值」:它的项最终在哪个上限以下徘徊、哪个下限以上徘徊?

这就是**上极限**(lim sup)与**下极限**(lim inf)。它们对发散数列也有定义,且**总是存在**(在扩展数轴 ℝ̄ 中)。它们不只是理论上的好奇——下面会看到,**根值判别法、幂级数的收敛半径**都要靠 lim sup 才能精确表述。而它们的存在性,直接来自[[an_monotone|单调收敛定理]]。

## 定义：尾部的 sup 与 inf

想法是:看数列「从第 n 项往后」的上确界和下确界,再让 n → ∞。

**定义.** 设 (xₙ) 是实数列。对每个 n,定义

yₙ := sup_{k≥n} xₖ = sup{ xₙ, xₙ₊₁, xₙ₊₂, … }，  zₙ := inf_{k≥n} xₖ = inf{ xₙ, xₙ₊₁, … }。

（若数列无上界,某个 yₙ 可能是 +∞;这正是要在 ℝ̄ 中工作的原因——[[num_retta_estesa|扩展数轴]]让 sup/inf 对任何集合都有定义。）

**关键观察:这两个新数列是单调的。** 当 n 增大,集合 {xₖ : k ≥ n} 变小(去掉了前面的项),所以它的 sup 只会变小或不变——**(yₙ) 递减**;同理它的 inf 只会变大或不变——**(zₙ) 递增**。

于是由[[an_monotone|单调收敛定理]](在 ℝ̄ 中,递减数列收敛到其下确界,递增收敛到其上确界——[[num_retta_estesa|ℝ̄ 中 sup/inf 无条件存在]]),这两个数列**必定收敛**(可能收敛到 ±∞)。它们的极限就是我们要的对象:

**定义.** 

lim sup_{n→∞} xₙ := lim_{n→∞} yₙ = inf_{n} ( sup_{k≥n} xₖ )，   （上极限 limit superior）

lim inf_{n→∞} xₙ := lim_{n→∞} zₙ = sup_{n} ( inf_{k≥n} xₖ )。   （下极限 limit inferior）

（第二个等号:递减数列 (yₙ) 的极限 = 它的下确界,故 lim sup = inf yₙ;对偶地 lim inf = sup zₙ。）

**核心优势:lim sup 与 lim inf 对任何实数列都存在**(在 ℝ̄ 中)——无论数列收不收敛。普通极限要求项「最终聚到一点」,可能不存在;lim sup/inf 只看尾部的 sup/inf 的走向,这个走向因单调性总有归宿。

## 它们是最大、最小的聚点

lim sup/inf 不是凭空的构造,它们有清晰的意义——正是数列的**极端聚点**。

**定理.** 任何实数列 (xₙ) 在 ℝ̄ 中都有**最大聚点** x* 和**最小聚点** x⁎,且

lim sup xₙ = x*（最大聚点）,   lim inf xₙ = x⁎（最小聚点）。

**证明思路（以 lim sup 为例）.** 记 x* := lim sup xₙ = inf yₙ。要证两件事:**(A) x* 是聚点;(B) 没有比 x* 更大的聚点。**

**(B) 上方无更大聚点:** 取任意 ξ > x*。因 x* = inf yₙ,存在某个 n 使 yₙ < ξ,即 sup_{k≥n} xₖ < ξ,于是 xₖ < ξ 对一切 k ≥ n——ξ 上方(及 ξ 处)只有有限项,故 ξ 不可能是聚点,任何 > x* 的点都不是。

**(A) x* 自己是聚点:** 任取 ε > 0。一方面,刚证 x* + ε 上方只有有限项;另一方面,对每个 n,yₙ = sup_{k≥n} xₖ ≥ x*(因 x* 是这些 yₙ 的下确界),故由[[num_estremo_superiore|上确界刻画]],存在 k ≥ n 使 xₖ > x* − ε。这说明「> x* − ε」的项有无穷多个(每个 n 之后都还有);配上「> x* + ε 的只有限个」,落在 (x* − ε, x* + ε) 里的必有无穷多——x* 是聚点。

两条合起来,x* 是最大的聚点。lim inf 对偶可证。∎

这个定理给了 lim sup/inf 一个一句话的记忆:**lim sup 是数列「最高的聚集高度」,lim inf 是「最低的聚集高度」**。对 ((−1)ⁿ),聚点是 ±1,故 lim sup = 1、lim inf = −1。

## 收敛的判据：lim sup = lim inf

lim sup 与 lim inf 把「收敛」刻画成一个等式——这是它们最重要的用途之一。

**定理.** 实数列 (xₙ) 在 ℝ̄ 中收敛 **当且仅当** lim inf xₙ = lim sup xₙ。此时三者相等,公共值就是极限:

lim xₙ = lim inf xₙ = lim sup xₙ。

**证明.** （⟹）若 xₙ → x,则 x 是**唯一**的聚点([[an_convergenza|收敛唯一]]+[[an_sottosuccessioni|极限是唯一聚点]])。而 lim sup、lim inf 都是聚点,夹在最大与最小之间又只有这一个,故 lim inf = lim sup = x。

（⟸）若 lim inf = lim sup = x,则最大聚点与最小聚点重合,数列只有 x 一个聚点。再由「x* + ε 上方有限项、x⁎ − ε 下方有限项」(两个极端聚点给出的双向控制),每个 x 的邻域 (x − ε, x + ε) 都含几乎所有项——这正是 xₙ → x。∎

直觉:**lim sup 与 lim inf 是数列尾部上下振荡的「上下包络线」**;它们重合,意味着上下包络挤成一条线,数列被夹着收敛;它们分开(如 ±1),意味着尾部在两个高度间持续振荡,数列发散。「收敛 ⟺ 上下极限相等」把收敛性变成了一个**可计算的等式判据**,无需事先猜测极限。

## 为什么要费这个劲

lim sup/inf 看着比普通极限繁琐,但它有两个不可替代的价值:

其一,**它对任何数列都存在**,所以可以无条件地谈论、放进不等式、用于估计——哪怕数列发散。许多定理的最干净表述用的是 lim sup 而非 lim。

其二,**它是根值判别法与幂级数收敛半径的精确语言**。后面会看到,级数 Σaₖ 的「根值判别」要算 lim sup ⁿ√|aₖ|;幂级数 Σcₖxᵏ 的收敛半径由 Cauchy–Hadamard 公式 1/R = lim sup ⁿ√|cₖ| 给出。这里的 lim sup **不能换成 lim**——因为 ⁿ√|cₖ| 这个数列一般不收敛,只有 lim sup 总存在。这是我们现在补上 lim sup 的直接原因:它是通往幂级数的必经一站。

## 一道激活练习

求下列数列的 lim sup 与 lim inf（在 ℝ̄ 中）:

(a) xₙ = (−1)ⁿ · n/(n+1)；
(b) xₙ = n^{(−1)ⁿ}（即 n 的 (−1)ⁿ 次方:n 为奇数时是 1/n,偶数时是 n）；
(c) xₙ = (−1)ⁿ + (−1)^{⌊n/2⌋}（提示:算出前 8 项,找出它在哪几个值间循环,最大最小者即 lim sup/inf）。

## 参考解答

(建议先自己写完再看。)

**(a)** xₙ = (−1)ⁿ·n/(n+1)。偶子列 x_{2k} = 2k/(2k+1) → 1;奇子列 x_{2k+1} = −(2k+1)/(2k+2) → −1。这两个是仅有的聚点,故 **lim sup = 1,lim inf = −1**。（注意每个 |xₙ| < 1,数列从未达到 ±1,但聚点不要求达到,只要无穷逼近。）

**(b)** xₙ = n^{(−1)ⁿ}。奇数项 x_{2k+1} = 1/(2k+1) → 0;偶数项 x_{2k} = 2k → ∞。偶数项无界,故尾部 sup 恒为 ∞:**lim sup = +∞**。最小聚点:奇数项 → 0,而偶数项跑向 +∞ 不贡献小聚点,故 **lim inf = 0**。

**(c)** 算前 8 项(⌊n/2⌋ 是下取整):
n=1: (−1)+(−1)⁰=−1+1=0;n=2: 1+(−1)¹=1−1=0;n=3: −1+(−1)¹=−1−1=−2;n=4: 1+(−1)²=1+1=2;n=5: −1+(−1)²=−1+1=0;n=6: 1+(−1)³=1−1=0;n=7: −1+(−1)³=−2;n=8: 1+(−1)⁴=2。
循环值为 0, 0, −2, 2, 0, 0, −2, 2, …——取值集合 {−2, 0, 2},每个出现无穷多次,都是聚点。故 **lim sup = 2,lim inf = −2**。

回顾:求 lim sup/inf 的通用办法,正是[[an_sottosuccessioni|求聚点]]那套——**按奇偶或周期拆子列,各看趋向**,然后 lim sup = 最大聚点、lim inf = 最小聚点。无界要用 ℝ̄:某方向无界则该方向的极限是 ±∞。本质上,lim sup/inf 把「找出所有聚点、取最大/最小」这件事,变成了一个有定义、可计算的标准量。

## 往前看一步

上下极限补齐了实数列收敛理论里最后一块结构性工具:现在每个数列都有一对总是存在的极端聚点,收敛被刻画成「上下极限相等」,而 lim sup 还将成为根值判别法的语言。

下一步回到[[an_serie|级数]],建立一批**收敛判别法**——不求值、只判敛散。核心概念是**绝对收敛**:若 Σ|aₖ| 收敛,则 Σaₖ 收敛(且性质更好)。由它派生出**比较判别法**(和已知级数比大小)、**根值判别法**(算 lim sup ⁿ√|aₖ|,这里 lim sup 正式上岗)与**比值判别法**(看 |aₖ₊₁/aₖ|)。这些判别法将让我们判定绝大多数级数的敛散,并最终引向**指数函数**的级数定义。这就是 [[an_convergenza_assoluta|绝对收敛与判别法]] 的内容。
