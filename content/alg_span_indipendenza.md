## 用少数向量生成整个空间

[[alg_sottospazi|子空间]]那节末尾留了个问题:一个向量空间到底有「多大」?回答它的钥匙,是看**用少数几个向量,通过加法和数乘,能生成出多少向量**。这就引出线性代数最核心的两个概念:**张成**与**线性无关**。

先把「用加法和数乘组合向量」这件事命名。

**定义(线性组合).** 设 v₁, …, vₘ 是 V 中的向量。形如

a₁v₁ + a₂v₂ + ⋯ + aₘvₘ   （a₁, …, aₘ ∈ 𝕂）

的向量,称这组向量的一个**线性组合**(linear combination)。

线性组合就是「各向量乘上标量后加起来」——向量空间允许的唯一一种「混合」方式。比如在 ℝ³ 中,(17,−4,2) = 6·(2,1,−3) + 5·(1,−2,4),所以它是后两个向量的一个线性组合。

## 张成：所有线性组合的全体

**定义(张成).** 一组向量 v₁, …, vₘ 的**全体**线性组合构成的集合,称它们的**张成**(span)，记

span(v₁, …, vₘ) := { a₁v₁ + ⋯ + aₘvₘ : a₁, …, aₘ ∈ 𝕂 }。

(空组的张成约定为 {0}。)

张成不只是一个集合——它**就是一个[[alg_sottospazi|子空间]]**,而且是含这组向量的最小子空间。

**命题.** span(v₁, …, vₘ) 是 V 的子空间,且是包含 v₁,…,vₘ 的**最小**子空间。

**证明.** 验[[alg_sottospazi|三条判据]]:含零(取全部系数为 0:0 = 0·v₁+⋯+0·vₘ);加法封闭(两个线性组合相加,对应系数相加,仍是线性组合);数乘封闭(线性组合乘标量 λ,各系数乘 λ,仍是线性组合)。故是子空间。**最小性**:每个 vₖ 本身是线性组合(它那项系数取 1、其余取 0),故都在 span 里;反过来,任何包含全部 vₖ 的子空间,由[[alg_sottospazi|对线性组合封闭]],必包含它们的一切线性组合,即包含整个 span。故 span 最小。∎

这个命题把「张成」和「子空间」接上了:**张成是「由几个向量生成子空间」的标准方式**。几何上,span 一个非零向量得过原点的直线,span 两个不共线的向量得过原点的平面——

注意图 3:v 和 2v 共线,加进 2v **并不能张成更多**——它已经在 span(v) 里。这个「冗余」现象,正是下面「线性无关」要刻画的。

**定义(张成空间 / 有限维).** 若 span(v₁,…,vₘ) = V,称这组向量**张成** V。**若 V 能被某个有限组向量张成,称 V 是有限维**(finite-dimensional)的;否则称无限维。

例:𝕂ⁿ 由 n 个「标准向量」e₁=(1,0,…,0), …, eₙ=(0,…,0,1) 张成(任何 (x₁,…,xₙ) = x₁e₁+⋯+xₙeₙ),故 **𝕂ⁿ 是有限维的**。而全体多项式 𝕂[X] 是无限维的(任何有限组多项式有最高次数,张不出更高次的)。

## 线性无关：没有冗余

图 3 显示,有些向量是「多余」的——加进去不扩大张成,因为它能被别的向量线性组合出来。「没有这种冗余」的组,称线性无关。

**定义(线性无关 / 线性相关).** 一组向量 v₁, …, vₘ 称**线性无关**(linearly independent)，若使

a₁v₁ + ⋯ + aₘvₘ = 0

成立的标量,**只有**全零这一种(a₁ = ⋯ = aₘ = 0)。否则(即存在不全为零的标量使线性组合为零)称**线性相关**(linearly dependent)。(空组约定为线性无关。)

直觉:线性相关意味着「这些向量之间有一个非平凡的零关系」——某种带非零系数的组合恰好抵消成零。比如 2·(2,3,1) + 3·(1,−1,2) + (−1)·(7,3,8) = (0,0,0),系数 2,3,−1 不全为零,故这三个向量线性相关。而 v 与 2v 相关:2·v + (−1)·(2v) = 0。

线性无关有一个极其重要的等价刻画,它解释了为什么「无关」是个好性质:

**命题(无关 ⟺ 表示唯一).** v₁,…,vₘ 线性无关 ⟺ span 中**每个**向量写成 a₁v₁+⋯+aₘvₘ 的方式**唯一**。

**证明.** 设无关。若某向量有两种表示 Σaᵢvᵢ = Σbᵢvᵢ,相减得 Σ(aᵢ−bᵢ)vᵢ = 0;由无关,所有 aᵢ−bᵢ = 0,即 aᵢ = bᵢ,两种表示相同。反之设表示唯一,则 0 的表示唯一;而 0 = Σ0·vᵢ 是一种,故这是**唯一**一种,即 Σaᵢvᵢ=0 只有全零解——无关。∎

**这就是线性无关的价值:它保证「坐标」有意义。** 若一组向量无关,span 里每个向量都有**唯一**的一串系数 (a₁,…,aₘ)——这串系数就是该向量「在这组向量下的坐标」。相关的话,坐标不唯一(同一向量有多种系数表示),「坐标」就失去意义。这条直接通向「基」的概念。

几个有用的小事实(都可由定义直接验证):
- 单个向量无关 ⟺ 它非零;
- 两个向量无关 ⟺ 谁都不是另一个的标量倍(即不共线);
- **含零向量的组必相关**(零向量那项取任意非零系数、其余取零,即得非平凡零关系);
- 无关组**去掉**若干向量,剩下的仍无关(零关系更难成立)。

## 线性相关引理：冗余可以精确定位并删除

线性相关只说「存在冗余」,下面这条引理把冗余**精确定位**——指出到底哪个向量是多余的,并说明删掉它不损失张成。它是后面证「基」「维数」的核心工具。

**引理(线性相关引理).** 设 v₁,…,vₘ 线性相关。则存在某个下标 k ∈ {1,…,m},使得

(i) **vₖ ∈ span(v₁, …, v_{k−1})**（第 k 个向量是它前面那些向量的线性组合）;

(ii) 把 vₖ 从组中删去后,**剩下组的张成不变**:span(去掉vₖ) = span(v₁,…,vₘ)。

**证明.** （i）由相关,存在不全为零的 a₁,…,aₘ 使 Σaᵢvᵢ = 0。设 k 是**最大**的、使 aₖ ≠ 0 的下标。则 aₖ₊₁=⋯=aₘ=0(更大的系数都为零),于是

a₁v₁ + ⋯ + aₖvₖ = 0，  aₖ ≠ 0。

解出 vₖ = −(a₁/aₖ)v₁ − ⋯ − (a_{k−1}/aₖ)v_{k−1}(可除,因 aₖ≠0 且 𝕂 是[[alg_campi|域]])——vₖ 是前面向量的线性组合,即 vₖ ∈ span(v₁,…,v_{k−1})。

（ii）要证删掉 vₖ 张成不变。任取原 span 中的向量,它是 v₁,…,vₘ 的线性组合;把其中的 vₖ 用 (i) 的表达式替换成 v₁,…,v_{k−1} 的组合,就得到一个**不含 vₖ** 的线性组合。故每个原 span 中的向量都能由剩下的向量组合出,张成不变。∎

引理的用法,一句话:**一组向量若相关,总能扔掉一个而不改变它张成的空间**——反复扔,直到无关为止,张成始终不变。这正是从「张成组」提炼出「基」(既张成、又无关的最小组)的机制,下一节就用它。

> 留意 (i) 说的是 vₖ 在**前面**向量的张成里,不是「某个向量在其余向量张成里」的笼统说法——「前面」这个顺序信息,是让「删除」干净进行的关键(删掉的是「第一个变得多余」的向量)。

## 一道激活练习

(a) 判断 ℝ³ 中下列向量组是否线性无关;相关的话,写出一个非平凡的零关系(不全为零的系数使组合为零):
   ① (1,0,0), (0,1,0), (0,0,1)；
   ② (1,2,3), (4,5,6), (7,8,9)（提示:试 (1)·第一个 + (−2)·第二个 + (1)·第三个）；
   ③ (1,1,0), (0,1,1)。

(b) 证明:在 𝕂[X] 中,1, X, X², …, Xⁿ 线性无关。(提示:a₀·1 + a₁X + ⋯ + aₙXⁿ = 0 作为多项式,意味着它在所有取值处为零,系数必须全为零——多项式恒为零当且仅当各系数为零。)

(c) 设 v₁,v₂,v₃ 线性无关。证明 v₁, v₁+v₂, v₁+v₂+v₃ 也线性无关。(提示:设 a(v₁)+b(v₁+v₂)+c(v₁+v₂+v₃)=0,展开按 v₁,v₂,v₃ 归并系数,用 v₁,v₂,v₃ 无关推出 a=b=c=0。)

## 参考解答

(建议先自己写完再看。)

**(a)**
① **无关**:a(1,0,0)+b(0,1,0)+c(0,0,1) = (a,b,c) = (0,0,0) 直接给 a=b=c=0。(这是 ℝ³ 的标准向量,典型的无关组。)

② **相关**:验证 1·(1,2,3) + (−2)·(4,5,6) + 1·(7,8,9) = (1−8+7, 2−10+8, 3−12+9) = (0,0,0)。系数 (1,−2,1) 不全为零,故相关。一个非平凡零关系即 (1,2,3) − 2(4,5,6) + (7,8,9) = 0。

③ **无关**:a(1,1,0)+b(0,1,1) = (a, a+b, b) = (0,0,0) 要求 a=0、b=0(由第一、三分量),故只有全零解。无关。

**(b)** 设 a₀ + a₁X + ⋯ + aₙXⁿ = 0(零多项式)。零多项式的每个系数都是 0,故 a₀ = a₁ = ⋯ = aₙ = 0。所以只有全零系数使组合为零,1,X,…,Xⁿ 无关。∎(这说明 𝕂[X] 里有任意长的无关组,印证它是无限维的。)

**(c)** 设 a·v₁ + b·(v₁+v₂) + c·(v₁+v₂+v₃) = 0。按 v₁,v₂,v₃ 归并:

(a+b+c)·v₁ + (b+c)·v₂ + c·v₃ = 0。

由 v₁,v₂,v₃ **无关**,三个系数全为零:a+b+c=0、b+c=0、c=0。从最后一式 c=0,代入第二式 b=0,代入第一式 a=0。故 a=b=c=0,所证组线性无关。∎

回顾:判线性无关的标准动作是**令线性组合等于零,解出系数,看是否被迫全为零**——(a) 直接读分量,(c) 先按原无关组归并再解。(c) 还示范了一个常见技巧:**用已知无关组的「系数必须全零」当作推理引擎**,把新组的无关性归结到旧组上。这种「把新问题化归到已知无关组」的手法,在以后处理基变换时极常用。

## 往前看一步

两个概念到手:**张成**(能生成多少)与**线性无关**(有没有冗余)。它们指向同一个目标的两面——我们想要一组向量,**既能张成整个空间(不太少)、又线性无关(不冗余)**。这样的「恰到好处」的向量组称为**基**(basis):它是张成空间的最小组,也是无关组里最大的;空间里每个向量在基下都有唯一坐标。而一个空间的基所含向量的个数,是一个不依赖于基的选择的数——这个数就是**维数**(dimension),终于精确回答了「向量空间有多大」。这就是 [[alg_base_dimensione|基与维数]] 的内容。
