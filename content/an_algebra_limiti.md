## 不再逐个回到定义

[[an_convergenza|收敛]]有了精确定义,但我们目前只会**逐个**验证:每证一个极限,都要回到 ε–N、手动找 N。算 lim (n+1)/(n+2) 这种式子时,这太笨重了。

这一节建立**运算法则**:若 xₙ → a、yₙ → b,则它们的和、数乘、积、商的极限,就是 a、b 的和、数乘、积、商。有了它们,复杂数列的极限可以像代数式一样**逐步拆开算**,只在最底层用一次基本极限(通常是 1/n → 0)。这是分析从「逐个验证」转向「成套计算」的关键一步。

所有法则在 ℝ 和 [[alg_complessi|ℂ]] 上同时成立(用 K 统称二者),证明只依赖[[an_valore_assoluto|绝对值/模]]的三条性质。

## 零数列:把收敛问题归零

先引入一个简化工具。

**定义.** K 中收敛到 0 的数列称**零数列**(null sequence)。即:对每个 ε > 0,存在 N 使 n ≥ N 时 |xₙ| < ε。

零数列之所以好用,是因为**任何收敛问题都能平移成零数列问题**:

**命题(平移).** xₙ → a 当且仅当 (xₙ − a) 是零数列。

**证明.** 两者的 ε–N 条件逐字相同:|xₙ − a| < ε 既是「xₙ → a」的定义,也是「xₙ − a → 0」的定义。∎

所以「证 xₙ → a」永远可以改成「证 xₙ − a → 0」。下面证积、商法则时,这个改写是核心技巧——把「逼近 ab」拆解成若干个「逼近 0」的零数列之和。零数列还有一条立刻要用的小性质:**若实数零数列 (rₙ) 满足 |xₙ| ≤ rₙ(几乎所有 n),则 (xₙ) 也是零数列**(被一个趋于 0 的东西压住,自己也趋于 0;由 |xₙ| ≤ rₙ < ε 即得)。

## 和与数乘

最简单的两条,直接由三角不等式得到。

**命题.** 设 xₙ → a，yₙ → b，α ∈ K。则 (i) xₙ + yₙ → a + b；(ii) α·xₙ → α·a。

**证明.** (i) 给定 ε > 0。因 xₙ → a,存在 M 使 n ≥ M 时 |xₙ − a| < ε/2；因 yₙ → b,存在 N 使 n ≥ N 时 |yₙ − b| < ε/2。则对 n ≥ max(M, N):

|(xₙ + yₙ) − (a + b)| = |(xₙ − a) + (yₙ − b)| ≤ |xₙ − a| + |yₙ − b| < ε/2 + ε/2 = ε。

故 xₙ + yₙ → a + b。

(ii) α = 0 时显然。设 α ≠ 0,给定 ε > 0,取 N 使 n ≥ N 时 |xₙ − a| < ε/|α|；则 |α·xₙ − α·a| = |α|·|xₙ − a| < |α|·(ε/|α|) = ε。∎

(i) 的证明里藏着一个标准技巧:**目标精度 ε,拆成两份 ε/2 分给两个数列**。每个数列各自逼近到 ε/2,合起来三角不等式正好凑成 ε。下图把它画出来:

由此(取 α = −1 再用 (i))还顺带得到**差**的法则:xₙ − yₙ → a − b。和、差、数乘三条合起来说明:**收敛数列对线性运算封闭,且取极限是线性的**——lim(αxₙ + βyₙ) = α·lim xₙ + β·lim yₙ。

## 积:一个关键引理 + 拆项

积的法则比和难,因为 xₙyₙ − ab 不能直接拆成两个小量。先备一个引理,它本身极常用。

**引理(零 × 有界 = 零).** 若 (xₙ) 是零数列,(yₙ) 有界,则 (xₙyₙ) 是零数列。

**证明.** (yₙ) 有界,存在 M > 0 使 |yₙ| ≤ M 对一切 n。给定 ε > 0,因 xₙ → 0,存在 N 使 n ≥ N 时 |xₙ| < ε/M。则

|xₙyₙ| = |xₙ|·|yₙ| < (ε/M)·M = ε，  n ≥ N。

故 xₙyₙ → 0。∎

注意「有界」这个条件**不能去掉**:取 xₙ = 1/n(零数列)、yₙ = n²(无界),则 xₙyₙ = n 发散。有界性是这条引理的命脉——它保证那个「不趋于 0 的因子」至少不会爆炸,从而被趋于 0 的因子压住。

**命题(积).** 若 xₙ → a、yₙ → b,则 xₙyₙ → ab。

**证明.** 用[[an_valore_assoluto|绝对值]]那节练习里的**加减同一项**手法,把 xₙyₙ − ab 拆成两个零数列之和:

xₙyₙ − ab = xₙyₙ − a·yₙ + a·yₙ − ab = (xₙ − a)·yₙ + a·(yₙ − b)。

逐项分析:(xₙ − a) 是零数列(因 xₙ → a),而 (yₙ) 收敛故[[an_convergenza|有界]],由引理 (xₙ − a)·yₙ 是零数列;(yₙ − b) 是零数列,a 是常数(有界),a·(yₙ − b) 也是零数列。两个零数列之和仍是零数列(和法则),所以 xₙyₙ − ab → 0,即 xₙyₙ → ab。∎

这个证明是[[an_valore_assoluto|绝对值]]那节那道练习的精确重演——当时我们估计 |xy − ab| 用的就是「加减 ay、拆成 (x−a)y + a(y−b)」。那时是静态的不等式,现在每一项都成了零数列,「拆项」直接兑现成「拆成零数列之和」。**静态估计技巧,在极限里全部复活。**

## 商:先把分母从 0 拉开

商的法则要先处理倒数,而倒数的麻烦在于分母可能趋于 0 附近——得先保证它**离 0 有一段安全距离**。

**命题(倒数).** 设 xₙ → a,且 a ≠ 0。则几乎所有 xₙ ≠ 0,且 1/xₙ → 1/a。

**证明.** 第一步,把 xₙ 从 0 拉开。因 |a| > 0,取 ε = |a|/2:存在 N 使 n ≥ N 时 |xₙ − a| < |a|/2。由[[an_valore_assoluto|反向三角不等式]],

|a| − |xₙ| ≤ |xₙ − a| < |a|/2，  故 |xₙ| > |a|/2 > 0，  n ≥ N。

所以从第 N 项起,xₙ 都非零(可取倒数),而且模有统一下界 |a|/2——分母**离 0 至少 |a|/2 远**,这正是控制 1/xₙ 的关键。

第二步,估计 1/xₙ − 1/a。通分:

|1/xₙ − 1/a| = |a − xₙ| / (|xₙ|·|a|) ≤ |xₙ − a| / ((|a|/2)·|a|) = (2/|a|²)·|xₙ − a|，  n ≥ N。

右边是常数 2/|a|² 乘以零数列 |xₙ − a|,故是零数列;由「被零数列压住」,|1/xₙ − 1/a| → 0,即 1/xₙ → 1/a。∎

第一步「把分母从 0 拉开」是全证的要害:没有 |xₙ| ≥ |a|/2 这个下界,通分后的分母 |xₙ||a| 可能趋于 0,整个估计失控。反向三角不等式在这里正好派上用场——它把「xₙ 接近 a」翻译成「|xₙ| 接近 |a|」,从而保证分母不塌。

**推论(商).** 若 xₙ → a、yₙ → b,且 b ≠ 0,则 xₙ/yₙ → a/b。

**证明.** xₙ/yₙ = xₙ·(1/yₙ)。由倒数法则 1/yₙ → 1/b,再由积法则 xₙ·(1/yₙ) → a·(1/b) = a/b。∎

商法则不必单独硬证——它是「倒数 + 积」的组合。这也体现了运算法则的威力:一旦基本几条立住,新法则就能由旧法则拼出来,不必每次回到 ε–N。

## 法则如何省力：一个例子

现在回头算开头那个 lim (n+1)/(n+2),看法则怎样把它拆开。把分子分母同除以 n:

(n+1)/(n+2) = (1 + 1/n) / (1 + 2/n)。

分子:1 + 1/n。常数列 1 → 1(例),1/n → 0(阿基米德),由和法则 1 + 1/n → 1。
分母:1 + 2/n。同理,2/n = 2·(1/n) → 2·0 = 0(数乘),故 1 + 2/n → 1。
分母极限 1 ≠ 0,由商法则:

lim (n+1)/(n+2) = (lim 分子)/(lim 分母) = 1/1 = 1。

整个计算没有出现一次 ε 或 N——全部回到一个基本极限 1/n → 0,其余由法则逐层拼装。**这就是运算法则的意义:把「找 N」的力气,一次性封装进基本极限,此后只做代数。**

## 一道激活练习

用运算法则(不直接用 ε–N)计算下列极限,每步注明用了哪条法则:

(a) lim (3n² − n + 1) / (2n² + 5)；
(b) lim ( (n+1)/(n+2) + (2n)/(n+3) )；
(c) lim ( (1 + i/n)·(2 − 1/n) )（复数列;i 是虚数单位）。

（提示:(a) 分子分母同除以 n²,把每项化成常数加 c/nᵏ 形状。(c) 用积法则,分别求两个因子的极限。）

## 参考解答

(建议先自己写完再看。)

**(a)** 分子分母同除以 n²:

(3n²−n+1)/(2n²+5) = (3 − 1/n + 1/n²) / (2 + 5/n²)。

分子:1/n → 0(阿基米德),1/n² = (1/n)(1/n) → 0·0 = 0(积法则),故 3 − 1/n + 1/n² → 3 − 0 + 0 = 3(和与数乘)。分母:5/n² → 5·0 = 0,故 2 + 5/n² → 2。分母极限 2 ≠ 0,商法则给 **lim = 3/2**。

**(b)** 由 (a) 同型计算:(n+1)/(n+2) = (1+1/n)/(1+2/n) → 1（正文已算）;(2n)/(n+3) = 2/(1+3/n) → 2/1 = 2。两个收敛数列之和,由和法则:**lim = 1 + 2 = 3**。

**(c)** 第一个因子 1 + i/n:i/n = i·(1/n) → i·0 = 0(数乘,α = i),故 1 + i/n → 1。第二个因子 2 − 1/n → 2 − 0 = 2。两者都收敛,由积法则:**lim = 1·2 = 2**。

回顾:三道题的统一套路是**把每个数列化简成「常数 + 趋于 0 的项」,再用和/数乘/积/商法则逐层组合**,最底层只用 1/n → 0。注意法则的使用顺序:总是先算清每个「零件」的极限(常数、1/n、1/n² …),再往上拼;商法则用前务必确认分母极限非零。

## 往前看一步

运算法则让我们能算出大量极限,但它们对**实数列**还漏掉了一件重要的事:序与极限的关系。如果 xₙ ≤ yₙ 对所有 n 成立,它们的极限之间有 lim xₙ ≤ lim yₙ 吗?更有用的是反过来——若一个数列被两个**收敛到同一极限**的数列上下夹住,它是否也被迫收敛到那个极限?这就是**夹逼定理**(squeeze theorem),实分析里求极限最锋利的工具之一,尤其当数列复杂到无法用运算法则拆解时。它依赖 ℝ 的序结构,因而是实数列特有的。这就是 [[an_confronto|夹逼定理与极限的序]] 的内容。
