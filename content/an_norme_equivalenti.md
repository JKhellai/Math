## 同一个空间，不同的「长度尺」

[[an_norma|范数]]那节见过:同一个向量空间可以配不同的范数——ℝ² 上有[[an_prodotto_interno|欧氏范数]] ‖x‖ = √(x₁²+x₂²)，也有[[an_norma|曼哈顿范数]] ‖x‖₁ = |x₁|+|x₂|，还有 sup 范数 ‖x‖∞ = max(|x₁|,|x₂|)。它们给出的「长度」数值不同,单位球形状也不同(圆、菱形、方形)。

一个自然的问题:**换一把范数尺,分析会不会变?** 比如「收敛」「聚点」这些概念,用欧氏范数和用 sup 范数定义,得到的结果一样吗?这一节回答它——对一大类范数(「等价」的),答案是**完全一样**。这件事有个重要的实际收获:它让 ℝᵐ 中的收敛**化归为各坐标分量的收敛**,把多维问题拆成一维问题。

## 等价范数

**定义(等价).** 向量空间 E 上的两个[[an_norma|范数]] ‖·‖₁ 和 ‖·‖₂ 称**等价**(equivalent)，若存在常数 K ≥ 1,使

(1/K)·‖x‖₁ ≤ ‖x‖₂ ≤ K·‖x‖₁，  对一切 x ∈ E。

记 ‖·‖₁ ∼ ‖·‖₂。

直观:两个范数等价,意味着它们「相差不超过一个固定的倍数」——一个范数大,另一个也大,谁也不会比对方大得离谱或小得离谱。它们度量长度的「尺度」是可比的。(可验证 ∼ 是范数集合上的一个[[fond_equivalenza|等价关系]]:自反、对称、传递都直接从定义得到。)

## ℝᵐ 上的三个范数两两等价

最重要的例子:𝕂ᵐ 上常用的三个范数互相等价。先回忆它们(对 x = (x₁,…,xₘ)):

- 欧氏范数 ‖x‖ = √(Σ|xⱼ|²)（[[an_prodotto_interno|内积诱导]]）;
- 1-范数 ‖x‖₁ = Σ|xⱼ|（各分量绝对值之和）;
- sup 范数 ‖x‖∞ = max_{1≤j≤m} |xⱼ|（最大分量绝对值）。

**命题.** 在 𝕂ᵐ 上,以下不等式成立(对一切 x):

‖x‖∞ ≤ ‖x‖ ≤ √m·‖x‖∞，   (1/√m)·‖x‖₁ ≤ ‖x‖ ≤ ‖x‖₁。

因此三个范数**两两等价**。

**证明.** 设 M := max|xⱼ| = ‖x‖∞。
- **‖x‖∞ ≤ ‖x‖**:某个 |xₖ| = M,而 ‖x‖² = Σ|xⱼ|² ≥ |xₖ|² = M²,开方得 ‖x‖ ≥ M。
- **‖x‖ ≤ √m·‖x‖∞**:Σ|xⱼ|² ≤ Σ M² = m·M²,开方 ‖x‖ ≤ √m·M。
- **‖x‖ ≤ ‖x‖₁**:Σ|xⱼ|² ≤ (Σ|xⱼ|)²（平方和 ≤ 和的平方,因交叉项非负）,开方即得。
- **(1/√m)‖x‖₁ ≤ ‖x‖**:这正是[[an_prodotto_interno|Cauchy–Schwarz]]——取 (|x₁|,…,|xₘ|) 与 (1,…,1) 作内积:‖x‖₁ = Σ|xⱼ|·1 ≤ √(Σ|xⱼ|²)·√(Σ1²) = ‖x‖·√m。移项即得。

所以欧氏范数被 sup 范数和 1-范数从两侧夹住(乘上 √m 这类常数),三者两两等价。∎

## 等价范数给出相同的收敛

等价为什么要紧?因为**它保证了拓扑概念(邻域、收敛、聚点)不变**。

**命题.** 设 ‖·‖₁ ∼ ‖·‖₂ 是 E 上两个等价范数。则它们给出**相同的邻域**:对每个点 a,「a 的邻域」这个集合在两个范数下完全一样。从而**收敛、聚点等概念在等价范数下不变**。

**证明思路.** 由等价,(1/K)‖·‖₁ ≤ ‖·‖₂ ≤ K‖·‖₁。这意味着一个范数的小球总能塞进另一个范数的球里(半径按 K 缩放):‖·‖₂ 下的球 B₂(a, r) 包含 ‖·‖₁ 下的球 B₁(a, r/K),反之亦然。所以「含某个 ‖·‖₁-球」与「含某个 ‖·‖₂-球」是一回事——[[an_spazio_metrico|邻域]]的集合相同。而[[an_convergenza|收敛]]「xₙ→a ⟺ a 的每个邻域含几乎所有项」只依赖邻域,故收敛性在两范数下一致;聚点同理。∎

一句话:**等价范数是「同一种收敛的不同度量方式」**。换一把等价的范数尺,长度的数值会变,但「谁趋于谁」「哪些点是聚点」这些定性结论丝毫不变。所以在 ℝᵐ 上,谈论收敛时用欧氏、sup 还是 1-范数,**结果完全相同**——可以挑最方便的那个用。(顺带:[[alg_complessi|ℂᵐ]] 与 ℝ²ᵐ 在这个意义下也可认同,谈邻域、收敛时二者无区别。)

## 积空间的收敛：按分量收敛

把上面用到 ℝᵐ 上,得到一个极其实用的结论——它把多维收敛拆成一维收敛。

**定理(按分量收敛).** 设 xₙ = (xₙ¹, …, xₙᵐ) ∈ 𝕂ᵐ。则以下等价:

(i) 序列 (xₙ) 在 𝕂ᵐ 中收敛到 x = (x¹, …, xᵐ);

(ii) **对每个** k ∈ {1,…,m},分量序列 (xₙᵏ) 在 𝕂 中收敛到 xᵏ。

**证明.** 因所有范数等价,用最方便的 **sup 范数** 判收敛。注意

‖xₙ − x‖∞ = max_{1≤k≤m} |xₙᵏ − xᵏ|。

「‖xₙ − x‖∞ → 0」(即 xₙ → x)⟺「max_k |xₙᵏ − xᵏ| → 0」⟺ **每个** |xₙᵏ − xᵏ| → 0(最大值趋零当且仅当每一项都趋零)⟺ 每个分量 xₙᵏ → xᵏ。∎

这条定理把「ℝᵐ(或 ℂᵐ)中向量序列的收敛」**完全化归为各坐标分量的收敛**——多维收敛 = 各分量分别收敛,称**按分量收敛**(componentwise convergence)。它的实用价值极大:研究 ℝᵐ 中的极限,原则上只需研究 ℝ 中的极限,逐坐标处理即可。([[an_succ_complesse|复数列]]那节对 ℂ = ℝ² 做的「实部虚部分别收敛」,正是这条定理 m=1（ℂ 视作 ℝ²）的特例;现在推广到任意维。)

> 一句提醒:这是把多维**收敛**问题降到一维,但并非说多维分析「不过是一维的堆叠」。许多多维现象(方向、连通、紧性的几何)无法靠逐坐标看清。按分量收敛是个有用的工具,不是说多维分析可被一维取代。

## 一道激活练习

(a) 在 ℝ² 上验证:‖(3, 4)‖ = 5（欧氏）、‖(3,4)‖₁ = 7、‖(3,4)‖∞ = 4。检查命题中的不等式 ‖x‖∞ ≤ ‖x‖ ≤ √2·‖x‖∞ 与 (1/√2)‖x‖₁ ≤ ‖x‖ ≤ ‖x‖₁ 对此 x 成立。

(b) 用按分量收敛判断:𝕂² 中序列 xₙ = (1/n, (1 + 1/n)ⁿ) 是否收敛?若是,极限是什么?

(c) 证明:若 xₙ → x 且 yₙ → y 在 ℝᵐ 中,则 xₙ + yₙ → x + y。(提示:可以用按分量收敛,把它降到 ℝ 中各分量的[[an_algebra_limiti|和的极限]];或直接用范数三角不等式——两种都行,体会「降维」与「直接」两条路。)

## 参考解答

(建议先自己写完再看。)

**(a)** ‖(3,4)‖ = √(9+16) = √25 = 5;‖(3,4)‖₁ = 3+4 = 7;‖(3,4)‖∞ = max(3,4) = 4。检查:
- ‖x‖∞ = 4 ≤ 5 = ‖x‖ ✓;‖x‖ = 5 ≤ √2·4 ≈ 5.66 ✓。
- (1/√2)·7 ≈ 4.95 ≤ 5 = ‖x‖ ✓;‖x‖ = 5 ≤ 7 = ‖x‖₁ ✓。
全部成立。

**(b)** 用按分量收敛,逐坐标看:第一分量 1/n → 0（[[num_archimede|阿基米德]]）;第二分量 (1+1/n)ⁿ → e（[[an_numero_e|欧拉数]]）。两个分量都收敛,故 (xₙ) **收敛**,极限 = **(0, e)**。

**(c)** **方法一(降维)**:由按分量收敛,xₙ→x 即每个分量 xₙᵏ→xᵏ,yₙ→y 即 yₙᵏ→yᵏ。则各分量 xₙᵏ+yₙᵏ → xᵏ+yᵏ（ℝ 中[[an_algebra_limiti|和的极限]]）,即 (xₙ+yₙ) 的每个分量收敛到 (x+y) 的对应分量,故 xₙ+yₙ → x+y。
**方法二(直接)**:‖(xₙ+yₙ)−(x+y)‖ = ‖(xₙ−x)+(yₙ−y)‖ ≤ ‖xₙ−x‖+‖yₙ−y‖（三角不等式）→ 0+0 = 0,故收敛。∎

回顾:(b)(c) 都体现按分量收敛的威力——**多维收敛逐坐标验证即可**,每个坐标用熟悉的一维结论。(c) 的两种方法对照有意思:方法一把问题「降维」到 ℝ、复用一维定理;方法二「直接」用范数的三角不等式(在任何[[an_norma|赋范空间]]通用,不限于 ℝᵐ)。降维法直观、依赖坐标结构;直接法普适、不依赖维数。两条路都通,体现了等价范数带来的灵活性。

## 往前看一步

等价范数与按分量收敛补齐了 ℝᵐ 上的收敛理论:无论用哪把(等价的)范数尺,收敛性一致,而且多维收敛可逐坐标验证。这把欧氏空间的极限理论收拾得干净利落,为多元分析备好了又一块基础。

接下来回到级数,补完[[an_convergenza_assoluta|绝对收敛]]留下的深层主题:**绝对收敛的级数,可以任意重排而和不变**(重排定理),还可以处理**二重级数**(双下标求和)与两个级数的**Cauchy 乘积**。这些都是「绝对收敛」这个性质的深层回报——它让无穷求和获得了有限求和那样的自由(交换、结合、相乘),而条件收敛则没有这种自由。这就是 [[an_riordinamenti|重排、二重级数与 Cauchy 乘积]] 的内容。
