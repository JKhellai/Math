## 把「长度」装回向量空间

[[alg_base_dimensione|向量空间]]的内在结构(子空间、基、维数)已经理清,但它仍然很「素」:只有加法和数乘,**没有「长度」**。我们能说「两个向量相加」,却还不能说「这个向量有多长」——而长度,是把分析(极限、距离、收敛)接到向量空间上的桥。这一节补上它。

动机来自最熟悉的 ℝ²。平面上一个向量 x,有一个**长度** ‖x‖(从原点到 x 的距离);两点 x, y 之间的距离就是 ‖x − y‖。这个「长度」函数有三条朴素性质:

- **非负,且只有零向量长度为零**;
- **伸缩 α 倍,长度变 |α| 倍**:‖αx‖ = |α|·‖x‖(α 可正可负,负的话方向反转但长度只看绝对值);
- **三角不等式**:‖x + y‖ ≤ ‖x‖ + ‖y‖(两边之和不短于第三边)。

把这三条抽出来当公理,就得到一般向量空间上的「长度」——**范数**。注意这三条**全都见过**:它们正是[[an_valore_assoluto|绝对值]] |·| 在 ℝ 上满足的性质!范数就是把绝对值「能度量长度」这件事,从数推广到了向量。

## 定义

设 E 是 𝕂 上的[[alg_spazio_vettoriale|向量空间]]。函数 ‖·‖ : E → ℝ₊（取非负实数值）称 E 上的一个**范数**(norm)，若满足:

- **(N1)** ‖x‖ = 0 ⟺ x = 0（正定性）;
- **(N2)** ‖λx‖ = |λ|·‖x‖,对一切 x ∈ E, λ ∈ 𝕂（正齐次性 positive homogeneity）;
- **(N3)** ‖x + y‖ ≤ ‖x‖ + ‖y‖,对一切 x, y ∈ E（三角不等式）。

配了范数的向量空间 (E, ‖·‖) 称**赋范向量空间**(normed vector space)。‖x‖ 读作 x 的**范数**或**长度**。

(N2) 取 λ = −1 给 ‖−x‖ = ‖x‖（反向不改长度）;取 λ = 0 配 (N1) 给 ‖0‖ = 0。这些都符合「长度」的直觉。

## 核心：范数诱导一个度量

范数最重要的性质,是它**自动给出一个[[an_spazio_metrico|度量]]**——把「长度」变成「距离」,从而让整个极限理论在向量空间上生效。

**定理.** 设 (E, ‖·‖) 是赋范向量空间。则

d(x, y) := ‖x − y‖

是 E 上的一个[[an_spazio_metrico|度量]]。于是**每个赋范向量空间自动是度量空间**。

**证明.** 逐条验度量公理 (M1)–(M3):
- **(M1)** d(x,y) = 0 ⟺ ‖x−y‖ = 0 ⟺ x−y = 0（由 (N1)）⟺ x = y。✓
- **(M2)** d(x,y) = ‖x−y‖ = ‖(−1)(y−x)‖ = |−1|·‖y−x‖（由 (N2)）= ‖y−x‖ = d(y,x)。✓ 对称性来自正齐次。
- **(M3)** 把范数的三角不等式 (N3) 用在 (x−z) + (z−y) = x−y 上:

  d(x,y) = ‖x−y‖ = ‖(x−z)+(z−y)‖ ≤ ‖x−z‖ + ‖z−y‖ = d(x,z) + d(z,y)。✓

三条齐备,d 是度量。∎

这条定理是这一节的枢纽:**它把代数(向量空间 + 范数)和分析(度量空间)接通了**。一旦有了范数,[[an_spazio_metrico|度量空间]]那节建立的一切——开球、邻域、[[an_convergenza|收敛]]、[[an_cauchy|Cauchy 列]]——立刻在 E 上有定义。特别地,向量序列的收敛就是

xₙ → x 在 E 中 ⟺ ‖xₙ − x‖ → 0，

即「向量与极限的距离(范数)趋于 0」。而[[an_algebra_limiti|运算法则]]中**凡不依赖 𝕂 的乘法或序的部分**(如和、数乘的极限)也自动成立——因为它们的证明只用到三角不等式。

> 这正是[[an_spazio_metrico|度量空间]]那节预告而当时无法严格给出的方向:把「距离」装到向量空间上。绝对值给了 ℝ 一个度量(那是一维的范数);现在范数给了任意向量空间一个度量。ℝⁿ 的欧氏距离是其中最重要的一例——但它的范数从哪来、为什么满足三角不等式,要靠下一节的「内积」回答。

**反向三角不等式**也随之成立(证明与[[an_valore_assoluto|绝对值]]、[[an_spazio_metrico|度量]]那两节一字不差):

‖x − y‖ ≥ | ‖x‖ − ‖y‖ |。

它把诱导度量的[[an_spazio_metrico|反向三角不等式]]翻译回范数语言,用处一致:估计「两个向量长度之差」。

## 球与有界

有了诱导度量,[[an_spazio_metrico|球]]的概念照搬:开球 B(a, r) = { x ∈ E : ‖x − a‖ < r }。特别地**单位球** B = { x : ‖x‖ < 1 }(到原点距离 < 1 的向量)。范数的全部信息其实都编码在单位球的「形状」里——不同范数对应不同形状的单位球(圆、方、菱形……),这是泛函分析里的重要视角,这里先记住概念。

子集 X ⊆ E 称**有界**,若它在诱导度量下[[an_convergenza|有界]],等价地:存在 r 使 ‖x‖ < r 对一切 x ∈ X(所有向量长度被同一个 r 框住）。

## 例子

**(a) 绝对值是 𝕂 上的范数.** 在一维向量空间 𝕂 上,‖x‖ := |x|（[[an_valore_assoluto|绝对值]]/[[alg_complessi|模]]）满足三条——这正是它当初满足的性质。所以 ℝ、ℂ 作为一维赋范空间,诱导的度量就是 d(x,y)=|x−y|,回到[[an_spazio_metrico|最初的例子]]。范数是绝对值的高维推广,这一例确认了「一维情形退化回绝对值」。

**(b) 上确界范数.** 设 X 是非空集合,B(X) 是 X 上**有界**函数构成的[[alg_spazio_vettoriale|向量空间]]。定义 ‖f‖_∞ := sup_{t∈X} |f(t)|（函数的「最大绝对值」）。可验证它是范数(三条都来自绝对值的对应性质 + sup 的性质)。这个「上确界范数」把两个函数的距离定义为「它们差的最大幅度」——是函数空间上最常用的范数之一,一致收敛理论(分析后续)的核心就是它诱导的度量。

(ℝⁿ 上的欧氏范数 ‖x‖ = √(Σxᵢ²) 是最重要的例子,但它满足三角不等式需要 Cauchy–Schwarz,留待下一节。)

## 一道激活练习

(a) 在 ℝ² 上定义 ‖(x, y)‖₁ := |x| + |y|（两个坐标绝对值之和,称「曼哈顿范数」/出租车范数）。验证它满足范数三公理 (N1)–(N3)。

(b) 设 (E, ‖·‖) 是赋范空间,xₙ → x 且 yₙ → y（在 E 中）。证明 xₙ + yₙ → x + y。(提示:估计 ‖(xₙ+yₙ)−(x+y)‖,用三角不等式拆成 ‖xₙ−x‖ + ‖yₙ−y‖;这正是[[an_algebra_limiti|和的极限]]在赋范空间里的版本——注意证明只用到 (N3),不碰 𝕂 的乘法。)

(c) 证明:在赋范空间中,若 xₙ → x,则 ‖xₙ‖ → ‖x‖（范数是「连续」的）。(提示:用反向三角不等式。)

## 参考解答

(建议先自己写完再看。)

**(a)** 设 (x,y), (x',y') ∈ ℝ²,λ ∈ ℝ。
**(N1)** ‖(x,y)‖₁ = |x|+|y| = 0 ⟺ |x|=0 且 |y|=0（两非负数之和为零则各为零）⟺ x=y=0 ⟺ (x,y)=0。✓
**(N2)** ‖λ(x,y)‖₁ = ‖(λx,λy)‖₁ = |λx|+|λy| = |λ||x|+|λ||y| = |λ|(|x|+|y|) = |λ|·‖(x,y)‖₁。✓（用绝对值的[[an_valore_assoluto|可乘性]]。）
**(N3)** ‖(x,y)+(x',y')‖₁ = |x+x'|+|y+y'| ≤ (|x|+|x'|)+(|y|+|y'|)（对每个坐标用绝对值三角不等式）= (|x|+|y|)+(|x'|+|y'|) = ‖(x,y)‖₁+‖(x',y')‖₁。✓ 故 ‖·‖₁ 是范数。∎

**(b)** 给定 ε > 0。因 xₙ→x,存在 N₁ 使 n≥N₁ 时 ‖xₙ−x‖ < ε/2;因 yₙ→y,存在 N₂ 使 n≥N₂ 时 ‖yₙ−y‖ < ε/2。则 n ≥ max(N₁,N₂) 时:

‖(xₙ+yₙ)−(x+y)‖ = ‖(xₙ−x)+(yₙ−y)‖ ≤ ‖xₙ−x‖ + ‖yₙ−y‖ < ε/2+ε/2 = ε（用 (N3)）。

故 xₙ+yₙ → x+y。∎（与[[an_algebra_limiti|实数列和法则]]证明结构完全相同,只把 |·| 换成 ‖·‖——因为只用到三角不等式,在任何赋范空间通用。）

**(c)** 由反向三角不等式,| ‖xₙ‖ − ‖x‖ | ≤ ‖xₙ − x‖。给定 ε>0,因 xₙ→x 取 N 使 n≥N 时 ‖xₙ−x‖<ε,则同样 n≥N 时 | ‖xₙ‖−‖x‖ | ≤ ‖xₙ−x‖ < ε。故 ‖xₙ‖ → ‖x‖。∎

回顾:这三题都印证同一件事——**赋范空间里的分析,本质是「把绝对值换成范数」后照搬实数列的论证**,只要原证明不依赖 𝕂 的乘法或序(即只用到三角不等式和齐次性)。(a) 验范数走「三公理逐条核对」标准流程;(b)(c) 则展示「实数列的极限定理,凡不碰乘法/序的,在赋范空间一字通用」。这是范数诱导度量带来的红利:一套分析,处处适用。

## 往前看一步

范数把「长度」和「距离」装进了向量空间,赋范空间自动成为度量空间,极限理论随之生效。但范数只给了**长度**,还没给**角度**——我们仍不能说「两个向量是否垂直」「它们的夹角是多少」。而几何里「垂直」「投影」「勾股定理」都离不开角度。

补上角度的,是一个更强的结构:**内积**(inner product)。在 ℝⁿ 上,内积就是熟悉的点积 ⟨x, y⟩ = Σxᵢyᵢ;由它能定义夹角(通过 cos θ),也能**诱导出范数** ‖x‖ = √⟨x, x⟩。而内积满足的一条关键不等式——**Cauchy–Schwarz** |⟨x,y⟩| ≤ ‖x‖‖y‖——恰恰保证这个诱导范数满足三角不等式 (N3)。于是链条闭合:**内积 → 范数 → 度量**,而欧氏空间 ℝⁿ 终于成为一个有长度、有角度、有距离的完整[[an_spazio_metrico|度量空间]]。这就是 [[an_prodotto_interno|内积与欧氏空间]] 的内容,也是我们在分析主干里一直推迟的欧氏 ℝⁿ 的终点站。
