## 把「无限相加」定义清楚

「1 + 1/2 + 1/4 + 1/8 + ⋯ 等于 2」——这种无穷多个数相加的说法,直觉上人人会用,但严格说来,「无限相加」是什么意思?加法是二元运算,一次只能加两个数;「加无穷多次」并非加法的定义内容,需要重新界定。

界定的办法,正是[[an_cauchy|数列极限]]:不去「一次加完」,而是**逐项累加,看累加的结果趋于什么**。先加前一项、前两项、前三项……得到一串「部分和」,这串部分和若收敛,它的极限就定义为那个「无穷和」。于是「无限相加」被化归成了「一个特殊数列的极限」——而数列极限我们已经彻底掌握。

**定义(级数).** 设 (aₖ) 是 K(= ℝ 或 ℂ,或更一般的 Banach 空间)中的数列。定义新数列 (sₙ):

sₙ := Σ_{k=0}^{n} aₖ = a₀ + a₁ + ⋯ + aₙ。

这个**部分和数列** (sₙ) 称一个**级数**(series)，记作 Σaₖ;sₙ 称第 n 个**部分和**(partial sum),aₖ 称第 k 个**项**(summand)。

换句话说,**级数就是它的部分和数列**——一个由递归 s₀ = a₀、sₙ₊₁ = sₙ + aₙ₊₁ 定义的数列([[num_ricorsione|递归定义]]的又一个实例)。

**定义(收敛与值).** 级数 Σaₖ **收敛**,若部分和数列 (sₙ) 收敛;此时 (sₙ) 的极限称级数的**值**,记

Σ_{k=0}^{∞} aₖ := lim_{n→∞} sₙ。

若 (sₙ) 发散,则称级数**发散**。

要紧的是分清两个对象:**项的数列 (aₖ)** 和**部分和数列 (sₙ)**。级数的收敛说的是**后者**——是累加的结果在收拢,不是项本身。记号 Σ_{k=0}^∞ aₖ 既指这个级数,又(在收敛时)指它的值,靠上下文区分。

## 收敛的必要条件：项趋于 0

第一条判据,简单却常用——它给出一个**排除发散**的快速检验。

**命题.** 若级数 Σaₖ 收敛,则 (aₖ) 是零数列(aₖ → 0)。

**证明.** Σaₖ 收敛即部分和 (sₙ) 收敛,由[[an_cauchy|收敛 ⟹ Cauchy]],(sₙ) 是 Cauchy 列:对每个 ε > 0,存在 N 使 m, n ≥ N 时 |sₙ − sₘ| < ε。特别取相邻两项,n ≥ N 时

|aₙ₊₁| = |sₙ₊₁ − sₙ| < ε。

故 aₙ → 0。∎

这条的用法是**逆否**:**若项不趋于 0,级数必发散**。例如 Σ(−1)ᵏ 的项在 ±1 间跳、不趋于 0,立即判定发散,不必算部分和。这是判断级数发散最快的一招——先看项是否趋于 0,不趋于就完了。

但**反过来不成立**:项趋于 0 **不**保证级数收敛。这正是下面调和级数要揭示的——也是[[an_cauchy|上一节练习]]埋下的伏笔。

## 调和级数：项趋于 0 却发散

**例.** 调和级数 Σ 1/k(即 1 + 1/2 + 1/3 + 1/4 + ⋯)发散。

它的项 1/k → 0,满足必要条件;若必要条件也充分,它就该收敛。但它不收敛——证明用 [[an_cauchy|Cauchy 判据]] 的反面:找到「任意远处仍不靠近」的两段部分和。

**证明.** 看从第 n+1 项到第 2n 项这一段的和(即 s_{2n} − sₙ):

s_{2n} − sₙ = Σ_{k=n+1}^{2n} 1/k = 1/(n+1) + 1/(n+2) + ⋯ + 1/(2n)。

这是 n 个加项,每一项都 ≥ 最小的那个 1/(2n)。所以

s_{2n} − sₙ ≥ n · 1/(2n) = 1/2，  对一切 n ≥ 1。

于是无论 N 多大,总能取 m = N、n = 2N,使 |s_{2n} − sₙ| ≥ 1/2 —— 部分和数列**不是 Cauchy 列**(它不满足「任意远的两项任意接近」,差永远顶着 1/2)。由[[an_cauchy|Cauchy 判据]],(sₙ) 发散,即调和级数发散。∎

这正还上了[[an_cauchy|上一节练习 (b)]]的账:相邻差 1/(n+1) → 0 不足以收敛,因为 Cauchy 要求的是**任意远两项之距**小,而调和级数里「跨度为 n 的一段」其和顶着 1/2 不降——相邻虽近,成段累积起来仍不收拢。**「项趋于 0」是收敛的必要条件,绝非充分**,调和级数是这件事最经典的反例。

## 几何级数：第一个能求和的级数

与调和级数相反,几何级数不仅收敛,还能算出确切的值——它是最基本、用得最多的级数。

**例(几何级数).** 设 a ∈ K。当 |a| < 1 时,Σaᵏ 收敛且

Σ_{k=0}^{∞} aᵏ = 1/(1 − a)。

当 |a| ≥ 1 时,Σaᵏ 发散。

**证明.** 关键是部分和有**封闭公式**。对 a ≠ 1,由[[alg_binomio|有限几何和]](可由 (1−a)(1+a+⋯+aⁿ) = 1−aⁿ⁺¹ 直接验证):

sₙ = Σ_{k=0}^{n} aᵏ = (1 − aⁿ⁺¹)/(1 − a)。

**|a| < 1 时**:[[an_monotone|几何数列]] aⁿ⁺¹ → 0,故由[[an_algebra_limiti|运算法则]]

sₙ = (1 − aⁿ⁺¹)/(1 − a) → (1 − 0)/(1 − a) = 1/(1 − a)。

**|a| ≥ 1 时**:|aᵏ| = |a|ᵏ ≥ 1,项不趋于 0,由必要条件级数发散。∎

把它和开头的例子对上:a = 1/2 时,Σ(1/2)ᵏ = 1/(1 − 1/2) = 2——这正是「1 + 1/2 + 1/4 + ⋯ = 2」的严格证明。那个直觉的等式,如今是几何级数公式的一个特例。

## 级数的线性

级数既是特殊的数列,数列的[[an_algebra_limiti|运算法则]]就直接适用——尤其是线性。

**命题.** 设 Σaₖ、Σbₖ 收敛,α ∈ K。则 Σ(aₖ + bₖ) 与 Σ(αaₖ) 收敛,且

Σ(aₖ + bₖ) = Σaₖ + Σbₖ，  Σ(αaₖ) = α·Σaₖ。

**证明.** 设 Σaₖ 的部分和 sₙ → s,Σbₖ 的部分和 tₙ → t。则 Σ(aₖ+bₖ) 的部分和恰是 sₙ + tₙ(有限和可重排),由[[an_algebra_limiti|和法则]] → s + t;Σ(αaₖ) 的部分和是 αsₙ → αs。∎ （注意:这只对**收敛**级数成立。两个发散级数逐项相加可能收敛,不能乱用。）

## 两个收敛的例子

**例 1:e = Σ 1/k!。** [[an_numero_e|欧拉数 e]]那节提过,e 还有一个收敛快得多的表示。现在能说清它是一个级数:Σ 1/k! 的部分和

sₙ = 1 + 1/1! + 1/2! + ⋯ + 1/n!

递增(每项为正),且有上界——由[[an_numero_e|e 的有界性证明]]里同样的估计,1/k! ≤ 1/2^{k−1},故 sₙ ≤ 1 + Σ(1/2)^{k−1} < 3。递增有上界,由[[an_monotone|单调收敛]]级数收敛。它的值正是 e(与 (1+1/n)ⁿ 同极限,严格证明需要更多工具,这里记住结论)。**e = Σ_{k=0}^∞ 1/k!** ——这个级数收敛极快,是实际计算 e 的标准方法。

**例 2:Σ 1/k² 收敛。** 部分和 sₙ = Σ_{k=1}^n 1/k² 递增。用一个**伸缩**(telescoping)技巧估上界:对 k ≥ 2,1/k² ≤ 1/(k(k−1)) = 1/(k−1) − 1/k。于是

sₙ ≤ 1 + Σ_{k=2}^{n} (1/(k−1) − 1/k) = 1 + (1 − 1/n) < 2，

中间那个和**逐项相消**(伸缩),只剩首尾。所以 (sₙ) 递增有上界 2,由[[an_monotone|单调收敛]]级数收敛。（它的值是 π²/6,著名的 Basel 问题,但求出这个值要等更深的工具;收敛性这里已经够了。）这个例子和调和级数恰成对照:1/k 发散、1/k² 收敛——**项趋于 0 的速度决定成败**,1/k 降得太慢,1/k² 够快。

## 一道激活练习

(a) 求 Σ_{k=0}^∞ (2/3)ᵏ 和 Σ_{k=1}^∞ (1/5)ᵏ 的值（注意第二个从 k=1 起）。

(b) 用「项趋于 0」判据说明 Σ k/(k+1) 发散。

(c) 用伸缩法求 Σ_{k=1}^∞ 1/(k(k+1)) 的值（提示:1/(k(k+1)) = 1/k − 1/(k+1),写出部分和 sₙ 看它消成什么,再取极限）。

## 参考解答

(建议先自己写完再看。)

**(a)** 第一个:几何级数 a = 2/3,|a| < 1,从 k=0 起,值 = 1/(1 − 2/3) = 1/(1/3) = **3**。
第二个:a = 1/5,但从 k=1 起,缺了 k=0 的项(=1)。整条(从 0 起)= 1/(1 − 1/5) = 5/4;减去 k=0 项 1,得 Σ_{k≥1} = 5/4 − 1 = **1/4**。（或直接:首项 1/5、公比 1/5 的几何级数,值 = 首项/(1−公比) = (1/5)/(4/5) = 1/4。）

**(b)** 项 aₖ = k/(k+1) = 1/(1 + 1/k) → 1/(1+0) = 1 ≠ 0。项不趋于 0,由必要条件的逆否,级数 **发散**。

**(c)** 用 1/(k(k+1)) = 1/k − 1/(k+1) 写部分和:

sₙ = Σ_{k=1}^{n} (1/k − 1/(k+1)) = (1 − 1/2) + (1/2 − 1/3) + ⋯ + (1/n − 1/(n+1))。

中间项全部相消(伸缩),只剩 sₙ = 1 − 1/(n+1)。取极限:sₙ → 1 − 0 = **1**。故 Σ_{k=1}^∞ 1/(k(k+1)) = 1。∎

回顾:(a) 是几何级数的直接套用,要点是看清「从哪一项起」(起点不同,要补/减开头的项)。(c) 是伸缩法的典型——**把每项拆成「相邻两个量之差」,部分和便首尾相消、只剩两端**,取极限即得。伸缩与几何级数,是少数几种能算出**确切值**的级数;大多数级数我们只能判断「收不收敛」而求不出值,那正是下面收敛判别法要解决的。

## 往前看一步

级数的框架立起来了:它是部分和数列,收敛性归结为数列极限,而我们已有的全部工具(Cauchy 判据、单调收敛、运算法则)都能用上。但目前能**求出值**的只有几何级数和伸缩级数寥寥几类;绝大多数级数,我们关心的不是「等于多少」,而是更基本的「**收不收敛**」。为此需要一批**收敛判别法**(convergence tests):不必算出部分和,仅凭项 aₖ 的大小或比值,就能判定级数敛散。其中最常用的是**比较判别法**(和已知级数比大小)、**比值判别法**与**根值判别法**(看相邻项之比或项的方根)。它们的根基,是一个把级数收敛性大大简化的概念——**绝对收敛**。这就是分析的下一站:级数的收敛判别法。
