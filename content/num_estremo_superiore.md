## 把「缺口」说严格

上一节证明了:ℚ 处处稠密,却没有平方等于 2 的数。我们当时把这件事叫做「缺口」——但这还只是比喻。一条处处稠密的数轴,「缺了一个点」到底是什么意思?稠密性说任意两点之间还有第三点,似乎哪里都不空;可 √2 该在的位置,确实没有 ℚ 的成员。要把这种「看不见的空」说清楚,得换一套语言:不谈某个具体的点在不在,而谈一个**集合的边界**——它有没有「天花板」,众多天花板里有没有「最低的那一个」。这套语言一旦建立,「缺口」就从感觉变成一条可以证明的命题,而 ℝ 与 ℚ 的根本差别也将由它一句话点明。

本节在任意**有序域** K 中展开(ℚ 是我们眼下唯一的具体样本,但定义和大部分定理只用到有序域的公理,将来对 ℝ 原样适用)。

## 上界与下界

**定义.** 设 A ⊆ K 是一个子集,b ∈ K。若 ∀a ∈ A, a ≤ b,称 b 是 A 的一个**上界**(upper bound),并称 A **有上界**(或称在上方有界)。对称地,若 ∀a ∈ A, c ≤ a,称 c 是 A 的**下界**(lower bound)。

两点立刻要注意。其一,上界**不必属于 A**:区间 {x ∈ ℚ : 0 ≤ x < 1} 的上界可以是 1、2、100,没有一个在集合里。其二,上界**一旦存在就成群**:若 b 是上界,任何 b′ ≥ b 也是上界(传递性)。所以问「A 的上界是什么」没有唯一答案;有意义的问题是:**这一整族上界里,有没有最小的一个?**

## 最大元未必有,但「最小上界」可能有

先厘清一个近邻概念,免得混淆。

**定义.** 若 b ∈ A 且 b 是 A 的上界,称 b 是 A 的**最大元**(maximum),记 max A。

最大元是「集合内部最靠上的成员」。它未必存在——而且不存在是常态:取

A := { x ∈ ℚ : 0 ≤ x < 1 }。

A 没有最大元。证明:反设 m = max A,则 m ∈ A,故 0 ≤ m < 1;但由稠密性,m 与 1 之间还有 m′ = (m+1)/2,满足 m < m′ < 1,即 m′ ∈ A 且 m′ > m,与 m 是最大元矛盾。∎ 直觉上,A 一路逼近 1 却永不到达,「最靠上的成员」根本不存在——边界 1 站在集合外面。

可是注意:1 虽不在 A 里,它却显然是 A 的上界,而且**是最小的那个上界**——任何 b < 1 都拦不住 A(同样由稠密性,b 与 1 之间有 A 的成员越过 b)。于是「集合内部没有最靠上的成员」与「集合外部有一个最贴身的上界」可以并存。后者正是我们要的概念。

**定义(上确界).** 设 A ⊆ K 有上界。若 s ∈ K 同时满足

- **(S1)** s 是 A 的上界:∀a ∈ A, a ≤ s;
- **(S2)** s 是最小的上界:对 A 的任何上界 b,都有 s ≤ b,

则称 s 是 A 的**上确界**(supremum,最小上界 least upper bound),记 sup A。

对称地定义**下确界**(infimum,最大下界),记 inf A。

**上确界若存在则唯一。** 设 s、s′ 都满足 (S1)(S2)。s′ 是上界,由 s 的 (S2) 得 s ≤ s′;s 是上界,由 s′ 的 (S2) 得 s′ ≤ s;反对称,s = s′。∎ 唯一性使记号 sup A 合法——这与此前 ∃! 给记号发资格的逻辑一致。

回到上例:1 是 A 的上确界。它满足 (S1)(刚验过是上界),也满足 (S2)(任何更小的数都不是上界)。**A 没有最大元,却有上确界**——max 与 sup 的区别就在这里:sup 不要求自己属于集合。当 max A 存在时,它必等于 sup A(留作练习的一部分);但 sup 能在 max 缺席时仍然存在,这正是它更有用的原因。

## 一条好用的刻画

(S2) 说「比 s 小的都不是上界」,把它正面展开,得到一条日后反复使用的判据:

**命题(上确界的 ε-刻画).** 设 s 是 A 的上界。则 s = sup A 当且仅当:**对任意 ε > 0,存在 a ∈ A 使 a > s − ε。**

**证明.** (⟸)设右条件成立,验 (S2)。任取上界 b,往证 s ≤ b。反设 b < s,令 ε := s − b > 0,由条件存在 a ∈ A 使 a > s − ε = b——这说明 b 拦不住 a,b 不是上界,矛盾。故 s ≤ b。(⟹)设 s = sup A,任取 ε > 0。则 s − ε < s,由 (S2) 的最小性,s − ε 不是上界(否则有比 s 小的上界),即存在 a ∈ A 使 a > s − ε。∎

这条刻画的用处:它把「最小上界」这个比较性的概念,换成了一个**构造性**的判据——只要能在 s 下方任意近处抓到集合的成员,s 就是上确界。下面立刻用到它。

## 核心定理:ℚ 里有界集可以没有上确界

现在把上一节的 √2∉ℚ 改写成一句关于上确界的话。考虑

A := { q ∈ ℚ : q > 0 且 q² < 2 }。

**定理.** A 在 ℚ 中有上界,但在 ℚ 中**没有上确界**。

直观上,A 是「正有理数里平方还没超过 2 的那些」,它在数轴上一路逼近本该是 √2 的位置;而那个位置没有 ℚ 的点,于是「最贴身的上界」在 ℚ 中无处可寻。下面把这点严格化。

**A 有上界.** 断言 2 是上界。设 q ∈ A,则 q > 0 且 q² < 2。若 q > 2,则 q² > 2·2 = 4 > 2(乘正保序),矛盾;故 q ≤ 2。所以 2 是 A 的上界,A 有上界。(A 也非空:1 ∈ A,因 1² = 1 < 2。)

**关键引理:夹缝里总能再进一步,也总能再退一步。** 这是整个证明的核心,它说明 A 的上界永远「不够贴身」。

> 设 q ∈ ℚ, q > 0。
> (i) 若 q² < 2,则存在 ℚ 中的 δ > 0 使 (q + δ)² < 2——**A 中的数总能再变大一点而不出界**;
> (ii) 若 q² > 2,则存在 ℚ 中的 δ > 0 使 (q − δ)² > 2 且 q − δ > 0——**平方超过 2 的上界总能再缩小一点,仍是上界**。

**证明 (i).** 想让 (q+δ)² = q² + 2qδ + δ² 仍小于 2。先把 δ 限制在 0 < δ ≤ 1,则 δ² ≤ δ,于是

(q + δ)² = q² + 2qδ + δ² ≤ q² + 2qδ + δ = q² + (2q + 1)δ。

要它 < 2,只需 (2q+1)δ < 2 − q²。因 q² < 2,右边 2 − q² > 0;而 2q + 1 > 0。取

δ := min( 1, (2 − q²)/(2(2q+1)) )

(两个正有理数取较小者,仍是正有理数;ℚ 全序保证 min 有定义)。则 δ ≤ 1 且 (2q+1)δ ≤ (2−q²)/2 < 2 − q²,代入上式得 (q+δ)² < 2。∎

**证明 (ii).** 想让 (q−δ)² = q² − 2qδ + δ² 仍大于 2。直接丢掉非负的 δ²:(q−δ)² ≥ q² − 2qδ。要它 > 2,只需 q² − 2qδ > 2,即 δ < (q²−2)/(2q)。因 q² > 2,右边为正;取 δ := min( q/2, (q²−2)/(4q) ),则 δ > 0、δ < (q²−2)/(2q) 给出 (q−δ)² > 2,且 δ ≤ q/2 < q 保证 q − δ > 0。∎

**没有上确界.** 反设 s := sup A 存在于 ℚ。s 是上界且 ≥ 1 > 0(因 1 ∈ A,故 s ≥ 1)。由上一节,s² ≠ 2(没有有理数平方等于 2)。于是由 ℚ 的全序,s² < 2 或 s² > 2,两条都通向矛盾:

- 若 s² < 2:由引理 (i),存在 δ > 0 使 (s+δ)² < 2,即 s + δ ∈ A。但 s + δ > s,与「s 是上界」矛盾。
- 若 s² > 2:由引理 (ii),存在 δ > 0 使 (s−δ)² > 2 且 s−δ > 0。此时 s − δ 也是 A 的上界——因为任何 a ∈ A 有 a² < 2 < (s−δ)²,而 a, s−δ 均正,由乘正保序的逆(同号且平方更小则本身更小)得 a < s − δ。于是 s − δ 是一个比 s **更小**的上界,与 s 的最小性 (S2) 矛盾。

两种情形俱矛盾,故 ℚ 中不存在 sup A。∎

把它与上一节并读:那里说「ℚ 里没有平方为 2 的数」,这里说「ℚ 里有一个有界非空集合没有上确界」。**同一道缺口,后者是它的纯序版本**——不提平方、不提 √2,只用「有界」「上确界」这些序的词汇,就把空隙指了出来。这正是我们要的语言:它不依赖任何具体的代数方程,因而能用来**刻画**「数轴有没有洞」这件事本身。

## ℝ 的使命,一句话锁定

ℚ 的全部毛病,现在浓缩成一句话:**它有有界非空的子集,却没有上确界。** 反过来,我们对 ℝ 的全部要求,也就锁定成这句话的否定——

> **(完备性公理 / 上确界公理)** 每一个非空、有上界的子集,都有上确界。

满足这条公理的有序域,称**完备有序域**(complete ordered field)。下一阶段的任务因此变得无比清晰:**造一个完备有序域**,并验证它确实把 ℚ 的洞全部填上。届时 A = {q>0 : q²<2} 将真的拥有上确界,那个上确界就是 √2——它终于在 ℝ 中获得定义,落到数轴上本该属于它的位置。

填洞有两条经典路线:**Dedekind 分割**——把每个实数定义成「数轴在某处的一刀切」,缺口处那一刀切出的正是新数;以及**Cauchy 列的完备化**——把实数定义成「步步逼近却在 ℚ 中无处落脚的序列」的极限。两条路殊途同归,造出的完备有序域本质唯一。我们将走 Dedekind 的路,因为它把本节的「上确界」直接变成构造的主角。

## 一道激活练习

设 A ⊆ K 非空有上界,在有序域 K 中。

(a) 证明:若 max A 存在,则 sup A 存在且 sup A = max A。

(b) 设 A = { 1 − 1/n : n ∈ ℕ, n ≥ 1 } ⊆ ℚ(即 0, 1/2, 2/3, 3/4, …)。求 sup A,并用 ε-刻画证明你的答案。A 有最大元吗?

(提示:(a) 直接验 max A 满足 (S1)(S2)——它在集合内,故任何上界都 ≥ 它。(b) 答案该是 1;验 (S1) 即 1−1/n < 1;验最小性用 ε-刻画——给定 ε > 0,要找 n 使 1 − 1/n > 1 − ε,即 1/n < ε,这一步需要「ℕ 在 ℚ 中无上界」,即阿基米德性质,可在 ℚ 中直接验证。)

## 参考解答

(建议先自己写完再看。)

**(a)** 记 m = max A。(S1):m 是 A 的上界,这是 max 的定义之一。(S2):设 b 是任一上界,则因 m ∈ A,由上界定义 m ≤ b。两条齐备,m = sup A。∎

**(b)** 断言 sup A = 1。

(S1):对每个 n ≥ 1,1 − 1/n < 1(因 1/n > 0),故 1 是上界。

最小性,用 ε-刻画:任给 ε > 0,要找 a ∈ A 使 a > 1 − ε。a = 1 − 1/n,条件 1 − 1/n > 1 − ε 即 1/n < ε,即 n > 1/ε。这样的自然数存在——因为 ℕ 在 ℚ 中没有上界(阿基米德性质:任何有理数 r,总有自然数超过它;否则 ℕ 有上界,而 ℕ 形如分数 1/ε 之上总能找到更大的整数,这点可由 ℚ 的构造直接核验)。取这样的 n,则 a = 1 − 1/n ∈ A 且 a > 1 − ε。由 ε-刻画,1 = sup A。∎

**A 没有最大元**:若 m = 1 − 1/N 是最大元,则 1 − 1/(N+1) ∈ A 且 > m,矛盾。又一个「有上确界而无最大元」的例子——sup 落在集合外,集合从下方无限逼近它却永不到达。

## 往前看一步

语言已经备好:上界、上确界、完备性公理。ℝ 的定义目标也已锁定——一个完备的有序域。下一步是真正动手把它造出来。Dedekind 的构想是:既然每个实数都对应数轴上的「一刀切」,就直接用这一刀——一个把 ℚ 分成「左、右」两部分的分割——来**定义**实数本身。有理数对应的切口落在某个有理点上,而像 √2 那样的切口,左右两边都没有「最大/最小」的有理数,恰好对应一个 ℚ 中的洞。把这些切口收集起来,就是 ℝ。这就是 [[num_dedekind|Dedekind 分割与 ℝ 的构造]] 的内容。
