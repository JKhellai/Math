## 一条被需要的环恒等式

我们在[[alg_anelli|环]]那节验证了分配律,在[[alg_campi|域]]那节用它推出了一批规则。分配律还有一个射程很远的推论——把 (a + b) 自乘 n 次会展开成什么。中学里背过 (a+b)² = a² + 2ab + b²、(a+b)³ = a³ + 3a²b + 3ab² + b³,系数排成 Pascal 三角。这条规律在任何环里都成立(只要两个元素可交换),而且它**纯粹是分配律的后果**,不需要任何新公理。本节把它严格建立——它将在证明「任意正实数都有 n 次方根」时直接用到。

先备好系数。

## 阶乘与二项式系数

[[num_ricorsione|递归定理]]那节,我们已经用递归定义了**阶乘**(factorial):

0! := 1,  (n + 1)! := (n + 1)·n!。

于是 1! = 1,2! = 2,3! = 6,4! = 24,……n! 是「1 到 n 的连乘」的严格版本。

**定义(二项式系数).** 对 m, n ∈ ℕ,**二项式系数**(binomial coefficient)C(n, m)（常写作 $\binom{n}{m}$，读「n 选 m」）定义为

C(n, m) := n! / ( m!·(n − m)! )  （当 m ≤ n）;  C(n, m) := 0  （当 m > n）。

（m ≤ n 时分母 m!(n−m)! 整除分子 n!，所以 C(n,m) 确实是自然数——这件事本身可由归纳证明，此处承认；它不影响我们对系数的使用。）

直接从定义可读出两条:

- **边界**:C(n, 0) = n!/(0!·n!) = 1,C(n, n) = n!/(n!·0!) = 1。
- **对称**:C(n, m) = C(n, n − m)（分母里 m! 与 (n−m)! 对调，分子不变）。

## Pascal 递推:全部归纳的引擎

二项式定理的归纳证明,全靠下面这条递推——它就是 Pascal 三角里「上面两个数相加得下面一个」的代数形式。

**引理(Pascal 递推).** 对 1 ≤ m ≤ n:

C(n, m − 1) + C(n, m) = C(n + 1, m)。

**证明.** 通分直接算。两项的公分母取 m!·(n − m + 1)!：

C(n, m−1) = n! / ( (m−1)!·(n−m+1)! )，把分子分母同乘 m，得 = m·n! / ( m!·(n−m+1)! )；

C(n, m) = n! / ( m!·(n−m)! )，把分子分母同乘 (n−m+1)，得 = (n−m+1)·n! / ( m!·(n−m+1)! )。

相加（同分母）:

C(n,m−1) + C(n,m) = [ m + (n−m+1) ]·n! / ( m!·(n−m+1)! ) = (n+1)·n! / ( m!·(n−m+1)! )。

而 (n+1)·n! = (n+1)!，且 (n−m+1)! = ((n+1)−m)!，所以右边 = (n+1)! / ( m!·((n+1)−m)! ) = C(n+1, m)。∎

这条递推还顺带说明了为什么 Pascal 三角能「只靠加法」一行行生成:每个内部系数是上一行相邻两个之和。

## 二项式定理

现在主定理。注意它对**任何环**成立,前提只是参与的两个元素**可交换**(ab = ba)——这一点在交换环里自动满足,但定理本身不要求整个环交换,只要这两个元素彼此交换即可。

**定理(二项式定理 binomial theorem).** 设 R 是含幺环,a, b ∈ R 且 ab = ba。则对一切 n ∈ ℕ:

(a + b)ⁿ = Σ_{k=0}^{n} C(n, k)·aᵏ·bⁿ⁻ᵏ。

(右边的 Σ 是[[num_ricorsione|递归定义]]的求和符号;aᵏ 是[[num_ricorsione|递归定义]]的幂,a⁰ = 1。)

**证明（对 n 归纳）.**

*奠基 n = 0.* 左边 (a+b)⁰ = 1。右边只有 k = 0 一项:C(0,0)·a⁰·b⁰ = 1·1·1 = 1。相等。

*归纳步 n → n+1.* 设公式对 n 成立。则

(a+b)ⁿ⁺¹ = (a+b)ⁿ·(a+b) = ( Σ_{k=0}^{n} C(n,k) aᵏ bⁿ⁻ᵏ )·(a + b)。

把右括号用分配律拆成两个和(这一步用到 ab = ba,使得 aᵏbⁿ⁻ᵏ·a = aᵏ⁺¹bⁿ⁻ᵏ——a 能「穿过」b):

= Σ_{k=0}^{n} C(n,k) aᵏ⁺¹ bⁿ⁻ᵏ  +  Σ_{k=0}^{n} C(n,k) aᵏ bⁿ⁺¹⁻ᵏ。

把第一个和里的指标平移（令 j = k+1，则 k=0…n 对应 j=1…n+1），再都写回字母 k：

= Σ_{k=1}^{n+1} C(n,k−1) aᵏ bⁿ⁺¹⁻ᵏ  +  Σ_{k=0}^{n} C(n,k) aᵏ bⁿ⁺¹⁻ᵏ。

把第一个和的 k=n+1 项（即 aⁿ⁺¹）和第二个和的 k=0 项（即 bⁿ⁺¹）单独拎出，中间 1 ≤ k ≤ n 的部分两个和合并:

= aⁿ⁺¹ + Σ_{k=1}^{n} [ C(n,k−1) + C(n,k) ] aᵏ bⁿ⁺¹⁻ᵏ + bⁿ⁺¹。

中括号里正是 **Pascal 递推**,等于 C(n+1, k)。而 aⁿ⁺¹ = C(n+1,n+1)aⁿ⁺¹b⁰、bⁿ⁺¹ = C(n+1,0)a⁰bⁿ⁺¹,正好补上 k = n+1 和 k = 0 两项:

= Σ_{k=0}^{n+1} C(n+1, k) aᵏ bⁿ⁺¹⁻ᵏ。

这正是 n+1 的公式。由归纳原理,定理对一切 n 成立。∎

证明的核心就一处:展开后出现 C(n,k−1) 与 C(n,k) 相邻两项,Pascal 递推把它们并成 C(n+1,k)。整个二项式定理,可以说就是 Pascal 递推撑起来的。

## 一个顺带的推论

在定理里取 a = b = 1（在任何含幺环里 1 与自身交换）:

**推论.** Σ_{k=0}^{n} C(n, k) = 2ⁿ。

**证明.** (1 + 1)ⁿ = Σ C(n,k)·1ᵏ·1ⁿ⁻ᵏ = Σ C(n,k)。而左边 (1+1)ⁿ = 2ⁿ。∎

这条在 ℤ 或 ℝ 里读作「Pascal 三角第 n 行之和是 2ⁿ」。它还有一个组合意义:一个 n 元集合的子集总数是 2ⁿ（回想[[fond_cardinalita|幂集]]）——因为 C(n,k) 数的正是「k 元子集的个数」，求和即全部子集。代数恒等式与计数,在此对上。

## 一道激活练习

(a) 用二项式定理证明:对 n ≥ 1，Σ_{k=0}^{n} (−1)ᵏ C(n, k) = 0。（即 Pascal 三角每行「正负交错求和」为零。）

(b) 在有序域中证明 **Bernoulli 不等式** 的一个特例:对实数 x ≥ 0 与 n ∈ ℕ,(1 + x)ⁿ ≥ 1 + nx。（提示:用二项式定理展开 (1+x)ⁿ,丢掉 k ≥ 2 的项——它们都非负，因为 x ≥ 0——只留 k = 0 和 k = 1 两项。这条不等式在下一章估计「指数增长」时极常用。）

## 参考解答

(建议先自己写完再看。)

**(a)** 在二项式定理中取 a = −1, b = 1（在 ℤ 或任何含幺环中它们交换）:

(−1 + 1)ⁿ = Σ_{k=0}^{n} C(n,k)·(−1)ᵏ·1ⁿ⁻ᵏ = Σ_{k=0}^{n} (−1)ᵏ C(n,k)。

左边 = 0ⁿ = 0（因 n ≥ 1）。故该交错和为 0。∎

**(b)** 由二项式定理（x 与 1 交换）:

(1 + x)ⁿ = Σ_{k=0}^{n} C(n,k) xᵏ = C(n,0) + C(n,1)x + Σ_{k=2}^{n} C(n,k) xᵏ = 1 + nx + Σ_{k=2}^{n} C(n,k) xᵏ。

（用了 C(n,0) = 1、C(n,1) = n!/(1!(n−1)!) = n。）末项的和中每一项都非负:C(n,k) 是自然数（≥ 0），xᵏ ≥ 0（因 x ≥ 0）。丢掉这个非负的尾巴,得

(1 + x)ⁿ ≥ 1 + nx。∎

回顾:(b) 的手法——「二项式展开后，扔掉一段同号的尾巴，留下主项作界」——是分析里用二项式定理做估计的典型套路。下一节证 n 次根、以及将来证「指数比多项式增长快」时，都会用到这种「只保留几项、放缩掉其余」的思路。
