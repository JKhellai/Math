[[fond_proposizioni|命题]]与[[fond_quantificatori|量词]]给出了表述数学陈述的记号。剩下的问题是怎样**证明**一个陈述为真。本节整理常用的证明结构，以及相关术语的分别。

## 术语

数学中被证明为真的命题按其地位有不同称呼：

**命题**(proposition)——一个已证为真的陈述。以下三者都是命题，只是地位不同。

**定理**(theorem)——特别重要的命题。

**引理**(lemma)——为证明某定理而先行准备的命题。

**推论**(corollary)——由某定理直接得出的命题。

这些区分是**表述习惯**，不是逻辑地位的差别：一个引理与一个定理同样为真，区别只在它在论述结构中扮演的角色。

## 要证什么

数学中最常见的命题形式是 A ⟹ B。由[[fond_proposizioni|蕴含的真值表]]，A 为假时 A ⟹ B 自动为真，所以唯一需要处理的情形是 A 为真。于是：

**要证 A ⟹ B，只需假设 A 为真，然后推出 B 为真。**

其中 A 称**前件**或**假设**，B 称**后件**或**结论**。

## 直接证明

从假设出发，一步步推到结论。若中间要经过若干过渡陈述，依据的是下面这条。

**命题（链式传递）** 

(A ⟹ C) ∧ (C ⟹ B) ⟹ (A ⟹ B)

**证明** 假设左端为真，且 A 为真。由 A ⟹ B 需要的只是「A 真时 B 真」：

A 真 ∧ (A ⟹ C) ⟹ C 真<br>
C 真 ∧ (C ⟹ B) ⟹ B 真

故 A 真时 B 真，即 A ⟹ B。∎

用法：想证 A ⟹ B 而一步跨不过去，就找一个中间陈述 C，把它拆成 A ⟹ C 与 C ⟹ B 两段。每段若仍跨不过，继续拆。**一条长证明就是这样由许多小步拼成的。**

**例** 证「若 4 | n，则 2 | n」（此处借用整数的整除，严格构造留待 [[num_n|后面]]）：

4 | n ⟹ n = 4k ⟹ n = 2·(2k) ⟹ 2 | n<br>
（中间陈述 C 是「n = 4k 对某整数 k 成立」）

一步跨不过去时就插入中间陈述，把长推理拆成若干可验证的短步。

## 逆否证明

**依据** 由[[fond_proposizioni|逆否等价]]，

(A ⟹ B) ⟺ (¬B ⟹ ¬A)

所以要证 A ⟹ B，可以改证 ¬B ⟹ ¬A。两者等价，证出一个就等于证出另一个。

**什么时候用**：当「¬B」比「A」更容易入手时。典型情形是 B 为一个等式或简单结论，而 ¬B 提供了具体的可操作信息。

**例** 证「n² 是偶数 ⟹ n 是偶数」。直接证不方便（从 n² 偶推 n 的性质要绕）。改证逆否「n 是奇数 ⟹ n² 是奇数」：

n 奇 ⟹ n = 2k+1（某整数 k）<br>
⟹ n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1<br>
⟹ n² 奇

（此处借用了整数的算术，严格构造留待 [[num_n|后面]]。）逆否成立，故原命题成立。∎

**注** 一个陈述与它的逆否既然等价，就可以按方便任选一个来陈述或证明。后面定义中出现的条件常有这两种写法并存的情形，届时不必两者都证——证出一个即得另一个。

## 反证法

**依据** 要证 B，假设 ¬B 为真，然后推出一个**已知为假**的陈述 C。既然由 ¬B 推出了假的东西，¬B 不可能为真，故 B 为真。

若要证的是 A ⟹ B，则同时保留假设 A 为真，从 A 与 ¬B 一起推出矛盾。

**什么时候用**：当 ¬B 提供的信息比 B 更具体、更好用时。特别是 B 形如「不存在……」「至多一个……」时，¬B 反而给出一个具体对象供你摆弄。

**为什么它常常好用**：形如「不存在……」的结论，本身给不出任何可操作的对象；而它的否定「存在某个……」立刻交到你手上一个具体的东西，可以对它做计算、代入、比较，从而制造矛盾。[[fond_quantificatori|量词否定规则]]正是完成这个转换的工具：

¬ ( ¬∃x : E(x) ) = ∃x : E(x)<br>
（反设「不存在」不成立，就得到一个具体的 x）

**例** 证「不存在最大的自然数」（借用自然数的基本性质，严格构造留待 [[num_n|后面]]）。

要证的是 ¬∃N ∀n : n ≤ N。反设它不成立，则存在这样的 N：

∀n ∈ ℕ : n ≤ N

取 n := N + 1，它是自然数，故按上式应有 N + 1 ≤ N，即 1 ≤ 0，与 0 < 1 矛盾。故原结论成立。∎

注意反设给了什么：**一个具体的 N**。有了它才能构造 N + 1 并代入。若不反证，「不存在最大自然数」这句话本身无从下手。

**注（反证与逆否的区别）** 二者都从否定出发，但不同：

逆否证明：把 A ⟹ B 换成等价的 ¬B ⟹ ¬A，得到的是**另一个蕴含式**，仍是直接推导。

反证法：假设 ¬B（连同 A），推出**任何**已知为假的陈述——矛盾的落点不必是 ¬A，可以是任何荒谬结论（如 y < y、1 = 0）。

反证法适用面更宽，但逆否证明结构更干净。能用逆否时优先用它。

## 两种常见的固定套路

以下两条不是新方法，是上述方法在特定命题形式上的固定用法。

**证双条件 A ⟺ B：分别证两个方向。** 依据是[[fond_proposizioni|等价的定义]]

(A ⟺ B) := (A ⟹ B) ∧ (B ⟹ A)

所以证 A ⟺ B 就是证两个蕴含式，各用上述任一方法。两个方向的难度常常不同，可分别选择合适的路径。

若推导的**每一步本身都是等价**（⟺）而非单向蕴含，则一条链走完即可，两个方向同时得到。这种写法更短，但每一步都必须真的可逆——把只成立一个方向的步骤误写成 ⟺ 是常见错误。

**证唯一存在 ∃!：分别证存在性与唯一性。** 依据是[[fond_quantificatori|∃! 的定义]]：

存在性——构造出一个满足条件的对象，或论证它存在。<br>
唯一性——设有两个对象都满足条件，推出它们相等。

两步缺一不可：只证存在性不排除有多个，只证唯一性时可能一个都不存在。

## 方法对照

| 要证的形式 | 优先考虑 |
|---|---|
| A ⟹ B，A 的信息具体好用 | 直接证明 |
| A ⟹ B，¬B 比 A 更好入手 | 逆否证明 |
| B 形如「不存在」「至多一个」「为空」 | 反证法 |
| A ⟺ B | 两个方向分别证，或全等价链 |
| ∃! | 存在性 + 唯一性 |

这张表是起手的参考，不是规定。同一个命题常有多种证法。

## 练习

(a) 用逆否证明：设 n 是整数。若 n² 不能被 3 整除，则 n 不能被 3 整除。（提示：写出逆否命题，会发现它更容易。）

(b) 用反证法证明：若整数 n 满足 n² 是偶数，则 n 是偶数。（提示：反设 n 是奇数，写出 n = 2k+1，计算 n²。此处借用整数的算术。）

(c) 指出下列证明用的是哪种方法，并写出它所依据的那条逻辑规则：

> 设 n 是整数，且 n + 1 是偶数。证 n 是奇数。<br>
> 若 n 是偶数，则 n = 2k，于是 n + 1 = 2k + 1 是奇数，与已知 n + 1 为偶数矛盾。故 n 是奇数。

## 参考解答

**(a)** 原命题：3 ∤ n² ⟹ 3 ∤ n。其逆否命题为

3 | n ⟹ 3 | n²

证逆否：

3 | n ⟹ n = 3k（某整数 k）<br>
⟹ n² = 9k² = 3·(3k²)<br>
⟹ 3 | n²

逆否成立，由逆否等价，原命题成立。∎

（对比：直接证「3 ∤ n² ⟹ 3 ∤ n」要从「n² 不被 3 整除」这个否定信息出发，不好用；逆否把两边的否定都去掉了。**逆否证明常常就是为了把否定条件换成肯定条件。**）

**(b)** 要证的结论 B 是「n 是偶数」。反设 ¬B，即 n 是奇数：

n = 2k + 1（某整数 k）<br>
⟹ n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1<br>
⟹ n² 是奇数

这与已知的「n² 是偶数」矛盾（一个整数不能既奇又偶）。故 n 是偶数。∎

（把这个解答与正文中逆否证明「n² 偶 ⟹ n 偶」的那一段对照：两者的**计算完全相同**，差别只在组织方式——逆否证明把它写成一个新的蕴含式「n 奇 ⟹ n² 奇」并直接证出，反证法则把同一步推导的结果拿去与假设相撞。这印证了前面那条注：能用逆否时，逆否的结构更干净。）

**(c)** 用的是**反证法**。

要证的结论 B 是「n 是奇数」。反设 ¬B，即「n 是偶数」，连同已知的假设「n + 1 是偶数」一起推导，得出「n + 1 是奇数」——这与假设矛盾。故 ¬B 不成立，即 B 成立。

依据的逻辑规则：**若由 ¬B（连同已有假设）推出一个已知为假的陈述，则 B 为真。**

（也可以用逆否证明：原命题「n + 1 偶 ⟹ n 奇」的逆否是「n 偶 ⟹ n + 1 奇」，直接验证即可。这个例子两种方法都走得通，写出来的推导几乎相同——差别只在如何组织：反证法把矛盾作为落点，逆否证明把它组织成一个新的蕴含式。）∎
