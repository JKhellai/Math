## 兑现造 ℝ 的初衷

本章一开始,我们造 ℝ 的动机是一个具体的缺憾:ℚ 里没有平方等于 2 的数。Dedekind 分割那节已经给出 √2 这个具体的实数。现在把它推到一般:**不只是 √2,任意正实数都能开任意次方**。这条定理一旦证成,「造 ℝ 是为了能开方」这个开篇承诺就完整兑现了——而且证明再次只依赖一件事:**完备性**。√2 将只是它的一个特例。

**定理(n 次根存在唯一).** 对每个 a ∈ ℝ,a > 0,和每个 n ∈ ℕˣ,存在唯一的 x ∈ ℝ,x > 0,使 xⁿ = a。

这个唯一的 x 记作 ⁿ√a 或 a^(1/n),称 a 的 **n 次方根**(nth root);n = 2 时就是平方根 √a。

证明分两半:唯一性容易(单调性),存在性是主体(用 sup 把根逼出来)。

## 唯一性:xⁿ 严格递增

**引理(幂函数严格递增).** 设 0 < x < y,n ≥ 1。则 xⁿ < yⁿ。

**证明.** 用[[alg_binomio|二项式定理]]那节练习里的因式分解(它本身是一条恒等式):

yⁿ − xⁿ = (y − x)·( yⁿ⁻¹ + yⁿ⁻²x + ⋯ + yxⁿ⁻² + xⁿ⁻¹ )。

右边第一个因子 y − x > 0;第二个因子是 n 个正数之和(x, y 都正),也 > 0。两正数相乘为正(有序域,[[num_q_ordine|O2]]),故 yⁿ − xⁿ > 0,即 xⁿ < yⁿ。∎

唯一性立刻得到:若 x₁ⁿ = a = x₂ⁿ 且两者都正,则 x₁ < x₂ 会推出 x₁ⁿ < x₂ⁿ(矛盾),x₁ > x₂ 同理矛盾;由全序性只剩 x₁ = x₂。∎

## 存在性:把根 sup 出来

主体在这里。思路与[[num_estremo_superiore|上确界]]那节"ℚ 里 {q²<2} 无上确界"的讨论是镜像的——那里我们证 ℚ **没有**这个 sup,这里我们利用 ℝ 的完备性**取到**这个 sup,然后证它的 n 次幂恰好命中 a。

不妨设 n ≥ 2(n = 1 时 x = a 直接成立)。考虑集合

A := { x ∈ ℝ : x ≥ 0 且 xⁿ ≤ a }。

**A 非空有上界,故 s := sup A 存在。** 非空:0 ∈ A(0ⁿ = 0 ≤ a)。有上界:断言 max(a, 1) + 1 是上界——更简单地,取 c := a + 1,验证 x ≥ c ⟹ xⁿ > a:若 x ≥ a + 1 > 1,则 xⁿ ≥ x > a(用引理,xⁿ ≥ x¹ 当 x > 1 且 n ≥ 1;且 x = a+1 > a)。所以 A 中元素都 < c,c 是上界。由[[num_dedekind|完备性]],s := sup A 存在,且 s ≥ 0。

A 是数轴上从 0 起、平方(n 次幂)还没超过 a 的那一段;它有上界(如 c = a+1),完备性保证它有最小上界 s。下面要证的是:这个 s 的 n 次幂**不多不少恰好**等于 a——即 s 就是 ⁿ√a。

往证 sⁿ = a。策略:证明 sⁿ < a 和 sⁿ > a **都**导致矛盾,由全序性只剩 sⁿ = a。两个方向都用**二项式定理**把 (s ± ε)ⁿ 展开后估计。

**排除 sⁿ < a.** 设 sⁿ < a,即 a − sⁿ > 0。我们要找一个小的 ε > 0,使 (s + ε)ⁿ 仍 ≤ a——这将给出 s + ε ∈ A,与 s 是上界矛盾。

把 ε 先限制在 0 < ε ≤ 1,则 εᵏ ≤ ε 对一切 k ≥ 1。用二项式定理:

(s + ε)ⁿ = Σ_{k=0}^{n} C(n,k) sⁿ⁻ᵏ εᵏ = sⁿ + Σ_{k=1}^{n} C(n,k) sⁿ⁻ᵏ εᵏ ≤ sⁿ + ε·Σ_{k=1}^{n} C(n,k) sⁿ⁻ᵏ。

记 b := Σ_{k=1}^{n} C(n,k) sⁿ⁻ᵏ(一个固定的正实数,只依赖 s 和 n)。于是 (s+ε)ⁿ ≤ sⁿ + εb。要它 ≤ a,只需 εb ≤ a − sⁿ,即 ε ≤ (a − sⁿ)/b。因 a − sⁿ > 0、b > 0,这个上界为正。取

ε := min( 1, (a − sⁿ)/b )（取较小者，[[num_q_ordine|有序域]]中 min 有定义），

则 ε > 0,且既 ≤ 1 又 ≤ (a−sⁿ)/b,代入得 (s + ε)ⁿ ≤ sⁿ + εb ≤ sⁿ + (a − sⁿ) = a。所以 s + ε ∈ A。但 s + ε > s,与「s 是 A 的上界」矛盾。

**排除 sⁿ > a.** 设 sⁿ > a,即 sⁿ − a > 0。此时 s > 0(否则 sⁿ = 0 ≤ a)。我们要找小的 ε > 0,使 (s − ε)ⁿ 仍 > a 且 s − ε > 0——这将说明 s − ε 也是 A 的上界(任何 x ∈ A 有 xⁿ ≤ a < (s−ε)ⁿ,由引理逆推得 x < s − ε),而 s − ε < s,与 s 是**最小**上界矛盾。

把 (s − ε)ⁿ 展开。逐项是 Σ C(n,k) sⁿ⁻ᵏ (−ε)ᵏ;把符号为负的项(k 奇)放大处理——丢掉所有 k ≥ 1 里使结果减小的部分,保留一个干净的下界。最省事的估计:对 0 < ε ≤ 1,

(s − ε)ⁿ = sⁿ + Σ_{k=1}^{n} C(n,k) sⁿ⁻ᵏ (−ε)ᵏ ≥ sⁿ − Σ_{k=1}^{n} C(n,k) sⁿ⁻ᵏ εᵏ ≥ sⁿ − ε·Σ_{k=1}^{n} C(n,k) sⁿ⁻ᵏ = sⁿ − εb,

（第一个 ≥：负项整体不小于「把每项都取绝对值再变号减去」；第二个 ≥：εᵏ ≤ ε。）b 同上。要 (s−ε)ⁿ > a,只需 sⁿ − εb > a,即 ε < (sⁿ − a)/b。再要 s − ε > 0,即 ε < s。取

ε := (1/2)·min( s, (sⁿ − a)/b )（严格正，且同时 < s 与 < (sⁿ−a)/b），

则 (s − ε)ⁿ ≥ sⁿ − εb > a 且 s − ε > 0。于是 s − ε 是比 s 小的上界,与 s = sup A 矛盾。

两种情形俱矛盾,故 sⁿ = a。存在性证毕。∎

## √2 是特例

回头看:取 a = 2、n = 2,定理给出唯一的正实数 x 使 x² = 2——这就是 √2,而它现在是「n 次根存在定理」的一个特例,与 Dedekind 分割那节那个具体的 γ 是同一个数(都满足 x² = 2 且 x > 0,由唯一性它们相等)。当初在[[fond_iniettive_suriettive|单射满射]]那节,我们说「√b 的存在留待完备性」;在[[num_estremo_superiore|上确界]]那节,把缺口表述成「无上确界」;现在,这条一般定理把「开方」彻底兑现——不只 √2,所有正实数的所有次方根都在 ℝ 里各就各位。这条贯穿全章的线,至此闭合。

值得记下证明的结构,因为它是「用完备性确立存在性」的范本:**把要找的对象表示成某个集合的 sup(用完备性保证它存在),再证这个 sup 恰好具有所需的性质(排除「太大」与「太小」)**。后面分析里许多存在性定理——介值定理、极值定理——用的都是这个套路。两个排除方向里,「太小则还能更大、太大则还能更小」的估计,几乎总要靠某种展开或放缩,这次用的是二项式定理。

## 一道激活练习

(a) 证明 n 次根的**可乘性**:对 a, b > 0,ⁿ√(a·b) = ⁿ√a · ⁿ√b。（提示:令 x = ⁿ√a、y = ⁿ√b,计算 (xy)ⁿ,用[[alg_anelli|环]]里乘法的交换结合;再用唯一性收口——「xy 是 ab 的正 n 次根」。）

(b) 证明:若 a > 1,则 ⁿ√a > 1;若 0 < a < 1,则 ⁿ√a < 1。（提示:反证 + 幂函数严格递增引理。比如 a > 1 时若 ⁿ√a ≤ 1，对两边取 n 次幂会推出什么？）

## 参考解答

(建议先自己写完再看。)

**(a)** 令 x := ⁿ√a，y := ⁿ√b，即 x, y > 0 且 xⁿ = a、yⁿ = b。计算

(x·y)ⁿ = xⁿ·yⁿ （乘法可交换，故 (xy)ⁿ 的因子可重排成 xⁿ 与 yⁿ） = a·b。

且 x·y > 0（两正数之积）。所以 x·y 是 a·b 的一个正 n 次根。由 n 次根的**唯一性**，它就是 ⁿ√(ab)。故 ⁿ√(ab) = ⁿ√a · ⁿ√b。∎

**(b)** 设 a > 1，记 x := ⁿ√a > 0，则 xⁿ = a > 1。反设 x ≤ 1：若 x = 1，则 xⁿ = 1 ≠ a，矛盾；若 x < 1，由幂函数严格递增引理（用在 x < 1 上，即 xⁿ < 1ⁿ = 1），得 a = xⁿ < 1，与 a > 1 矛盾。故 x > 1。

设 0 < a < 1，记 x := ⁿ√a，则 xⁿ = a < 1。反设 x ≥ 1：x = 1 给 xⁿ = 1 ≠ a；x > 1 给 xⁿ > 1 > a，矛盾。故 x < 1。∎

回顾:这两条都是「幂函数严格递增」的直接应用——n 次根保持大小关系（它是个递增函数）。「开方不改变与 1 的大小关系」这件事，下一章讨论「aⁿ 当 0<a<1 时趋于 0、当 a>1 时趋于无穷」会用到。
