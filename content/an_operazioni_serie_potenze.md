## 幂级数能像多项式一样运算吗

[[an_serie_potenze|幂级数]]在收敛圆盘内[[an_convergenza_assoluta|绝对收敛]]——而[[an_riordinamenti|绝对收敛]]那节刚证明,绝对收敛的级数可以自由地相加、相乘。这一节把这份自由用到幂级数上:**两个幂级数可以像多项式那样相加、相乘,结果仍是幂级数**。更进一步,我们将证明一个奠基性的事实——**幂级数的表示是唯一的**:一个函数若能展成幂级数,这个展开式只有一种。这让「比较系数」成为合法的推理手段,是幂级数方法的基石。这两件事合起来,为第二章「收敛」画上句号。

## 加法与乘法

**命题.** 设 a(x) = Σaₖxᵏ、b(x) = Σbₖxᵏ 是两个幂级数,收敛半径分别 ρₐ、ρᵦ。记 ρ := min(ρₐ, ρᵦ)。则对一切 |x| < ρ:

- **加法(逐项相加)**:Σaₖxᵏ + Σbₖxᵏ = Σ(aₖ + bₖ)xᵏ;
- **乘法(Cauchy 乘积/卷积)**:(Σaₖxᵏ)·(Σbₖxᵏ) = Σ_{k}(Σ_{j=0}^{k} aⱼb_{k−j})xᵏ。

且 a+b 与 a·b 的收敛半径都 **≥ ρ**(即在两者公共的收敛圆盘内,运算结果仍是收敛的幂级数)。

**证明.** 在 |x| < ρ 处,两个幂级数都绝对收敛。加法是收敛级数的[[an_serie|逐项相加]](运算法则);乘法正是两个绝对收敛级数的 [[an_riordinamenti|Cauchy 乘积]]——其第 k 项对角线和是 Σ_{j=0}^{k} aⱼ·b_{k−j},而 (aⱼxʲ)(b_{k−j}x^{k−j}) = aⱼb_{k−j}xᵏ,提出 xᵏ 得系数 Σ_{j=0}^{k}aⱼb_{k−j}。Cauchy 乘积定理保证它绝对收敛到积。∎

注意乘法的系数 cₖ = Σ_{j=0}^{k} aⱼb_{k−j} ——这正是多项式相乘时「同次项系数」的算法(**卷积**):x⁰ 系数是 a₀b₀,x¹ 系数是 a₀b₁+a₁b₀,x² 系数是 a₀b₂+a₁b₁+a₂b₀,…… **幂级数相乘,系数按卷积合成,和有限多项式完全一样**——只是现在有无穷多项,靠绝对收敛保证合法。

> 收敛半径**可能变大**(故写 ≥ 而非 =):例如两个幂级数相加,主导项可能抵消,使和的收敛半径超过 min(ρₐ,ρᵦ)。但「至少在公共圆盘 |x|<ρ 内收敛」总成立,这已足够用。

**例(指数律的伏笔).** [[an_serie_potenze|exp(x) = Σxᵏ/k!]]。算 exp(x)·exp(y)（把 y 看成参数,或在形式幂级数层面）的 Cauchy 乘积,第 n 项系数整理后恰是 (x+y)ⁿ/n!（用[[alg_binomio|二项式定理]]:Σ_{k=0}^n (xᵏ/k!)(y^{n−k}/(n−k)!) = (1/n!)Σ C(n,k)xᵏy^{n−k} = (x+y)ⁿ/n!）。于是

exp(x)·exp(y) = Σ (x+y)ⁿ/n! = exp(x+y)。

**指数律 exp(x)exp(y) = exp(x+y) 就此由 Cauchy 乘积严格证出**——这是幂级数相乘最漂亮的一个应用,也兑现了[[an_riordinamenti|Cauchy 乘积]]那节埋的伏笔。

## 表示的唯一性：恒等定理

现在是第二章的压轴结果。它回答一个根本问题:**一个函数的幂级数展开,会不会有两种不同的写法?** 答案是否定的——展开唯一。这要从一个看似很强、实则深刻的引理开始。

**定理(幂级数的零点引理).** 设 Σaₖxᵏ 的收敛半径 ρ > 0。若存在一列**非零**的点 yⱼ,满足 yⱼ → 0(且 0 < |yⱼ| < ρ),使得

a(yⱼ) = Σ_{k=0}^{∞} aₖ yⱼᵏ = 0  对**所有** j，

则**所有系数 aₖ = 0**（即 a 是零幂级数）。

**证明.** 反设系数不全为零。由[[num_n|良序原理]],存在**最小**的下标 n₀ 使 a_{n₀} ≠ 0。把级数从第 n₀ 项拆开:a(x) = a_{n₀}x^{n₀} + Σ_{k>n₀} aₖxᵏ。关键是估计后面那个尾巴。

**尾部估计**:固定 r ∈ (0, ρ)。由绝对收敛,对 |x| ≤ r,

|Σ_{k≥n} aₖxᵏ| ≤ Σ_{k≥n}|aₖ||x|ᵏ = |x|ⁿ·Σ_{k≥n}|aₖ||x|^{k−n} ≤ |x|ⁿ·(Σ_{j≥0}|a_{j+n}|rʲ)。

记 C := Σ_{j≥0}|a_{j+n₀+1}|rʲ < ∞(绝对收敛保证有限),则尾巴 |Σ_{k>n₀}aₖxᵏ| ≤ C·|x|^{n₀+1}。所以

|a(x) − a_{n₀}x^{n₀}| ≤ C|x|^{n₀+1}，  |x| ≤ r。

把 x = yⱼ 代入。因 a(yⱼ) = 0,左边 = |a_{n₀}yⱼ^{n₀}| = |a_{n₀}||yⱼ|^{n₀};右边 = C|yⱼ|^{n₀+1}。两边除以 |yⱼ|^{n₀}（yⱼ ≠ 0）:

|a_{n₀}| ≤ C·|yⱼ|，  对所有 j。

但 yⱼ → 0,令 j → ∞ 得 |a_{n₀}| ≤ 0,即 **a_{n₀} = 0**——与「a_{n₀} ≠ 0」矛盾。故系数全为零。∎

证明的精髓:**最低次的非零系数 a_{n₀} 主导了原点附近的行为**(其它项是更高次的、更小的)。若函数在一列逼近 0 的点上全为零,这个主导项被迫为零——一个漂亮的「用最低次项卡住」的论证。

由这个引理,立刻得到唯一性:

**定理(恒等定理 identity theorem).** 设 a(x) = Σaₖxᵏ、b(x) = Σbₖxᵏ 收敛半径都 > 0。若存在一列非零点 yⱼ → 0,使 a(yⱼ) = b(yⱼ) 对所有 j,则 **aₖ = bₖ 对所有 k**(两幂级数逐项相同)。

**证明.** 考虑差 a − b = Σ(aₖ−bₖ)xᵏ。它在所有 yⱼ 处为零(因 a(yⱼ)=b(yⱼ)),由零点引理,所有系数 aₖ−bₖ = 0,即 aₖ = bₖ。∎

## 唯一性意味着什么：可以比较系数

恒等定理的推论极其重要:

**幂级数表示唯一.** 若一个函数 f 在原点附近能写成幂级数 f(x) = Σaₖxᵏ,则这个幂级数是**唯一**的——系数 aₖ 被 f 完全确定。(因为「在原点附近相等」尤其意味着「在某列 yⱼ→0 上相等」,恒等定理即给出系数唯一。)

这条「唯一性」让一个常用手段变得合法——**比较系数**(comparison of coefficients):若两个幂级数表示同一个函数(在原点邻域),就可以逐项令它们的系数相等。这是幂级数方法的核心技巧:

- 解微分方程时,设解为幂级数 Σaₖxᵏ,代入方程,**比较两边同次幂的系数**,得到 aₖ 的递推关系——合法性正来自唯一性。
- 证恒等式(如三角恒等式、组合恒等式)时,把两边展成幂级数,**系数对应相等**即证。
- 求一个函数的幂级数展开时,不必担心「会不会有别的展开」——唯一性保证算出的就是那一个。

没有恒等定理,「比较系数」只是一厢情愿;有了它,这成了严格的推理。**唯一性是幂级数从「形式工具」升格为「严格方法」的关键。**

> 一个**重要的前提不能省**:零点 yⱼ 必须**趋于 0**(在原点堆积)。仅仅「有无穷多个零点」不够——存在非零的幂级数(如以后会遇到的 sin),它有无穷多个零点(0, ±π, ±2π, …),但这些零点**不**在原点堆积(彼此隔开),所以不与恒等定理矛盾。零点在某点的「堆积」才是迫使系数全零的关键。

## 一道激活练习

(a) 用 Cauchy 乘积求 (Σ_{k=0}^∞ xᵏ)·(Σ_{k=0}^∞ xᵏ) 的幂级数(|x|<1),即算乘积的系数 cₖ。(提示:aⱼ=bⱼ=1,cₖ=Σ_{j=0}^k aⱼb_{k−j}。)

(b) 已知 1/(1−x) = Σxᵏ(|x|<1)。利用幂级数唯一性(比较系数)求满足 (1−x)·f(x) = 1 的幂级数 f(x) = Σaₖxᵏ。(提示:把 (1−x)Σaₖxᵏ 展开,令其等于常数 1=1+0·x+0·x²+…,逐项比较系数解出 aₖ。)

(c) 设幂级数 f(x) = Σaₖxᵏ 满足 f(x) = f(−x) 对原点附近所有 x（偶函数）。用恒等定理证明:所有奇数次系数为零(a₁=a₃=a₅=⋯=0)。

## 参考解答

(建议先自己写完再看。)

**(a)** cₖ = Σ_{j=0}^{k} 1·1 = k+1（k+1 个 1 相加）。故 (Σxᵏ)² = Σ_{k=0}^∞ (k+1)xᵏ = 1 + 2x + 3x² + 4x³ + ⋯。∎（与[[an_riordinamenti|上节练习]]一致;也即 1/(1−x)² = Σ(k+1)xᵏ。）

**(b)** 展开 (1−x)Σaₖxᵏ = Σaₖxᵏ − Σaₖx^{k+1}。第二个和换指标(令 k+1=m）= Σ_{m≥1}a_{m−1}xᵐ。合并同次幂:常数项 a₀;xᵏ 项（k≥1）系数 aₖ − a_{k−1}。令整体 = 1 = 1 + 0·x + 0·x² + ⋯,**比较系数**:

x⁰: a₀ = 1;  xᵏ (k≥1): aₖ − a_{k−1} = 0,即 aₖ = a_{k−1}。

由 a₀=1 递推得 aₖ = 1 对所有 k。故 f(x) = Σxᵏ = 1/(1−x)——印证了 f = 1/(1−x) 确实是 (1−x)f=1 的解,且唯一性保证这是唯一的幂级数解。∎

**(c)** f(x) = Σaₖxᵏ,而 f(−x) = Σaₖ(−x)ᵏ = Σ(−1)ᵏaₖxᵏ。条件 f(x) = f(−x) 对原点附近所有 x 成立,尤其在某列 yⱼ→0 上成立。由**恒等定理**,两个幂级数 Σaₖxᵏ 与 Σ(−1)ᵏaₖxᵏ 系数对应相等:

aₖ = (−1)ᵏaₖ,  对所有 k。

当 k 为奇数,(−1)ᵏ = −1,得 aₖ = −aₖ,即 2aₖ = 0,故 aₖ = 0。所以所有奇数次系数为零。∎（偶函数的幂级数只含偶次幂——这与直觉一致,而恒等定理把它变成了严格结论。对称地,奇函数只含奇次幂。）

回顾:这三题展示幂级数运算与唯一性的典型用法。(a) 是 Cauchy 乘积的直接计算(卷积系数)。(b)(c) 都用「**比较系数**」——其合法性正是恒等定理:(b) 通过令两边同次系数相等解出未知幂级数(幂级数解微分方程/函数方程的雏形);(c) 用对称性 + 恒等定理推出系数的奇偶结构。比较系数是幂级数方法的招牌动作,而它每一次使用,背后都站着唯一性定理。

## 第二章收官

到这里,A–E 第二章「收敛」全部学完。回望整章的拱顶:从[[an_convergenza|数列收敛]]的 ε–N 定义出发,经[[an_cauchy|完备性]](ℝ 的根本性质)、[[an_serie|级数]]与[[an_convergenza_assoluta|判别法]],抵达[[an_serie_potenze|幂级数]]——而幂级数现在不仅有[[an_serie_potenze|收敛半径]]、能[[an_riordinamenti|相乘]],还有了唯一的表示。「逼近」与「无限求和」的理论完整而严密。

但幂级数目前仍是「静态」的:我们能谈它在一点收敛到什么,却还不能对它做**微积分**——求导、积分。要让幂级数真正成为分析的利器(逐项求导得 exp'=exp、sin'=cos),必须先建立**函数的连续性与可微性**。这正是第三章的主题。

第三章从**连续函数**开始:函数的极限(ε–δ 语言)、连续的定义、连续函数的运算与基本定理(介值定理、最值定理)。连续性是「函数」这一对象的第一个分析性质,也是通向**导数**的必经之路——而导数,正是你那条暂停的[[物理线]]等待已久的汇合点。数列收敛的理论已经备齐了一切工具(尤其[[an_convergenza|序列收敛]]与[[an_cauchy|完备性]]),连续性的大门就此打开。这是 [[an_continuita|连续函数]] 的起点,也是第三章的开篇。
