## 从数系转入分析

到上一节为止,我们造完了实数轴:一个完备的有序域。数系构造这条线就此收尾。从这一节起,工作的性质变了——不再问「这些数**是**什么」,而是问「这些数**如何逼近**」。这是**分析**(analysis)的主题,而它的第一个、也是最基础的工具,是一把度量「远近」的尺子:**绝对值**。

为什么从绝对值开始?因为「逼近」的本质是「距离越来越小」,而在数轴上,两点 x、y 的距离正是 |x − y|。整个极限理论——数列收敛、函数连续、导数、积分——都建立在「|某某| < ε」这种句子上。所以在谈第一个极限之前,必须先把这把尺子的性质彻底弄清。

绝对值的定义只用到有序域的公理,所以本节在任意**有序域** K 中展开(ℚ、ℝ 都是具体样本);将来对 ℝ 原样适用。

## 定义

**定义.** 设 K 是有序域,x ∈ K。**绝对值**(absolute value)|x| 与**符号函数**(sign)sign(x) 定义为

|x| := x(若 x > 0)/ 0(若 x = 0)/ −x(若 x < 0);

sign(x) := 1(若 x > 0)/ 0(若 x = 0)/ −1(若 x < 0)。

直觉:|x| 把负数「翻正」,量的是 x 到 0 的距离,不计方向;sign(x) 单独记录方向。两者合起来恰好还原 x——这是下面第一条性质。

(三歧性保证定义无歧义:每个 x 恰好落入「正/零/负」之一,所以三条子句恰好适用一条。这正是[[num_q_ordine|有序域]]的全序性在起作用。)

## 基本性质

**命题.** 设 K 是有序域,x, y, a ∈ K,ε > 0。则

- (i) x = |x|·sign(x);
- (ii) |−x| = |x|,且 x ≤ |x|;
- (iii) **|xy| = |x|·|y|**(绝对值可乘);
- (iv) **|x| ≥ 0**,且 |x| = 0 ⟺ x = 0;
- (v) **|x − a| < ε ⟺ a − ε < x < a + ε**(ε-带刻画);
- (vi) **|x + y| ≤ |x| + |y|**(三角不等式)。

**证明.** (i)(ii)(iv) 直接按定义分「正/零/负」三种情形逐一核对即得(例如 (iv):正数与负数取绝对值都得正数,只有 0 得 0)。

(iii) 也是分情形:若 x、y 同号,xy > 0,|xy| = xy,而 |x||y| 在两正或两负时都等于 xy(负负得正);若异号,xy < 0,|xy| = −xy,而 |x||y| 此时一正一负相乘…逐格验证即可,根子是 [[num_z_ordine|环的符号定理]]。

(v) 是后面用得最多的一条,值得写清。分两个方向,核心是把绝对值的定义拆开:

|x − a| < ε  ⟺  −ε < x − a < ε  （∗）

这一步本身要分情形:若 x − a ≥ 0,|x−a| = x−a < ε 给出右半 x − a < ε,而左半 −ε < x − a 因 x−a ≥ 0 > −ε 自动成立;若 x − a < 0,|x−a| = −(x−a) < ε 给出 x − a > −ε,即左半,右半 x − a < 0 < ε 自动成立。两种情形合起来就是 (∗)。再两边同加 a(序与加法相容,O1),得 a − ε < x < a + ε。∎ 这条说的是:**「x 到 a 的距离小于 ε」等价于「x 落在以 a 为心、ε 为半径的开区间里」**——「距离」与「邻域」的互译,极限定义就靠它。

空心端点表示开区间(不含 a±ε 本身);x 落在带内,正对应 |x−a| < ε。整个极限理论里「x 充分接近 a」这句话,画出来就是这条带。

(vi) **三角不等式**,本节的主角。证明用一个漂亮的分情形(依据 (ii) 的 x ≤ |x|):

先设 x + y ≥ 0。则 |x + y| = x + y;而 x ≤ |x|、y ≤ |y|,相加得 x + y ≤ |x| + |y|。故 |x+y| ≤ |x| + |y|。

再设 x + y < 0。则 −(x + y) > 0,于是

|x + y| = |−(x+y)| = |(−x) + (−y)| ≤ |−x| + |−y| = |x| + |y|,

中间的 ≤ 是把刚证的「非负情形」用在 (−x)+(−y) 上(它非负),末步用 (ii) 的 |−x| = |x|。两种情形俱得。∎

为什么叫「三角」不等式:把它写成距离形式 |x − z| ≤ |x − y| + |y − z|(令上式中的两项为 x−y 与 y−z),读作「从 x 直接到 z 的距离,不超过绕道 y 的距离」——三角形两边之和不小于第三边。这条几何直觉,将在下一节被抽象成距离的公理。

## 反向三角不等式

三角不等式给「和」的绝对值一个**上界**;它的推论给「差」一个**下界**,同样常用。

**推论(反向三角不等式).** 对一切 x, y ∈ K:

|x − y| ≥ | |x| − |y| |。

**证明.** 把三角不等式用在恒等式 x = (x − y) + y 上:

|x| = |(x−y) + y| ≤ |x − y| + |y|,

移项得 |x| − |y| ≤ |x − y|。把 x、y 互换,得 |y| − |x| ≤ |y − x| = |x − y|（由 (ii)）。两个不等式合起来:|x−y| 同时 ≥ (|x|−|y|) 和 ≥ −(|x|−|y|),即 ≥ 其绝对值。∎

用处:它说「两个数的距离,至少是它们大小之差」。将来证「若 xₙ → x 则 |xₙ| → |x|」时,一行就靠它。

## 一个典型估计

把这两条不等式连用,演示分析里最常见的一种「拆项放缩」。这类操作以后会成为家常便饭,这里先看一遍它的样子。

**例.** 设 |x − a| < δ 且 |y − b| < δ。则 |(x + y) − (a + b)| < 2δ。

**证明.** 关键是先「拆」再「放」:

|(x+y) − (a+b)| = |(x − a) + (y − b)| ≤ |x − a| + |y − b| < δ + δ = 2δ。

第一步把目标重组成「两个已知小量之和」,第二步三角不等式拆成两段,第三步代入各自的界。∎

这个套路——**把要估计的量,拼凑成若干已知小量的组合,再用三角不等式逐段控制**——是极限证明的基本动作。下一节定义数列收敛后,第一批定理(和的极限、积的极限)用的全是它。

## 一道激活练习

设 K 是有序域,x, y ∈ K。

(a) 证明:|x| − |y| ≤ |x + y|。(注意是 x + y,不是 x − y。)

(b) 设 |x − a| < δ₁ 且 |y − b| < δ₂。给出 |xy − ab| 的一个上界,用 |a|、|b|、δ₁、δ₂ 表示。(提示:这是积的情形,比和难一点。先做一次「加减同一项」的拆分:xy − ab = xy − ay + ay − ab = (x−a)y + a(y−b),再用三角不等式与可乘性 (iii);你还需要把 |y| 控制住——由 |y − b| < δ₂ 和反向三角不等式,|y| < |b| + δ₂。)

## 参考解答

(建议先自己写完再看。)

**(a)** 把反向三角不等式用在 x 与 −y 上:|x − (−y)| ≥ | |x| − |−y| |,即 |x + y| ≥ | |x| − |y| | ≥ |x| − |y|(任何数 ≤ 其绝对值,用了 (ii))。∎

**(b)** 先做加减同一项的拆分:

xy − ab = xy − ay + ay − ab = (x − a)·y + a·(y − b)。

三角不等式 + 可乘性:

|xy − ab| ≤ |x − a|·|y| + |a|·|y − b| < δ₁·|y| + |a|·δ₂。

再把 |y| 控制住:由 |y − b| < δ₂ 与反向三角不等式,|y| − |b| ≤ |y − b| < δ₂,故 |y| < |b| + δ₂。代入:

|xy − ab| < δ₁·(|b| + δ₂) + |a|·δ₂ = |b|·δ₁ + |a|·δ₂ + δ₁·δ₂。∎

回顾:积的估计比和复杂,核心技巧是「加减同一项 ay」——把一个差拆成两个各含一个小因子 (x−a)、(y−b) 的项。这个「加减同项」的手法,是分析证明里仅次于三角不等式的常用动作,证「积的极限」时会原样登场。

## 往前看一步

我们有了一把尺子 |x − y|,量的是数轴上两点的距离,而且摸清了它的全部脾性:非负、可乘、满足三角不等式。下一步是一次关键的抽象。回头看这把尺子真正用到的性质,其实只有三条:距离非负且仅在两点重合时为零、距离对称(|x−y| = |y−x|)、以及三角不等式。任何一个集合,只要配上一个满足这三条的「距离函数」,「逼近」就能在其中谈论——无论它的元素是实数、复数、向量,还是函数。把这三条提炼成公理,就得到**度量空间**(metric space),它是整个分析(以及拓扑、泛函分析)的统一舞台。这就是 [[an_spazio_metrico|度量空间]] 的内容;而我们的第一把尺子 |x−y|,将成为它的头号例子。
