## 完备性的两个直接推论

ℝ 造好了,完备性公理也证了。但在进入极限之前,还有两条「显然得几乎不像定理」的事实需要正式确立——因为整个逼近理论都从它们起步,而它们其实都是完备性的推论,并非自明。

第一条:**自然数能要多大有多大**(没有哪个实数能盖过所有自然数)。第二条:**有理数在实数里到处都是**(任何实数旁边都挤着有理数)。前者让「1/n 趋于 0」这种最基本的逼近成为可能;后者让「用有理数逼近实数」有了着落。两条都短,但都不能跳过。

## 阿基米德性质

直觉上「ℕ 没有上界」再明显不过——可在一个抽象的有序域里,这件事**可能不成立**(确实存在「非阿基米德有序域」,里面有比所有自然数都大的元素)。所以对 ℝ,它必须被证明,而证明的关键正是完备性。

**定理(阿基米德性质 Archimedean property).** ℕ 在 ℝ 中没有上界:对每个 x ∈ ℝ,存在 n ∈ ℕ 使 n > x。

**证明.** 反证。x < 0 时取 n = 0 即可,故设 x ≥ 0。假设 ℕ 有上界(即结论不成立),那么 ℕ 是一个非空、有上界的实数子集,由[[num_dedekind|完备性公理]],s := sup ℕ 存在于 ℝ。

s 是最小上界,所以 s − 1 不是上界([[num_estremo_superiore|上确界的 ε-刻画]],取 ε = 1):存在 n ∈ ℕ 使 n > s − 1。但则 n + 1 > s,而 n + 1 也是自然数——这与 s 是 ℕ 的上界矛盾。所以 ℕ 无上界。∎

证明的要害值得点出:用完备性「凭空」造出一个 sup,再用它的「最小性」逼出矛盾。**完备性是这条定理唯一的、也是不可替代的依据**——非阿基米德有序域之所以存在,正因为它们不完备。

## 推论:1/n 可以任意小

这条推论,是「数列 1/n 趋于 0」的全部内容,也是分析里被引用最多的事实之一。

**推论.** (i) 设 a ∈ ℝ,若 0 ≤ a ≤ 1/n 对**一切** n ∈ ℕˣ 成立,则 a = 0。
(ii) 对每个 a > 0,存在 n ∈ ℕˣ 使 1/n < a。

**证明.** 先证 (ii),(i) 是它的等价改写。给定 a > 0,由阿基米德性质,存在 n ∈ ℕ 使 n > 1/a(> 0,故 n ≥ 1)。两边取倒数(正数取倒翻序,[[num_q_ordine|有序域性质]]):1/n < a。

(i):反设 a > 0,则由 (ii) 存在 n 使 1/n < a,与「a ≤ 1/n 对一切 n」矛盾。故 a = 0。∎

(ii) 说「再小的正数,也有某个 1/n 比它更小」;(i) 说「一个非负数若被所有 1/n 压在下面,它只能是 0」。后面证收敛、证极限唯一,反复就靠这两句。

## 一条整数夹逼引理

证有理数稠密之前,需要一个小工具:任何实数都被两个相邻整数夹住。它本身又是良序原理的一个应用——又一次回到[[num_radice2|良序]]。

**引理.** 对任意 x ∈ ℝ,存在唯一的 m ∈ ℤ 使 m − 1 ≤ x < m。

**证明(存在性).** 由阿基米德性质,存在自然数 m₁ > x 和 m₂ > −x,即 −m₂ < x < m₁。于是集合 { k ∈ ℤ : k > x } 非空(含 m₁)且在 ℤ 中有下界(被 −m₂ 界住)。这样的整数集合有最小元(良序原理对 ℤ 的下有界版本——把它平移进 ℕ 即可应用)。取这个最小元为 m:m > x,而 m − 1 不再 > x(否则 m 不是最小),即 m − 1 ≤ x。

**唯一性**:若 m、m′ 都满足,则 m − 1 ≤ x < m 且 m′ − 1 ≤ x < m′ 给 |m − m′| < 1,而整数之差小于 1 只能为 0,故 m = m′。∎

(这个 m − 1,就是 x 的**下取整** ⌊x⌋;本引理即「下取整存在」。)

## ℚ 在 ℝ 中稠密

**定理(ℚ 在 ℝ 中稠密).** 对任意 a, b ∈ ℝ,若 a < b,则存在 r ∈ ℚ 使 a < r < b。

**证明.** 思路:先把 a、b 之间的「缝」用一个足够大的 n 放大到「宽度超过 1」,这样缝里必然套得进一个整数;再除回去,那个整数除以 n 就是要找的有理数。

(a) b − a > 0,由阿基米德性质取 n ∈ ℕ 使 n > 1/(b−a)(> 0)。两边乘 (b−a) > 0:n(b − a) > 1,即 **nb > na + 1**。缝被放大到宽度大于 1。

(b) 对实数 na 用整数夹逼引理:存在 m ∈ ℤ 使 m − 1 ≤ na < m。于是

na < m ≤ na + 1 < nb,

中间 m ≤ na + 1 来自 m − 1 ≤ na,末端 na + 1 < nb 来自 (a)。两端同除以 n > 0:

a < m/n < b。

取 r := m/n ∈ ℚ 即可。∎

「先放大缝、套进整数、再除回去」——这个三步是稠密性证明的标准结构。注意它把两件刚证的事(阿基米德放大缝、整数夹逼套整数)拼在了一起。

> **顺带:无理数也稠密。** 任意 a < b 之间也必有无理数。简证:由稠密性,在 a 与 b 之间取有理数 r₁ < r₂(连用两次),则 ξ := r₁ + (r₂ − r₁)/√2 落在 (r₁, r₂) ⊆ (a, b) 内,且 ξ 无理(若 ξ 有理,反解出 √2 = (r₂−r₁)/(ξ−r₁) 有理,与[[num_radice2|√2 无理]]矛盾)。所以**有理数与无理数,在实数轴上彼此交错、都处处稠密**——这是 ℝ 的精细结构的第一瞥。（这里暂用了 √2 在 ℝ 中的存在性,它由 ℝ 的完备性保证,下一节正式给出 n 次根的存在定理。）

## 一道激活练习

(a) 证明:对任意 x ∈ ℝ 与任意 ε > 0,存在 r ∈ ℚ 使 |x − r| < ε。（即:每个实数都能被有理数任意逼近——这是「稠密」最常用的形式。）

(b) 证明:对任意 x ∈ ℝ,存在唯一整数 m 使 m ≤ x < m + 1（下取整 ⌊x⌋ 的标准形式;与正文引理只差一个记号平移,请独立写一遍以熟悉手法）。

（提示:(a) 把稠密性定理用在区间 (x − ε, x + ε) 上。(b) 仿正文引理,或直接对 { k ∈ ℤ : k ≤ x } 取最大元。）

## 参考解答

(建议先自己写完再看。)

**(a)** 因 ε > 0,有 x − ε < x + ε。由 ℚ 在 ℝ 中稠密(取 a = x−ε, b = x+ε),存在 r ∈ ℚ 使 x − ε < r < x + ε。由[[an_valore_assoluto|绝对值]]的 ε-带刻画,这正是 |x − r| < ε。∎

**(b)** 存在性:集合 S := { k ∈ ℤ : k ≤ x } 非空(由阿基米德性质,存在自然数 > −x,其相反数 ≤ x,故在 S 中)且有上界 x。ℤ 的上有界非空子集有最大元(平移进 ℕ 用良序);取最大元 m,则 m ≤ x,而 m + 1 ∉ S 即 m + 1 > x,合起来 m ≤ x < m + 1。唯一性:若 m、m′ 都满足,则 |m − m′| < 1,整数之差小于 1 只能为 0。∎

回顾:(a) 把「稠密」从「两数之间有有理数」改写成了「每个数可被有理数 ε-逼近」——这两种说法等价,但后者是分析里直接要用的形式(下一章定义「有理数列逼近实数」时就是它)。(b) 的下取整,以后取整数部分、做估计时会反复用到。

## 往前看一步

完备性的这两条推论就位了:自然数无界、ℚ 处处稠密。其中阿基米德性质还藏着一个尚未兑现的承诺——本章开头说「造 ℝ 是为了能开平方」。我们已经有了 √2 这个具体的分割,但「任意正实数都有 n 次方根」这条一般定理还没证。它同样是完备性的产物(用 sup 把根「逼出来」),正是 [[num_radici_n|n 次根的存在性]] 的内容。
