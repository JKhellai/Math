## 绝对收敛的深层回报

[[an_convergenza_assoluta|绝对收敛]]比普通收敛「强」,强在哪里?这一节给出三个深刻的回报——**重排自由、求和次序无关、级数可相乘**。它们共同的主题是:**绝对收敛让无穷求和获得了有限求和那样的自由**(可以随意交换次序、可以像多项式那样相乘),而条件收敛则没有这种自由。这是「绝对」二字真正的分量所在。

先用一个小热身,把[[an_convergenza_assoluta|上节的判别法]]用在几个常见极限上。

## 热身：几个增长速度的极限

比值判别法不仅判级数敛散,还能顺手算出几个「谁增长得快」的标准极限——因为「级数收敛 ⟹ 项趋于 0」,只要证某个级数收敛,它的通项就自动趋于 0。

**命题(增长速度).** 设 a > 1,k ∈ ℕ 固定。则

(i) nᵏ/aⁿ → 0（指数 aⁿ 压倒任何多项式 nᵏ）;  (ii) aⁿ/n! → 0（阶乘 n! 压倒任何指数 aⁿ）。

**证明.** 都用「证级数收敛 ⟹ 通项趋零」。

(i) 看级数 Σ nᵏ/aⁿ。比值 ((n+1)ᵏ/a^{n+1})/(nᵏ/aⁿ) = (1+1/n)ᵏ·(1/a) → 1ᵏ·(1/a) = 1/a < 1（因 a>1）。由[[an_convergenza_assoluta|比值判别法]]级数收敛,故通项 nᵏ/aⁿ → 0。

(ii) 看级数 Σ aⁿ/n!。比值 (a^{n+1}/(n+1)!)/(aⁿ/n!) = a/(n+1) → 0 < 1。由比值判别法级数收敛,故 aⁿ/n! → 0。∎

这两条极限(指数压多项式、阶乘压指数)是分析里反复用到的「增长速度排序」:**多项式 ≪ 指数 ≪ 阶乘**(≪ 表示「增长慢得多」)。用级数判别法证它们,比直接估计利落得多——这也补上了[[an_numero_e|单调数列]]那节「几个重要极限」里当时没细证的部分。

## 重排：绝对收敛的级数可以随意调换次序

有限个数相加,次序无所谓(加法交换律)。无穷多个呢?先看一个**警示性的例子**——条件收敛的级数,调换次序竟能改变和!

**例(交错调和级数重排).** 交错调和级数 s = Σ(−1)^{k+1}/k = 1 − 1/2 + 1/3 − 1/4 + ⋯ [[an_convergenza_assoluta|条件收敛]](值是 log 2)。现在把它**重排**——按「一个正项、两个负项」的次序重新排列同样这些项:

1 − 1/2 − 1/4 + 1/3 − 1/6 − 1/8 + 1/5 − 1/10 − 1/12 + ⋯

可以算出(把负项两两与前面的正项配对),这个重排级数收敛到 **s/2 = (log 2)/2**——**同样的项、不同的次序,和变成了一半!**

这说明:**对条件收敛的级数,「无穷和」不满足交换律**——调换次序能改变结果。(更惊人的是 **Riemann 重排定理**:条件收敛级数可以重排成收敛到**任意**指定实数,甚至发散。条件收敛的「和」严重依赖次序。)

但**绝对收敛的级数没有这个毛病**——它的和像有限和一样,与次序无关。

**定理(重排定理).** 设 Σxₖ 绝对收敛。则它的**任何重排** Σx_{σ(k)}（σ 是 ℕ 的任意[[fond_funzioni|双射/置换]]）也绝对收敛,且与原级数有**相同的值**。

**证明.** 由 Σ|xₖ| 收敛,其 [[an_serie|Cauchy 判据]]给出:对每个 ε > 0,存在 N 使

Σ_{k=N+1}^{∞} |xₖ| ≤ ε（尾部绝对值之和任意小）。

设 σ 是任意置换。取 M := max{σ⁻¹(0), …, σ⁻¹(N)}（即原级数前 N+1 项 x₀,…,x_N 在重排后出现的最晚位置）。则对 m ≥ M,重排的前 m 项 {x_{σ(0)},…,x_{σ(m)}} **必定包含** {x₀,…,x_N} 全部。于是这两个部分和之差,只剩下标 > N 的那些项,被尾部绝对值控制:

|Σ_{k=0}^{m} x_{σ(k)} − Σ_{k=0}^{N} xₖ| ≤ Σ_{k=N+1}^{∞} |xₖ| ≤ ε，  m ≥ M。

令 m → ∞:|（重排级数的和）− Σ_{k=0}^{N} xₖ| ≤ ε。而原级数的和也与 Σ_{k=0}^{N}xₖ 相差 ≤ ε。故重排的和与原级数的和相差 ≤ 2ε,对一切 ε 成立,两者相等。绝对收敛性同理(对 |x_{σ(k)}| 重复论证)。∎

**核心机制:绝对收敛时,「尾部绝对值之和任意小」**——所以无论怎么重排,只要取得足够靠后,前面那 N 个重要的项总会被包含进来,而剩下的尾巴贡献可忽略。条件收敛缺的正是这一条:它的尾部绝对值之和**不**趋于零(否则就绝对收敛了),所以重排能把正负项重新搭配出不同的和。**绝对收敛 = 无穷和的交换律。**

这个无穷矩阵可以**按行求和**(先把每行加起来,再加各行和)、**按列求和**,或**按其它任何次序**(如沿对角线)。结果会一样吗?和重排一样,关键在一个绝对型条件。

**定义.** 二重级数 Σx_{jk} 称**可和**(summable)，若部分和的绝对值有统一上界:存在 M 使 Σ_{j,k=0}^{n} |x_{jk}| ≤ M 对一切 n。（这是「二维的绝对收敛」。）

**定理(二重级数定理).** 设 Σx_{jk} 可和。则:把矩阵元素按**任意**次序排成一列([[fond_cardinalita|ℕ×ℕ 可数]],故能排)求和,都绝对收敛到**同一个值** s,与次序无关;特别地,**行和之和 = 列和之和 = s**:

Σ_{j} (Σ_{k} x_{jk}) = Σ_{k} (Σ_{j} x_{jk}) = s。

**思路.** 可和性使任意排列后的级数都被 M 控制,从而绝对收敛;再用[[an_serie|重排]]的思想证明所有排列同值。行和、列和只是两种特殊的「求和次序」,故都等于 s。∎ 直觉:**可和(二维绝对收敛)时,无穷矩阵的元素可以任意次序相加而和不变——行、列、对角线随便加**。又是「绝对型条件买来次序自由」。

## Cauchy 乘积：两个级数相乘

二重级数最重要的应用,是给**两个级数相乘**一个意义。有限和相乘是 (Σxⱼ)(Σyₖ) = Σ_{j,k} xⱼyₖ(每项乘每项)。无穷级数呢?把所有乘积 xⱼyₖ 排成无穷矩阵(第 (j,k) 格是 xⱼyₖ),沿**对角线** j + k = n 收集,就得到 Cauchy 乘积。

**定义(Cauchy 乘积).** 级数 Σxⱼ 与 Σyₖ 的 **Cauchy 乘积**是级数 Σzₙ,其中第 n 项是第 n 条对角线之和:

zₙ := Σ_{k=0}^{n} xₖ y_{n−k} = x₀yₙ + x₁y_{n−1} + ⋯ + xₙy₀。

**定理(Cauchy 乘积).** 若 Σxⱼ 与 Σyₖ 都**绝对收敛**,则它们的 Cauchy 乘积 Σzₙ 也绝对收敛,且

(Σ_{j=0}^{∞} xⱼ)·(Σ_{k=0}^{∞} yₖ) = Σ_{n=0}^{∞} zₙ = Σ_{n=0}^{∞} (Σ_{k=0}^{n} xₖy_{n−k})。

**思路.** 两级数绝对收敛 ⟹ 乘积矩阵 (xⱼyₖ) 可和(其绝对值之和 ≤ (Σ|xⱼ|)(Σ|yₖ|) < ∞);由二重级数定理,矩阵元素可任意次序求和而同值。按「行/列」求和给出 (Σxⱼ)(Σyₖ),按「对角线」求和给出 Σzₙ,故两者相等。∎

**这把「级数相乘」化归到了「绝对收敛 + 二重级数」**。最重要的应用是指数函数的加法定理:用 [[an_serie_potenze|exp(x) = Σxᵏ/k!]] 的级数,算 exp(x)·exp(y) 的 Cauchy 乘积,对角线之和恰好整理成 Σ(x+y)ⁿ/n! = exp(x+y)——**指数律 exp(x)exp(y) = exp(x+y) 由此严格证出**(细节留待指数函数那节)。Cauchy 乘积是连接「级数」与「函数运算」的关键桥梁。

> 注意 Cauchy 乘积定理要求**绝对收敛**。两个只条件收敛的级数,其 Cauchy 乘积可能发散——又一次,绝对收敛是「能相乘」的保证,条件收敛不够。

## 一道激活练习

(a) 写出两个几何级数 Σxⱼ（x₀=x₁=⋯，公比形式这里简化为 Σaʲ）与 Σbᵏ 的 Cauchy 乘积的通项 zₙ。具体地,设 a, b ∈ ℝ,|a|,|b| < 1,求 Σaʲ 与 Σbᵏ 的 Cauchy 乘积 zₙ = Σ_{k=0}^n aᵏb^{n−k}（当 a ≠ b 时化简）。

(b) 用 Cauchy 乘积验证 (Σ_{k=0}^∞ xᵏ)² = Σ_{n=0}^∞ (n+1)xⁿ（|x|<1）。(提示:两个相同的几何级数 Σxᵏ 作 Cauchy 乘积,算 zₙ = Σ_{k=0}^n xᵏ·x^{n−k}。)

(c) 解释为什么交错调和级数能重排成不同的和,而 Σ(−1)ᵏ⁺¹/k² 不能。(提示:看哪个绝对收敛——比较 Σ1/k 与 Σ1/k²。)

## 参考解答

(建议先自己写完再看。)

**(a)** zₙ = Σ_{k=0}^n aᵏb^{n−k} = b^n Σ_{k=0}^n (a/b)ᵏ（提出 bⁿ）。当 a ≠ b,内部是有限几何和 = (1−(a/b)^{n+1})/(1−a/b),整理:

zₙ = bⁿ·(1 − (a/b)^{n+1})/(1 − a/b) = (b^{n+1} − a^{n+1})/(b − a)。

（这也正是 1/((1−a)(1−b)) 展开成幂级数的系数——Cauchy 乘积给出 (Σaʲ)(Σbᵏ) = 1/(1−a)·1/(1−b)。）

**(b)** 两个 Σxᵏ 的 Cauchy 乘积通项:zₙ = Σ_{k=0}^n xᵏ·x^{n−k} = Σ_{k=0}^n xⁿ = (n+1)xⁿ（n+1 个相同的 xⁿ 相加）。故 (Σxᵏ)² = Σ(n+1)xⁿ。∎（左边 = (1/(1−x))² = 1/(1−x)²,所以顺带得到 1/(1−x)² = Σ(n+1)xⁿ,一个有用的展开。）

**(c)** **交错调和级数 Σ(−1)^{k+1}/k 只条件收敛**——绝对值级数 Σ1/k 是发散的[[an_serie|调和级数]]。条件收敛的级数,重排能改变其和(正文的 s/2 例,以及 Riemann 定理)。而 **Σ(−1)^{k+1}/k² 绝对收敛**——绝对值级数 Σ1/k² [[an_serie|收敛]]。由重排定理,绝对收敛级数任意重排和不变。所以前者「能重排出不同的和」、后者「重排和恒不变」,分野正在于**是否绝对收敛**。∎

回顾:这三题围绕同一主线——**绝对收敛是无穷求和获得「有限求和的自由」(交换、相乘)的前提**。(a)(b) 是 Cauchy 乘积的计算(几何级数相乘,对角线求和),(c) 点明重排自由的边界:绝对收敛者有此自由,条件收敛者没有。判断一个无穷求和操作(重排、相乘、换序)是否「安全」,第一步永远是看**绝对收敛**。

## 往前看一步

绝对收敛的三大回报——重排自由、二重级数次序无关、Cauchy 乘积——都已就位。它们共同确立了一个原则:**绝对收敛的无穷和,行为像有限和一样温顺**;而条件收敛则保留了无穷的「危险」(次序敏感)。这套理论,尤其是 Cauchy 乘积,是下一步处理幂级数运算的直接工具。

回到[[an_serie_potenze|幂级数]]:既然幂级数在收敛圆盘内[[an_convergenza_assoluta|绝对收敛]],就能对它们做代数运算——**两个幂级数相加、相乘**(乘法正是 Cauchy 乘积),结果仍是幂级数。还有一个深刻的事实:**幂级数的表示是唯一的**——若两个幂级数在原点附近处处相等,则它们逐项系数相同(恒等定理)。这让「比较系数」成为合法手段,是幂级数方法的基石。这就是第二章最后一块:[[an_operazioni_serie_potenze|幂级数的运算与唯一性]]。
