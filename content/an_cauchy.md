## 不靠极限点判断收敛

到目前为止,判断一个数列收敛,要么[[an_algebra_limiti|算出极限]]、要么找[[an_confronto|夹板]]、要么靠[[an_monotone|单调有界]]——前两者都得对「极限是什么」有所掌握,第三个只管单调数列。但有一大类数列,既不单调、又算不出极限,却明显在「收拢」:项与项之间越来越靠近。能不能**不引入任何外部的极限点**,只看数列**自己**的项,就判定它收敛?

Cauchy 给了一个深刻的答案。他的想法是:与其问「项是否靠近某个外部的 a」,不如问「**项之间**是否最终任意接近」。

**定义(Cauchy 列).** 度量空间 (X, d) 中的数列 (xₙ) 称 **Cauchy 列**(Cauchy sequence)，若:对每个 ε > 0,存在 N ∈ ℕ,使得

d(xₙ, xₘ) < ε，  对一切 m, n ≥ N。

注意它和[[an_convergenza|收敛]]定义的根本区别:收敛说「项与**极限 a** 的距离 < ε」,需要一个外部的 a;Cauchy 说「**项与项**的距离 < ε」,**只牵涉数列自己**。这个差别看似微小,意义重大——Cauchy 条件可以在不知道、甚至不存在极限的情况下检验。

## 收敛 ⟹ Cauchy

一个方向是容易的,且对**任何**度量空间成立。

**命题.** 每个收敛数列都是 Cauchy 列。

**证明.** 设 xₙ → x。给定 ε > 0,存在 N 使 n ≥ N 时 d(xₙ, x) < ε/2。则对 m, n ≥ N,由三角不等式

d(xₙ, xₘ) ≤ d(xₙ, x) + d(x, xₘ) < ε/2 + ε/2 = ε。

故 (xₙ) 是 Cauchy 列。∎

直觉:如果所有项最终都挤在极限 x 附近半径 ε/2 的球里,那它们彼此之间自然不会超过 ε 远。极限点 x 在这里只是「中转」——经过它用一次三角不等式,就把「项靠近 x」转成了「项之间靠近」。

## 逆命题为何需要完备性：ℚ 里的反例

反过来——**Cauchy ⟹ 收敛——却不是对所有度量空间都成立**。这正是「完备」与否的分水岭。在 ℚ 里,它就失败。

**例.** 在 ℚ 中递归定义 x₀ := 2,x_{n+1} := ½(xₙ + 2/xₙ)。则 (xₙ) 是 ℚ 中的 Cauchy 列,但在 ℚ 中**不收敛**。

这就是求 √2 的牛顿迭代。算几项:

x₀ = 2,  x₁ = 1.5,  x₂ ≈ 1.41667,  x₃ ≈ 1.414216,  x₄ ≈ 1.414214, …

每个 xₙ 都是有理数(有理数的四则运算仍是有理数)。这串数收敛到 √2(在 ℝ 中),所以它在 ℝ 中收敛、从而是 Cauchy 列([[an_convergenza|收敛⟹Cauchy]]),而 Cauchy 条件只关乎项之间的距离,在 ℚ 里检验和在 ℝ 里检验是同一回事——故它在 ℚ 中也是 Cauchy 列。

但它在 ℚ 中**不收敛**:若 xₙ → a 且 a ∈ ℚ,则它在 ℝ 中也收敛到 a([[an_convergenza|极限唯一]]),于是 a = √2;可 √2 [[num_radice2|不是有理数]],矛盾。所以这个 Cauchy 列在 ℚ 里找不到极限——**它要靠近的那个点,恰好是 ℚ 的一个洞**。

这个反例点破了完备性的实质:**Cauchy 列总在「收拢」,但收拢的目标点可能不在空间里**。ℚ 有洞,洞处的 Cauchy 列就无家可归。ℝ 之所以「完备」,正是因为它把这些洞全填上了——每个 Cauchy 列收拢的目标,在 ℝ 里都真实存在。

## Cauchy 列的两条性质

要证「在 ℝ 中 Cauchy ⟹ 收敛」,先备两块。

**命题(Cauchy ⟹ 有界).** 每个 Cauchy 列有界。

**证明.** 取 ε = 1:存在 N 使 m, n ≥ N 时 d(xₙ, xₘ) < 1。特别地,对 n ≥ N,d(xₙ, x_N) < 1。开头的有限项 x₀, …, x_{N−1} 与 x_N 的距离有最大值 M₀。取 M := M₀ + 1,则所有项到 x_N 的距离 ≤ M,数列有界。∎(与[[an_convergenza|收敛⟹有界]]同一手法:尾部挤在一起、前段有限,合起来有界。)

**命题(有收敛子列的 Cauchy 列必收敛).** 若 Cauchy 列 (xₙ) 有一个子列收敛到 x,则 (xₙ) 整列收敛到 x。

**证明.** 设子列 x_{n_k} → x。给定 ε > 0。由 Cauchy 性,存在 N 使 m, n ≥ N 时 d(xₙ, xₘ) < ε/2;由子列收敛,存在 K 使 k ≥ K 时 d(x_{n_k}, x) < ε/2。取一个足够大的下标 n_k(同时满足 k ≥ K 且 n_k ≥ N),则对一切 n ≥ N,

d(xₙ, x) ≤ d(xₙ, x_{n_k}) + d(x_{n_k}, x) < ε/2 + ε/2 = ε。

故 xₙ → x。∎ 直觉:Cauchy 列「全体挤在一起」,只要有**一个**子列找到了归宿 x,整列就被它带着一起收敛到 x——因为整列和这个子列本就贴在一起。

## 主定理：ℝ 与 ℂ 完备

三块齐备,拼出主定理。

**定理.** 在 ℝ(及 ℂ)中,数列收敛 **当且仅当** 它是 Cauchy 列。

**证明.** 「收敛 ⟹ Cauchy」已证(对任何度量空间成立)。「Cauchy ⟹ 收敛」:设 (xₙ) 是 ℝ 中的 Cauchy 列。由「Cauchy ⟹ 有界」,它有界;由 [[an_bolzano_weierstrass|Bolzano–Weierstrass]],有界数列有收敛子列;由「有收敛子列的 Cauchy 列必收敛」,(xₙ) 整列收敛。ℂ 同理(或视作 ℝ²)。∎

看清这条证明链:**Cauchy → 有界 →(B–W)收敛子列 →(带动整列)收敛**。Bolzano–Weierstrass 是其中不可替代的引擎——正是它把「自我收拢」兑现成「真的有个极限点」,而这一步的底层依据,是 ℝ 的完备性。

## 完备空间与 Banach 空间

把这条性质抽象出来,命名:

**定义.** 度量空间 (X, d) 称**完备**(complete)，若其中每个 Cauchy 列都收敛(到空间内的点)。完备的赋范向量空间称 **Banach 空间**(Banach space)。

于是上面的定理一句话:**ℝ 和 ℂ 是完备度量空间**(更进一步是 Banach 空间)。而 ℚ **不完备**——那个逼近 √2 的 Cauchy 列就是反证。完备性从此有了一个不依赖序、对任何度量空间都说得通的表述:「Cauchy 列都有归宿」。这比「上确界存在」更通用——后者要序,前者只要距离,所以它能搬到 ℝⁿ、函数空间等没有自然序的地方,成为现代分析里「完备」的标准定义。

> 一个回响:[[num_dedekind|Dedekind 分割]]那节我们提过,造 ℝ 有两条路——分割,以及「Cauchy 列的完备化」。后者正是用本节的语言:把 ℚ 的所有 Cauchy 列收集起来、按「差为零列」归类,商出的就是 ℝ,每个洞由一个收拢于它的 Cauchy 列填上。我们走了分割那条路;但 Cauchy 完备化是等价的另一条,且更容易推广到一般度量空间(任何度量空间都能这样「补全」成完备的)。两条路殊途同归。

## 一道激活练习

(a) 用 Cauchy 判据证明:若 (xₙ) 满足 |x_{n+1} − xₙ| ≤ (1/2)ⁿ 对一切 n,则 (xₙ) 收敛。(提示:估计 |x_{n+p} − xₙ|,用三角不等式拆成相邻差之和,再用几何级数 Σ(1/2)ᵏ 的尾部 → 0 说明它是 Cauchy 列;ℝ 完备故收敛。注意:你**不需要**算出极限。)

(b) 举例说明 (a) 中的条件 |x_{n+1} − xₙ| → 0(只要求相邻差趋于 0)**不足以**保证收敛。(提示:部分和 xₙ = 1 + 1/2 + 1/3 + ⋯ + 1/n——相邻差 1/n → 0,但这个数列发散,你以后会在级数里证;先直观接受或用「xₙ 无界」论证。)

## 参考解答

(建议先自己写完再看。)

**(a)** 验证 Cauchy。对 n < n+p,由三角不等式把跨度拆成相邻差之和:

|x_{n+p} − xₙ| ≤ |x_{n+p} − x_{n+p−1}| + ⋯ + |x_{n+1} − xₙ| ≤ Σ_{k=n}^{n+p−1} (1/2)ᵏ。

这个和 ≤ Σ_{k=n}^{∞} (1/2)ᵏ = (1/2)ⁿ/(1 − 1/2) = 2·(1/2)ⁿ = (1/2)^{n−1}。给定 ε > 0,因 (1/2)^{n−1} → 0([[an_monotone|几何数列]]),取 N 使 (1/2)^{N−1} < ε。则对一切 m = n+p > n ≥ N,|xₘ − xₙ| ≤ (1/2)^{n−1} ≤ (1/2)^{N−1} < ε。故 (xₙ) 是 Cauchy 列;ℝ 完备,故收敛。∎(全程没算极限——这正是 Cauchy 判据的威力。)

**(b)** 取 xₙ := Σ_{k=1}^{n} 1/k = 1 + 1/2 + ⋯ + 1/n(调和级数部分和)。相邻差 |x_{n+1} − xₙ| = 1/(n+1) → 0,满足「相邻差趋于 0」。但 (xₙ) 发散:它无界(可证 x_{2ᵐ} ≥ 1 + m/2,随 m 增到无穷;严格证明留待级数)。所以「相邻差 → 0」是收敛的必要条件,**远不充分**——Cauchy 要求的是「**任意远**的两项 d(xₙ, xₘ) 都小」(m, n 都 ≥ N 即可,无论相距多远),而非只是「相邻两项」小。这个区别是 Cauchy 判据的精髓:(a) 里相邻差按 (1/2)ⁿ 几何式衰减,快到连「任意远」的跨度求和都受控;(b) 里相邻差按 1/n 衰减,太慢,跨度一拉长求和就发散。∎

回顾:Cauchy 判据的关键,是控制「**任意两项**」之距,而非相邻两项。(a)(b) 的对比正卡在这里——同样是「相邻差趋于 0」,几何式衰减(快)给出 Cauchy 列、调和式衰减(慢)不给。用 Cauchy 判据时,务必估计 |x_{n+p} − xₙ| 对**所有** p 一致地小,这一步通常归结为某个级数尾部的控制。

## 往前看一步

数列收敛的理论到此完整:定义(ε–N)、唯一性、有界、子列、聚点、运算法则、夹逼、单调收敛、e、Bolzano–Weierstrass、Cauchy 完备——ℝ 与 ℂ 上「一列点如何趋于一个点」已被彻底厘清。

但「无限相加」还没真正展开。Cauchy 判据其实已经叩到了门口:把一串数 a₀, a₁, a₂, … **依次累加**,得到部分和 sₙ = a₀ + ⋯ + aₙ,这个部分和数列收不收敛?它收敛,就说无穷级数 Σaₖ「收敛」,其极限就是这个「无穷和」的值。e = Σ 1/k!、以及各种把函数展成无穷次多项式的展开,都属于这个主题。而判断级数收敛最根本的工具,正是刚建立的 Cauchy 判据(用在部分和数列上)与完备性。这就是分析的下一大块:**无穷级数**。
