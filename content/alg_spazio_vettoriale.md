## 把「能加、能伸缩」抽象出来

代数主干此前造了三种结构:[[alg_gruppi|群]]、[[alg_anelli|环]]、[[alg_campi|域]]——它们刻画的是「一个集合上的运算」。现在引入第四种,它的味道略有不同:它涉及**两个**集合的协作——一堆「向量」,和一个用来「缩放」向量的[[alg_campi|域]](称**标量**)。这就是**向量空间**,线性代数的中心对象。

动机来自最熟悉的例子:平面 ℝ² 或空间 ℝ³ 里的向量。它们能做两件事——**相加**(首尾相接,或平行四边形法则)和**数乘**(被一个实数拉伸/压缩/反向):

把这两件事的运算规律抽出来、立成公理,就得到向量空间——而抽象的回报是:**不只几何向量,函数、多项式、数列……一大批看似无关的对象,都满足同一套规律,于是线性代数的一切定理对它们一并成立**。

## 定义

固定一个[[alg_campi|域]] 𝕂(它的元素称**标量** scalar;最常用的是 𝕂 = ℝ 或 ℂ)。

**定义(向量空间).** 𝕂 上的一个**向量空间**(vector space)是一个集合 V,配上两个运算:
- **加法** V × V → V,(u, v) ↦ u + v;
- **数乘**(scalar multiplication)𝕂 × V → V,(a, v) ↦ a·v,

满足以下公理(u, v, w ∈ V,a, b ∈ 𝕂):

- **(V1)** 加法交换:u + v = v + u;
- **(V2)** 加法结合:(u + v) + w = u + (v + w);
- **(V3)** 零向量:存在 0 ∈ V,使 v + 0 = v 对一切 v;
- **(V4)** 加法逆:每个 v 有 w ∈ V 使 v + w = 0;
- **(V5)** 数乘结合:(ab)·v = a·(b·v);
- **(V6)** 幺元:1·v = v(1 是 𝕂 的乘法幺元);
- **(V7)** 数乘对向量加法分配:a·(u + v) = a·u + a·v;
- **(V8)** 数乘对标量加法分配:(a + b)·v = a·v + b·v。

V 的元素称**向量**(vector)。

## 它就是「交换群 + 相容的数乘」

直接看这八条会觉得零碎,但换个角度,它们其实是两块拼起来的——**而两块我们都学过**。

**看前四条 (V1)–(V4):** 它们一字不差地就是说 **(V, +) 是一个[[alg_gruppi|交换群]]**(阿贝尔群)——加法封闭、结合、有单位元 0、有逆元,且交换。所以向量空间的「加法那一半」,**完全是一个我们早已研究透的交换群**;[[alg_gruppi|群]]那节证过的一切(单位元唯一、逆元唯一……)立刻适用。

**看后四条 (V5)–(V8):** 它们规定数乘如何与加法、与标量的运算**相容**——数乘结合 (V5)、幺元 (V6)、两条分配律 (V7)(V8)。这是「域 𝕂 如何作用在群 V 上」的相容条件。

所以一句话:**向量空间 = 一个交换群 (V, +),外加一个域 𝕂 通过相容的数乘作用在它上面。** 这不是巧合的类比,而是精确的结构分解——它让我们把向量空间接到了已有的地基上,而不是凭空起步。(在更高的抽象里,「域作用在交换群上」一般化为「环作用在交换群上」,产物称**模** module;向量空间正是「域上的模」这一最规整的特例。一般模理论留待抽象代数。)

> **一处与教材的分歧,值得说明。** 许多线性代数教材(如 Axler)刻意只在 𝕂 = ℝ 或 ℂ 上定义向量空间,回避「一般的域」,因为对初学者而言抽象的域是额外负担。但**我们不必回避——因为我们已经从公理造好了[[alg_campi|域]]**。在一般域 𝕂 上定义向量空间,不仅更通用(将来有限域上的向量空间在编码、密码学里要用),而且**更干净**:它清楚地暴露出「向量空间依赖一个域」这个结构事实。这是我们的公理化地基带来的好处——别人要回避的抽象,在我们这里是现成的。

## 例子：抽象的威力

下面这些对象,验证一下都满足八条公理,于是都是向量空间——线性代数对它们一视同仁。

**(a) 坐标空间 𝕂ⁿ.** 全体 n 元组 (x₁, …, xₙ)(xᵢ ∈ 𝕂),逐分量加法、逐分量数乘。这是最基本的例子,ℝⁿ、ℂⁿ 都是它的特例。零向量是 (0, …, 0)。([[an_succ_complesse|复数列]]里把 ℂ 看成 ℝ² 时,用的就是 ℝ² 这个向量空间结构。)

**(b) 函数空间.** 设 S 是任意集合,𝕂^S := { f : S → 𝕂 } 全体从 S 到 𝕂 的函数,加法 (f+g)(s) := f(s)+g(s)、数乘 (af)(s) := a·f(s)([[fond_funzioni|函数]]的逐点运算)。零向量是常值零函数。这个例子说明向量空间远不止「箭头」——**函数也是向量**。微分方程、傅里叶分析的舞台,正是这种函数空间。

**(c) 多项式空间.** 系数在 𝕂 中的全体多项式 𝕂[X],通常的加法与数乘。零向量是零多项式。(以及它的子类:次数 ≤ n 的多项式,记 𝕂[X]_{≤n}。)

**(d) 零空间.** {0} ——只含一个零向量,八条公理平凡满足。这是最小的向量空间,以后常作边界情形。

把 (a)(b)(c) 摆在一起看:n 元组、函数、多项式,外表毫无相似之处,却服从同一套公理。**这正是公理化的力量——证一次定理,处处适用**;线性代数后面所有关于「维数」「线性映射」「特征值」的结论,对这三者(及更多)同时成立,不必各讲一遍。

## 几条基本推论

像当初对[[alg_gruppi|群]]、[[alg_campi|域]]那样,从公理推出几条「显然但需证明」的基本性质。前两条直接搬用群的结论。

**零向量唯一、加法逆唯一.** (V1)–(V4) 说 (V,+) 是交换群,而[[alg_gruppi|群]]那节已证「单位元唯一、逆元唯一」。所以向量空间的零向量 0 唯一,每个 v 的加法逆唯一,记作 −v。∎(又一次「在更大结构里,旧定理直接复用」——不必重证。)

**0·v = 0**(标量 0 乘任何向量得零向量)。**证明:** 0·v = (0+0)·v = 0·v + 0·v(用 (V8),标量 0+0=0)。两边加 −(0·v):0 = 0·v。∎ (注意区分两个 0:等号左边 0 ∈ 𝕂 是标量零,右边 0 ∈ V 是零向量。)

**(−1)·v = −v**(标量 −1 乘 v,得 v 的加法逆)。**证明:** v + (−1)·v = 1·v + (−1)·v = (1 + (−1))·v = 0·v = 0(依次用 (V6)、(V8)、𝕂 中 1+(−1)=0、刚证的 0·v=0)。所以 (−1)·v 满足「加到 v 上得 0」,由加法逆唯一,它就是 −v。∎

这三条的证明值得回味:**它们几乎只用到「交换群 + 分配律」**,和当初[[alg_anelli|环]]里证「0·x = 0」「(−1)x = −x」如出一辙——因为分配律是共同的引擎。结构不同(那里是环,这里是向量空间),手法却同源:**把要证的量,通过分配律拆成自己与自己的关系,再消去**。

## 一道激活练习

(a) 设 V 是 𝕂 上的向量空间,a ∈ 𝕂,v ∈ V。证明 **a·0 = 0**(标量 a 乘零向量得零向量;注意与正文「0·v = 0」对称,但这里是标量非零、向量为零)。(提示:a·0 = a·(0+0),用 (V7)。)

(b) 证明:若 a·v = 0(a ∈ 𝕂,v ∈ V),则 **a = 0 或 v = 0**。(这是向量空间版的「无零因子」。提示:设 a ≠ 0,则 a 在域 𝕂 中可逆;两边数乘 a⁻¹,用 (V5)(V6) 和 (a) 的结论。)

(c) 验证:次数**恰好**为 2 的多项式全体（连同零多项式）在通常加法下**不**构成向量空间——指出哪条公理被破坏。(提示:试把 X² 与 −X²+X 相加,结果的次数是多少？还在这个集合里吗？)

## 参考解答

(建议先自己写完再看。)

**(a)** a·0 = a·(0 + 0)（零向量 0+0=0,由 (V3)）= a·0 + a·0（分配律 (V7)）。两边加 −(a·0):0 = a·0。∎（与正文 0·v=0 的证明同构,只是这次拆的是零向量、用 (V7) 而非 (V8)。）

**(b)** 设 a ≠ 0。因 𝕂 是[[alg_campi|域]],a 有乘法逆 a⁻¹。对 a·v = 0 两边数乘 a⁻¹:

a⁻¹·(a·v) = a⁻¹·0。

左边 = (a⁻¹a)·v（(V5) 数乘结合）= 1·v（𝕂 中 a⁻¹a=1）= v（(V6)）;右边 = 0（由 (a),标量乘零向量）。故 v = 0。所以「a ≠ 0」时必有 v = 0,即 a = 0 或 v = 0。∎

**(c)** 这个集合对加法**不封闭**,破坏了加法的封闭性(它是「+ 是 V×V→V 的运算」这一前提的一部分,也可看作 (V3)/(V2) 赖以成立的基础——运算必须不越出集合)。反例:X² 和 −X² + X 都是次数恰为 2 的多项式,但它们的和

X² + (−X² + X) = X，

次数是 1,**不在**「次数恰为 2」的集合里。加法把两个元素加出了集合之外,所以这不是向量空间。(对比:次数 ≤ 2 的多项式就没问题——和的次数仍 ≤ 2,封闭。「恰好等于」破坏封闭,「不超过」保持封闭,这个区别以后定义子空间时关键。)∎

回顾:(c) 点出一个易错点——**向量空间要求运算「封闭」**(加法、数乘的结果仍在集合内),这是比八条公理更基础的前提。「次数恰为 n」这类「等式约束」常常破坏封闭性,而「次数 ≤ n」「等于零」这类「不等式或齐次约束」往往保持封闭。下一节的子空间,核心就是「哪些子集对运算封闭、从而自己也是向量空间」。

## 往前看一步

向量空间的舞台搭好了,八条公理把「能加、能伸缩」精确化,并接到了[[alg_gruppi|交换群]]与[[alg_campi|域]]的地基上。但一个向量空间往往很大(如全体函数),我们常关心它**内部的、自身也构成向量空间的子集**——比如 ℝ³ 里过原点的平面、全体多项式里次数 ≤ n 的那些。这种「空间里的空间」称**子空间**(subspace)。判定一个子集是不是子空间,不必重验全部八条公理——只需查它对加法和数乘**封闭**(练习 (c) 已经触到这个关键)。这就是 [[alg_sottospazi|子空间]] 的内容,也是通向「张成、线性无关、基、维数」的第一步。
