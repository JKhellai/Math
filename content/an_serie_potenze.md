## 把级数变成函数

[[an_convergenza_assoluta|绝对收敛]]那节的指数级数 Σzᵏ/k! 已经透露了下一步:把级数的项里放进一个**变量**。一般地,取一列系数 (aₖ),考虑

Σ_{k=0}^{∞} aₖxᵏ = a₀ + a₁x + a₂x² + a₃x³ + ⋯，

其中 x 是变量。这就是**幂级数**(power series)——形式上是「无穷次多项式」。对每个具体的 x,它是一个普通[[an_serie|级数]];这个级数收敛与否、收敛到什么,取决于 x。于是幂级数定义了一个**函数**:在它收敛的那些 x 处,函数值就是级数的和。

**定义(幂级数与收敛域).** 设 (aₖ) 是 𝕂 中一列系数。幂级数 Σaₖxᵏ 的**收敛域**(domain of convergence)是

dom := { x ∈ 𝕂 : Σaₖxᵏ 收敛 }，

在其上定义函数

a(x) := Σ_{k=0}^{∞} aₖxᵏ,  x ∈ dom。

注意 0 总在 dom 里(x = 0 时级数 = a₀,平凡收敛)。问题是:除了 0,还有哪些 x 使它收敛?

幂级数为什么重要,一句话:**初等函数大多是幂级数**。指数、正弦、余弦、对数,都能写成幂级数,从而获得严格的定义——这是把「函数」建立在「无穷级数」这块已经夯实的地基上的关键一步。本节先解决最基础的问题:**一个幂级数到底在哪些 x 处收敛?**

## 收敛域的三种形态

先看三个例子,它们恰好展示收敛域的三种可能。

**(a) 指数级数 Σxᵏ/k!:处处收敛。** [[an_convergenza_assoluta|上节用比值判别法]]证过它对一切 x ∈ ℂ 绝对收敛。故 dom = ℂ(整个 𝕂)。它定义的函数就是**指数函数** exp。

**(b) 几何级数 Σxᵏ:在单位圆盘内收敛。** [[an_serie|几何级数]]当 |x| < 1 时收敛到 1/(1−x),当 |x| ≥ 1 时发散(项不趋于 0)。故 dom = { x : |x| < 1 },一个圆盘。它定义的函数是 1/(1−x)。

**(c) Σk!xᵏ:只在 0 收敛。** 对任意 x ≠ 0,用比值判别法:|（k+1)!x^{k+1}| / |k!xᵏ| = (k+1)|x| → ∞,故发散。所以 dom = {0},除原点外处处发散。

三个例子,三种收敛域:**整个 𝕂、一个圆盘、仅一个点**。它们的共同结构是——收敛域总是「以原点为心的某种圆盘」(退化情形是半径 ∞ 的「全平面」或半径 0 的「一个点」)。下面的定理把这件事说精确。

## 收敛半径与 Cauchy–Hadamard 公式

**定理(收敛半径).** 对任意幂级数 Σaₖxᵏ,存在唯一的 ρ ∈ [0, ∞](称**收敛半径** radius of convergence),使得:

- 当 **|x| < ρ** 时,级数**绝对收敛**;
- 当 **|x| > ρ** 时,级数**发散**。

且 ρ 由 **Cauchy–Hadamard 公式** 给出:

ρ = 1 / ( lim sup_{k→∞} ᵏ√|aₖ| )。

（约定:若 lim sup = ∞ 则 ρ = 0;若 lim sup = 0 则 ρ = ∞。）集合 { x : |x| < ρ } 称**收敛圆盘**(disk of convergence)。

**证明.** 把 ρ 定义为公式右边。对固定的 x,看级数 Σaₖxᵏ 的**根值判别法**——算它的项 aₖxᵏ 的 k 次根:

lim sup_{k→∞} ᵏ√|aₖxᵏ| = lim sup_{k→∞} (|x|·ᵏ√|aₖ|) = |x|·lim sup_{k→∞} ᵏ√|aₖ| = |x|/ρ。

(|x| 是常数,可提到 lim sup 外。)由[[an_convergenza_assoluta|根值判别法]]:这个 lim sup < 1 时绝对收敛、> 1 时发散。即

|x|/ρ < 1 （亦即 |x| < ρ）⟹ 绝对收敛;　|x|/ρ > 1 （亦即 |x| > ρ）⟹ 发散。

正是所断言的。∎

**这就是[[an_limsup|上极限]]的第二次关键登场。** 当初补 lim sup 时说它是「根值判别法和收敛半径的必备工具」——现在兑现:Cauchy–Hadamard 公式 ρ = 1/limsup ᵏ√|aₖ| 里的 lim sup **不能换成 lim**,因为 ᵏ√|aₖ| 这个数列一般不收敛(系数 aₖ 可以毫无规律),只有它的[[an_limsup|上极限总存在]]。正是上极限的「无条件存在性」,让每个幂级数都有一个确定的收敛半径。

> **边界 |x| = ρ 上发生什么,公式不回答**——圆周上可能收敛、可能发散,需逐例分析。例如 Σxᵏ/k 的 ρ = 1:在 x = 1 处是发散的[[an_serie|调和级数]],在 x = −1 处是收敛的[[an_convergenza_assoluta|交错调和级数]]。同一个圆周上,不同点不同命运。这是幂级数理论里精细的一面,这里先记住「边界另议」。

## 用比值判别法求半径

Cauchy–Hadamard 公式理论上完美(对一切幂级数成立),但 lim sup ᵏ√|aₖ| 有时不好算。当系数比值的极限存在时,[[an_convergenza_assoluta|比值判别法]]给出一个更易用的公式。

**命题.** 若 lim_{k→∞} |aₖ/aₖ₊₁| 存在(在 ℝ̄ 中),则收敛半径

ρ = lim_{k→∞} |aₖ / aₖ₊₁|。

**思路.** 对固定 x ≠ 0,级数 Σaₖxᵏ 的相邻项之比 |aₖ₊₁x^{k+1}|/|aₖxᵏ| = |x|·|aₖ₊₁/aₖ| → |x|/ρ。由[[an_convergenza_assoluta|比值判别法]],|x|/ρ < 1 收敛、> 1 发散,得半径 ρ。∎ 实践中,**系数含阶乘或幂时,比值公式通常比根值公式好算**——这与上节「比值比根值易算」一脉相承。

## 例子：算几个收敛半径

**指数级数 Σxᵏ/k!:** aₖ = 1/k!。用比值公式:|aₖ/aₖ₊₁| = (1/k!)/(1/(k+1)!) = (k+1)! / k! = k+1 → ∞。故 **ρ = ∞**,处处收敛——印证了它定义 exp 于整个 ℂ。

**几何级数 Σxᵏ:** aₖ = 1。|aₖ/aₖ₊₁| = 1 → 1,故 **ρ = 1**——印证收敛圆盘是单位圆盘。

**Σk!xᵏ:** aₖ = k!。|aₖ/aₖ₊₁| = k!/(k+1)! = 1/(k+1) → 0,故 **ρ = 0**——只在原点收敛。

**Σxᵏ/k²(以及 Σxᵏ/k):** aₖ = 1/k²。|aₖ/aₖ₊₁| = (k+1)²/k² = (1+1/k)² → 1,故 **ρ = 1**。这两个级数收敛圆盘都是单位圆盘,但边界行为不同(Σxᵏ/k² 在整个边界收敛,Σxᵏ/k 在 x=1 发散)——再次说明边界需单独看。

## 初等函数即将由幂级数定义

收敛半径理论的意义,在于它为「用幂级数定义函数」扫清了最后障碍:**只要算出 ρ > 0,幂级数就在收敛圆盘上定义了一个货真价实的函数**。下一阶段(微分理论之后)将看到:

- **指数函数** exp(x) := Σ xᵏ/k!（ρ = ∞,定义在整个 ℂ）;
- **正弦、余弦** sin(x) := Σ (−1)ᵏ x^{2k+1}/(2k+1)!,cos(x) := Σ (−1)ᵏ x^{2k}/(2k)!（ρ = ∞）;
- **对数** log(1+x) := Σ (−1)^{k+1} xᵏ/k（ρ = 1，在单位圆盘内）。

这些定义把初等函数**完全建立在级数(从而极限、完备性)的地基上**,不再依赖几何直觉或「中学的定义」。指数与三角函数的全部性质(exp 的加法定理、sin²+cos²=1、欧拉公式 e^{ix}=cos x+i sin x),都将从幂级数严格推出。这是分析「把熟悉的函数重新严格化」的核心工程,而收敛半径保证了这些级数确实定义了函数。

## 一道激活练习

求下列幂级数的收敛半径 ρ:

(a) Σ_{k=0}^∞ 2ᵏ xᵏ（提示:比值公式,aₖ = 2ᵏ）;

(b) Σ_{k=1}^∞ xᵏ/k!（注:这是 exp 去掉常数项的尾巴,但请独立用比值公式算）;

(c) Σ_{k=0}^∞ xᵏ/2^{k²}（提示:这里比值 aₖ/aₖ₊₁ = 2^{(k+1)²}/2^{k²} = 2^{2k+1} → ∞,故 ρ = ∞;或用根值 ᵏ√|aₖ| = ᵏ√(1/2^{k²}) = 1/2ᵏ → 0,Cauchy–Hadamard 给 ρ = 1/0 = ∞）;

(d) Σ_{k=1}^∞ kᵏ xᵏ（提示:根值公式更顺,ᵏ√|aₖ| = ᵏ√(kᵏ) = k → ∞,故 ρ = 1/∞ = 0）。

## 参考解答

(建议先自己写完再看。)

**(a)** aₖ = 2ᵏ。比值:|aₖ/aₖ₊₁| = 2ᵏ/2^{k+1} = 1/2 → 1/2。故 **ρ = 1/2**。(收敛圆盘 |x| < 1/2;直观:Σ(2x)ᵏ 是公比 2x 的几何级数,|2x| < 1 即 |x| < 1/2 时收敛,一致。)

**(b)** aₖ = 1/k!。比值:|aₖ/aₖ₊₁| = (k+1)!/k! = k+1 → ∞。故 **ρ = ∞**,处处收敛。(与指数级数同,去掉常数项不改收敛半径。)

**(c)** 用根值最直接:ᵏ√|aₖ| = ᵏ√(1/2^{k²}) = (2^{k²})^{−1/k} = 2^{−k} = 1/2ᵏ → 0。由 Cauchy–Hadamard,ρ = 1/(lim sup ᵏ√|aₖ|) = 1/0 = **∞**。处处收敛。(系数衰减极快,2^{k²} 比任何几何级数都快,故收敛域无限大。)

**(d)** 用根值:ᵏ√|aₖ| = ᵏ√(kᵏ) = k → ∞。由 Cauchy–Hadamard,ρ = 1/∞ = **0**。只在原点收敛。(系数 kᵏ 增长极快,压垮任何 xᵏ，x≠0 即发散——与 Σk!xᵏ 同类。)

回顾:求收敛半径的两把工具——**系数含阶乘或简单幂(2ᵏ、1/k!)用比值公式 ρ = lim|aₖ/aₖ₊₁|;系数形如 (k 的函数)ᵏ 或 2^{k²} 这类「k 进入指数」的,用根值/Cauchy–Hadamard ρ = 1/limsup ᵏ√|aₖ|（方根能消掉外层 k 次幂)**。(c)(d) 都是根值更顺的情形。Cauchy–Hadamard 是万能的(对一切幂级数成立),比值公式是它在「比值极限存在」时的便捷特例。

## 往前看一步

收敛半径理论为初等函数的严格定义铺好了路,A–E 第二章「收敛」到此画上句号:从[[an_convergenza|数列收敛]]、[[an_cauchy|完备性]],到[[an_serie|级数]]、判别法,再到本节的幂级数——「逼近」与「无限求和」的理论完整了。

但幂级数现在还只是「能定义函数」,我们尚不能对它做分析运算——**求导、积分**。下一大块(第三章起)进入**函数的分析**:先是**连续性**(函数极限、连续函数的性质),再是**微分**(导数、微分中值定理)。届时会证明:幂级数在收敛圆盘内可以**逐项求导、逐项积分**,且导数仍是幂级数——这将让我们轻松地从 exp 的级数推出 exp' = exp、从 sin/cos 的级数推出它们的导数关系。而**导数**,正是你那条暂停的[[物理线]]一直等待的汇合点:速度是位移的导数、加速度是速度的导数,牛顿力学的语言就是微积分。连续与微分,是分析的下一座山,也是数学与物理重新合流的地方。
