## 为什么要两个理想端点

这是数系准备的最后一节,内容是约定而非定理——但这个约定会让后面整个极限理论的叙述干净许多。

动机是这样:[[num_estremo_superiore|上确界]]那节的完备性公理,只对**有上界**的非空集合保证 sup 存在。可现实里常遇到无上界的集合,比如 ℕ 本身（[[num_archimede|阿基米德性质]]说它无上界）,或者「数列趋向无穷」这种情形。每次都要分「有界/无界」两种情况来叙述,既啰嗦又割裂。

解决办法是给数轴**添两个理想端点**:一个比所有实数都大的 +∞,一个比所有实数都小的 −∞。有了它们,「ℕ 没有最小的实数上界」就可以统一说成「ℕ 的上确界是 +∞」;「数列无限增大」可以说成「趋于 +∞」。注意:**±∞ 不是实数**,它们是两个新添的符号,专为「安放无界情形」而设。

## 定义与序

**定义.** 扩展实数轴(extended number line)

ℝ̄ := ℝ ∪ { +∞, −∞ }，

并约定序:对一切 x ∈ ℝ,

−∞ < x < +∞。

加上 ℝ 自身原有的序,ℝ̄ 成为一个**全序集**——任两个元素可比较,−∞ 最小、+∞ 最大,中间是原来的实数轴。

## 部分扩展的运算

把加法、乘法**部分地**延伸到 ℝ̄。说「部分」,是因为有些组合无法自洽地赋值(下面会看到),那些组合一律**不定义**。对 x ∈ ℝ̄,约定（并设这些运算可交换）:

**加法:**
- x + ∞ := +∞   （只要 x > −∞，即 x 是实数或 +∞）
- x − ∞ := −∞   （只要 x < +∞，即 x 是实数或 −∞）

特别地 ∞ + ∞ = ∞，−∞ − ∞ = −∞。

**乘法:**
- 对 x > 0：x·(+∞) := +∞，x·(−∞) := −∞；
- 对 x < 0：x·(+∞) := −∞，x·(−∞) := +∞。

特别地 ∞·∞ = ∞，(−∞)·(−∞) = ∞，(−∞)·∞ = −∞。（符号规则与有限数的「正负相乘」完全一致。）

**与实数的除法:** 对 x ∈ ℝ，
- x/(+∞) := 0，x/(−∞) := 0（有限数除以无穷是 0）；
- x/0 := +∞（若 x > 0）或 −∞（若 x < 0）。

## 哪些组合不定义,为什么

下面这些**一律不定义**:

∞ − ∞，  0·(±∞)，  (±∞)/(±∞)，  ±∞/0（指 +∞ 或 −∞ 作分子时另算，下面只说不定的几类），  0⁰，  (±∞)⁰，  以及 0 自己作分母配 0 作分子……

最该理解的是前两个——它们是「不定式」,日后求极限时是核心难点:

**∞ − ∞ 为什么不定义?** 假如硬给它一个值 c。考虑「两个都趋于无穷、但差可以是任意值」的情形:n 与 n 之差趋于 0,n 与 n+5 之差趋于 −5,n 与 2n 之差趋于 −∞……同样是「∞ 减 ∞」的形状,结果却可以是任何数甚至无穷。没有哪个 c 能一致地代表它,所以只能不定义。

**0·(±∞) 为什么不定义?** 同理:一个趋于 0、一个趋于 ∞,乘积可以是任何值——(1/n)·n = 1,(1/n²)·n = 1/n → 0,(1/n)·n² = n → ∞。结果不被两个因子的「趋向」决定,故不定义。

这些「不定式」不是技术上的麻烦,而是分析里真正有内容的地方:后面求极限时,遇到 ∞−∞、0·∞ 这种形状,不能直接代入,必须用别的手段（化简、洛必达等）把它「解开」——它们标记着「极限不能由部分信息直接读出」的情形。

**ℝ̄ 不是域.** 添了 ±∞ 之后,ℝ̄ 失去了域的结构——因为运算不再处处有定义（∞ + (−∞) 无值），域公理（要求加法处处可逆等）无法满足。ℝ̄ 是一个有用的**全序集**,带一部分运算,但**不是**有序域。这一点要记牢:在 ℝ̄ 里不能随意套用域的运算律。

## 回报:每个子集都有上确界

有了 ±∞,完备性公理可以**升级成无条件的形式**——再也不必要求「有上界」。

**约定(无界情形的 sup/inf).** 对 ℝ 的子集 M：
- 若 M 非空但**无上界**,记 sup M := +∞；
- 若 M 非空但**无下界**,记 inf M := −∞；
- 对空集,记 sup ∅ := −∞，inf ∅ := +∞。

（空集的约定初看奇怪:sup ∅ = −∞ 是因为「∅ 的每个上界」这个条件对**任何**实数都空洞地成立——人人都是 ∅ 的上界,故最小上界要取到 ℝ̄ 的最小元 −∞。inf ∅ 对称。）

**命题(ℝ̄ 中 sup/inf 普遍存在).** ℝ 的**每一个**子集 M,都在 ℝ̄ 中有上确界和下确界。

**证明.** 三种情形覆盖一切:M 非空有上界——由[[num_dedekind|完备性公理]],sup M 存在于 ℝ（进而在 ℝ̄）；M 非空无上界——按上面约定 sup M = +∞；M = ∅——按约定 sup M = −∞。下确界对称。∎

这个「无条件版」是后面的便利所在:讨论 sup、inf 时不必再前置「设 M 有界」,直接写 sup M 即可,值落在 ℝ̄ 里。需要时再区分它是有限实数还是 ±∞。

> 仍要当心:把 sup 取到 ℝ̄ 里很方便,但一旦 sup M = +∞,它就**不是实数**,不能拿去做实数的加减乘除。「∞」是一个安放符号,不是可运算的数——这正是上面强调「ℝ̄ 不是域」的实际意义。

## 一道激活练习

(a) 解释为什么 (+∞)/(+∞) 不能自洽地定义。（提示:仿正文 ∞−∞ 的论证——找两组「都趋于 ∞」的量,使它们的比趋于不同的值。比如 n 与 n、n 与 n²、n² 与 n 的比各趋于什么？）

(b) 在 ℝ̄ 中求下列集合的上确界与下确界:
   ① M₁ = { 1 − 1/n : n ∈ ℕˣ }（即 0, 1/2, 2/3, …）；
   ② M₂ = ℤ（全体整数）；
   ③ M₃ = { x ∈ ℝ : x < 5 }。

## 参考解答

(建议先自己写完再看。)

**(a)** 假设给 (+∞)/(+∞) 赋一个值 c。看三组都「趋于 ∞」的量之比:n 除以 n 恒等于 1（趋于 1）；n² 除以 n 等于 n（趋于 +∞）；n 除以 n² 等于 1/n（趋于 0）。同样是「∞ 比 ∞」的形状,比值却可以趋于 1、+∞、0 等任意结果。没有单一的 c 能一致代表,故不定义。（这是又一个「不定式」,与 ∞−∞、0·∞ 同类。）∎

**(b)**
① M₁:这是[[num_estremo_superiore|上确界]]那节算过的集合,sup M₁ = 1（有上界,sup 是实数 1，不属于集合）;inf M₁ = 0（0 = 1 − 1/1 ∈ M₁，是最小元,故 inf = min = 0）。

② M₂ = ℤ:无上界（由阿基米德性质，任何实数之上都有整数）也无下界,故在 ℝ̄ 中 sup ℤ = +∞，inf ℤ = −∞。

③ M₃ = { x < 5 }:有上界（5 是上界，且任何 b < 5 都不是上界——由稠密性 b 与 5 之间有实数落在 M₃ 里），故 sup M₃ = 5（实数，不属于集合）;无下界（x 可任意小）,故 inf M₃ = −∞。∎

回顾:sup 落在 ℝ 里还是落在 ±∞,取决于集合「那一侧」有没有界。无条件地写 sup、inf,正是 ℝ̄ 带来的便利——但读出的值要分清是实数还是无穷符号。

## 数系准备完成,转入分析

到这里,从 ℝ 出发的全部准备就绪了:[[an_valore_assoluto|绝对值]]给了度量距离的尺子,[[num_archimede|阿基米德性质与稠密性]]给了逼近的起点,[[num_radici_n|n 次根]]兑现了开方,扩展数轴 ℝ̄ 给了无穷一个安放之处。回填清单清空,跟随 Amann–Escher 路径的暗坑已全部填平。

下一步正式离开「数系」,进入**分析**主干的核心。第一个概念是「**距离**」的抽象——绝对值 |x−y| 让我们能谈实数间的远近,但「逼近」这件事的本质,其实只用到距离的三条性质（非负且重合才为零、对称、三角不等式）。把这三条提炼成公理,就得到**度量空间**(metric space)：任何配上这种「距离」的集合，都能在其上谈论收敛、连续与极限——无论元素是实数、复数、向量还是函数。这是分析、拓扑、泛函分析共同的舞台。这就是 [[an_spazio_metrico|度量空间]] 的内容,也是我们真正进入极限理论的入口。
