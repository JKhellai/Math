## 一类拆不开也夹不住的数列

到现在,判断收敛的工具有两套:[[an_algebra_limiti|运算法则]](把数列拆成会算的零件)和[[an_confronto|夹逼]](用两个夹板围堵)。但有一类数列,两套都使不上——我们**看得出它在往一个方向走,却既拆不开、也找不到夹板**。

最有名的例子是 (1 + 1/n)ⁿ。展开它,项数随 n 变化,运算法则无从下手;它在缓慢上升,可上升到哪里没有现成的数能当夹板。直觉告诉我们它该收敛(它一直涨、又涨不快),但前面的工具都给不出判断。

这一节的定理填上这个缺口,而填补它的,正是我们费尽周折造 ℝ 时得到的那个性质——**完备性**。这是完备性第一次在极限理论里正面出场:它让我们能断定一个数列收敛,**而无需事先知道极限是多少**。

## 单调数列

**定义.** 实数列 (xₙ) 称**递增**(increasing)，若 xₙ ≤ xₙ₊₁ 对一切 n;称**递减**(decreasing)，若 xₙ ≥ xₙ₊₁ 对一切 n。两者统称**单调**(monotone)。

（"递增"这里指"不减",允许相等;严格不等的情形称"严格递增"。）单调是个很强的约束:数列只能一直往一个方向走,不能回头。正是这个约束,让"有界"这个原本不充分的条件变得充分。

## 主定理

回忆[[an_convergenza|收敛蕴含有界]]:有界是收敛的**必要**条件,但不充分——((−1)ⁿ) 有界却发散。问题出在它来回振荡。如果禁止振荡(即要求单调),有界就**变充分**了。

**定理(单调收敛).** ℝ 中递增且有上界的数列 (xₙ) 必收敛,且

lim xₙ = sup{ xₙ : n ∈ ℕ }。

(对称地,递减且有下界的数列收敛到它的下确界。)

**证明.** 设 (xₙ) 递增有上界。其值域 X := { xₙ : n ∈ ℕ } 非空且有上界,由 ℝ 的[[num_dedekind|完备性公理]],上确界

x := sup X

存在。往证 xₙ → x。

给定 ε > 0。由[[num_estremo_superiore|上确界的 ε-刻画]],x − ε 不是 X 的上界,故存在某项 x_N 满足 x_N > x − ε。而 (xₙ) 递增,所以对一切 n ≥ N,

xₙ ≥ x_N > x − ε。

另一方面,x 是上界,故 xₙ ≤ x < x + ε 对一切 n。两边合起来:

x − ε < xₙ ≤ x < x + ε，  n ≥ N，

即 xₙ ∈ B(x, ε)。故 xₙ → x = sup X。∎

**递减情形**由「翻号」化归:若 (xₙ) 递减有下界,则 (−xₙ) 递增有上界,由已证部分 −xₙ → sup{−xₙ} = −inf{xₙ},再由[[an_algebra_limiti|数乘法则]](乘 −1)得 xₙ → inf{xₙ}。∎

## 这个定理为什么重要

它的分量在证明的**第一步**:`x := sup X` 凭完备性**直接存在**,我们还没算出它是多少,就已经拿它当极限的候选。这是单调收敛定理独一无二的能力——

**它判定收敛,而不要求你先知道极限。** 运算法则要你把极限拼出来,夹逼要你找到收敛到已知值的夹板,两者都得对"极限是什么"有所掌握。单调收敛不需要:只要确认"一直涨"和"有顶",收敛就成立,极限自动是那个上确界(哪怕你暂时算不出它)。

把它和[[an_convergenza|收敛⟹有界]]并排,正好补成一对:那条说"收敛必有界"(有界是必要的),这条说"单调时有界就够"(对单调数列,有界是充分的)。中间隔着的"振荡"被单调性禁掉了,必要条件就升格成了充分条件。而支撑这次升格的,是完备性——在有理数 ℚ 里,单调有界数列**可能不收敛**(比如逼近 √2 的那串递增有理数,在 ℚ 里没有极限),正是 ℝ 补上的洞,才让这条定理成立。**单调收敛定理,本质上是完备性穿上极限外衣的样子。**

## 第一个收获：几何数列

用它立刻拿下一个基本极限。

**命题.** 设 a ∈ ℝ,|a| < 1。则 aⁿ → 0。

**证明.** 先设 0 ≤ a < 1。数列 (aⁿ) 递减(因 0 ≤ a < 1,每乘一次 a 变小:aⁿ⁺¹ = a·aⁿ ≤ aⁿ）且有下界 0(aⁿ ≥ 0)。由单调收敛定理,它收敛,设 aⁿ → L,且 L = inf{aⁿ} ≥ 0。

求 L 用一个漂亮的技巧:子列 (aⁿ⁺¹) 是 (aⁿ) 的[[an_sottosuccessioni|子列]],也收敛到同一极限 L。但 aⁿ⁺¹ = a·aⁿ,由[[an_algebra_limiti|积法则]]它收敛到 a·L。极限唯一,故

L = a·L，  即 (1 − a)·L = 0。

因 a < 1,1 − a ≠ 0,所以 L = 0。

一般的 |a| < 1:由 |aⁿ| = |a|ⁿ → 0(刚证,用在 |a| ∈ [0,1) 上),再由「[[an_convergenza|绝对值趋零则本身趋零]]」得 aⁿ → 0。∎

这个"极限满足 L = aL、故 L = 0"的手法值得记住:**对递推关系两边取极限,得到一个关于极限本身的方程,解出极限**。它在处理递归定义的数列时是标准动作——下面的练习就用它。

## 一道激活练习

设数列 (xₙ) 由递归定义:x₁ := 1,x_{n+1} := √(2 + xₙ)（每一项是"2 加上一项"再开方）。

(a) 证明 (xₙ) 递增且以 2 为上界(提示:对"xₙ < 2"和"xₙ < x_{n+1}"分别用归纳;开方[[num_radici_n|保序]])。
(b) 由单调收敛定理,(xₙ) 收敛。设极限为 L,对递推式两边取极限,求出 L。

## 参考解答

(建议先自己写完再看。)

**(a) 有上界(xₙ < 2,归纳).** 奠基 x₁ = 1 < 2。归纳步:设 xₙ < 2,则 x_{n+1} = √(2 + xₙ) < √(2 + 2) = √4 = 2(开方保序)。故对一切 n,xₙ < 2。

**递增(xₙ < x_{n+1},归纳).** 即证 xₙ < √(2 + xₙ),两边平方(都正)等价于 xₙ² < 2 + xₙ,即 xₙ² − xₙ − 2 < 0,即 (xₙ − 2)(xₙ + 1) < 0。因 0 < xₙ < 2(由上一段),xₙ − 2 < 0 而 xₙ + 1 > 0,乘积为负,成立。故 xₙ < x_{n+1} 对一切 n,数列递增。

（递增 + 有上界,由单调收敛定理,(xₙ) 收敛。）

**(b) 求极限.** 设 xₙ → L。则子列 x_{n+1} 也 → L。对递推式 x_{n+1} = √(2 + xₙ) 两边取极限:左边 → L;右边,2 + xₙ → 2 + L(和法则),开方 → √(2 + L)（根号连续,直观接受,以后严格化）。故

L = √(2 + L)。

两边平方:L² = 2 + L,即 L² − L − 2 = 0,(L − 2)(L + 1) = 0,得 L = 2 或 L = −1。因所有 xₙ > 0,极限 L ≥ 0,排除 −1。故 **L = 2**。∎

回顾:这道题是单调收敛定理的标准用法,分两步。**第一步用定理保证极限存在**(单调 + 有界)——这一步至关重要,因为第二步"对递推式取极限求 L"只有在**已知极限存在**时才合法(否则 L = √(2+L) 这个方程是对一个不存在的对象列的,可能解出假答案)。先证存在、再求值,顺序不能颠倒——这正是单调收敛定理不可替代的地方:它提供了"存在性"这块别的工具给不了的基石。

## 往前看一步

单调收敛定理给了我们一把判定收敛的新钥匙,而它最著名的用武之地,是定义一个数学中无处不在的常数。数列 (1 + 1/n)ⁿ ——本节开头那个拆不开也夹不住的例子——可以证明它**递增且有上界**(上界是 3),于是由单调收敛定理它收敛。它的极限就是**欧拉数 e**,自然对数的底,满足 2 < e ≤ 3。e 不是某个简单运算的结果,它**本质上是一个极限**——没有完备性、没有单调收敛定理,就无法保证这个极限存在,也就无法定义 e。这就是 [[an_numero_e|欧拉数 e]] 的内容:用本节的定理,给这个基本常数一个严格的出生证明。
