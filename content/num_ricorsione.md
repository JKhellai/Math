## 还一笔账

[[num_aritmetica|算术]]那一节,我们用递归定理定义了加法与乘法,但当时只证了它的**唯一性**,存在性是「暂且承认」的。当时也说明了为什么不能用归纳法搪塞过去:归纳法只能证明「已经存在的对象」具有某种性质,它**变不出一个集合来**。而一个函数 f : ℕ → X 是一个实实在在的集合(它的全体有序对);要确认这个集合**存在**,必须真的把它构造出来。这一节就动手做这件事——补上地基里这唯一一处「正文承认、尚未兑现」的承重证明。

先把要证的命题完整重述。

**递归定理(recursion theorem).** 设 X 是非空集合,a ∈ X,g : X → X 是一个函数。则**存在唯一**的函数 f : ℕ → X,满足

- (i) f(0) = a;
- (ii) f(S(n)) = g(f(n)),对一切 n ∈ ℕ。

唯一性已在算术那节证过(对 P(n) :≡「f(n) = f′(n)」归纳)。本节只补**存在性**。

## 难点在哪里

直觉上,f 的值是「一层层算出来的」:f(0) = a,f(1) = g(a),f(2) = g(g(a)),……每一项都由前一项唯一确定。困难不在于「算不出某一项」——任何**有限**步都算得出;困难在于,要把这无穷多步的结果,真正收拢成**一个**合法的函数(一个确定的有序对集合)。

A–E 的办法很巧妙:既然无穷步一次拼不出来,就先一段一段地拼。对每个 n,构造一个只定义在 **{0, 1, …, n}** 上的「有限近似」函数 fₙ——它把递归规则执行到第 n 步为止。这些有限函数每个都是合法的(有限步,无收拢问题)。然后证明它们**彼此相容**(在公共定义域上取值一致),最后把它们粘起来,得到定义在整个 ℕ 上的 f。

为叙述方便,记 **⟦n⟧ := {m ∈ ℕ : m ≤ n}**,即 {0, 1, …, n}。

## 第一步:构造有限近似 fₙ

**引理.** 对每个 n ∈ ℕ,存在函数 fₙ : ⟦n⟧ → X,满足

(a) fₙ(0) = a;
(b) fₙ(S(k)) = g(fₙ(k)),对一切满足 S(k) ≤ n 的 k。

**证明(对 n 归纳).**

*奠基 n = 0.* ⟦0⟧ = {0}。定义 f₀ : {0} → X 为 f₀(0) := a。条件 (a) 成立;(b) 空缺(没有 k 满足 S(k) ≤ 0,因为 S(k) 是后继,而 0 不是后继),自动满足。

*归纳步 n → S(n).* 设已有满足 (a)(b) 的 fₙ : ⟦n⟧ → X。⟦S(n)⟧ 比 ⟦n⟧ 多了一个元素 S(n)(由[[num_radice2|离散性]]:m ≤ S(n) 当且仅当 m ≤ n 或 m = S(n))。把 fₙ 向这个新点延拓一步,定义 f_{S(n)} : ⟦S(n)⟧ → X 为

f_{S(n)}(m) := fₙ(m)  若 m ≤ n;  f_{S(n)}(S(n)) := g(fₙ(n))。

这是良定义的:两条子句的定义域 ⟦n⟧ 与 {S(n)} 不相交(S(n) ∉ ⟦n⟧,因 S(n) > n),每个 m ∈ ⟦S(n)⟧ 恰好落入一条。验证 (a)(b):

- (a):f_{S(n)}(0) = fₙ(0) = a(因 0 ≤ n)。
- (b):取 k 使 S(k) ≤ S(n),即 S(k) = S(n) 或 S(k) ≤ n(离散性)。
  - 若 S(k) ≤ n:则 k < S(k) ≤ n,两个点 k、S(k) 都 ≤ n,于是 f_{S(n)} 在它们上等于 fₙ,由 fₙ 的 (b) 得 f_{S(n)}(S(k)) = fₙ(S(k)) = g(fₙ(k)) = g(f_{S(n)}(k))。
  - 若 S(k) = S(n):由 S 单射,k = n;则 f_{S(n)}(S(n)) := g(fₙ(n)) = g(f_{S(n)}(n))(因 n ≤ n)。

两条都成立。归纳完成,fₙ 对一切 n 存在。∎

## 第二步:相容性

有限近似造好了,但每个 n 给一个 fₙ,彼此是否打架?下面证明它们在公共定义域上完全一致——这正是能把它们粘起来的前提。

**引理(相容性).** 设 m ≤ n。则 fₘ 与 fₙ 在 ⟦m⟧ 上一致:∀j ≤ m, fₘ(j) = fₙ(j)。

**证明.** 固定 m,对「n ≥ m」归纳(即对差值归纳;形式上对命题 Q(n) :≡「n ≥ m ⟹ ∀j≤m, fₘ(j)=fₙ(j)」归纳,但只需看 n 从 m 起往上走)。

奠基 n = m:fₘ 与 fₘ 当然一致。

归纳步 n → S(n)(设 n ≥ m):由归纳假设,fₘ 与 fₙ 在 ⟦m⟧ 上一致。而上一步构造里,f_{S(n)} 在 ⟦n⟧ 上**就等于** fₙ(延拓只在新点 S(n) 处添值,旧点原样保留)。由于 ⟦m⟧ ⊆ ⟦n⟧(因 m ≤ n),在 ⟦m⟧ 上 f_{S(n)} = fₙ = fₘ。∎

相容性的实质很简单:fₙ 是一步步**向右延拓**得来的,延拓从不修改已有的值,所以「越长的近似」只是「越短的近似」的延续。

## 第三步:粘合

现在定义整体函数。对每个 n ∈ ℕ,令

**f(n) := fₙ(n)**

(用第 n 个近似在它自己最右端的值)。这无歧义——fₙ(n) 是确定的。验证 f 满足递归定理的两条:

**(i)** f(0) = f₀(0) = a。

**(ii)** 任取 n,要证 f(S(n)) = g(f(n))。按定义 f(S(n)) = f_{S(n)}(S(n))。由第一步构造的子句,f_{S(n)}(S(n)) = g(fₙ(n))。而由相容性,fₙ(n) = f_{S(n)}(n)……更直接地,fₙ(n) 就是 f(n) 的定义。于是

f(S(n)) = f_{S(n)}(S(n)) = g(fₙ(n)) = g(f(n))。

两条齐备。存在性证毕。∎

至此递归定理完整成立——加法、乘法,以及此后一切「一层层定义出来」的对象(阶乘、幂、求和符号 Σ、序列……),终于都站在了证明过的地基上,而不再是承认。

## 推广与一则应用

A–E 的原始表述比上面更一般:第 n+1 步的值可以依赖**前面所有**的值 f(0), …, f(n),而不只是前一项——即 f(S(n)) = Vₙ₊₁(f(0), …, f(n)),其中 Vₙ₊₁ 是给定的函数。证明手法完全一样(有限近似 + 相容 + 粘合),只是记号更繁。我们用到的简单形式(只依赖前一项)是它的特例,已足够支撑数系构造。

> **一则应用:求和符号 Σ 的严格定义。** 设 X 上有结合运算（比如 ℤ 的加法），(xₖ) 是 X 中一列元素。我们想定义 ∑_{k=0}^{n} xₖ = x₀ + x₁ + ⋯ + xₙ——但右边那三个点同样需要递归来消除。取 g 为「加上 xₙ₊₁」这一步,递归定理给出唯一的 f 满足 f(0) = x₀、f(S(n)) = f(n) + x_{S(n)};定义 ∑_{k=0}^{n} xₖ := f(n)。于是得到递归规则
>
> ∑_{k=0}^{0} xₖ = x₀，  ∑_{k=0}^{S(n)} xₖ = ( ∑_{k=0}^{n} xₖ ) + x_{S(n)}。
>
> 「连加」从此有了严格定义,而不靠省略号。乘积符号 ∏、阶乘 n! 同理。

## 顺带:强归纳法

递归与良序、归纳本是一体三面。这里把[[num_radice2|那一节]]提过一句的**强归纳法**正式立起——它在证明里允许使用「**所有**更小情形」的假设,而不止前一个。

**命题(强归纳法 strong induction).** 设 P(n) 是关于自然数的谓词。若对每个 n ∈ ℕ:「P(k) 对所有 k < n 成立」蕴含 P(n),则 P(n) 对一切 n ∈ ℕ 成立。

(注意这条表述里**奠基藏在归纳步内**:取 n = 0 时,「所有 k < 0」是空的,前提自动成立,所以必须直接推出 P(0)。)

**证明(借良序).** 反设 P 不恒真,令 M := {n ∈ ℕ : P(n) 假}。M 非空,由[[num_radice2|良序原理]]有最小元 m。最小性意味着:所有 k < m 都不在 M,即 P(k) 对一切 k < m 成立。由命题的前提,P(m) 成立——但 m ∈ M 说 P(m) 假,矛盾。故 M = ∅。∎

强归纳与普通归纳逻辑等价(都等价于良序),但在「第 n 步要回溯到好几步之前」的证明里更顺手——例如证「每个大于 1 的自然数都有素因子分解」,就要用到比 n−1 更早的情形。日后用到时直接引用。

## 一道激活练习

用递归定理严格定义**幂** aⁿ(设 X 是含幺的乘法结构,a ∈ X),使其满足 a⁰ = 1 且 a^{S(n)} = aⁿ · a;然后用归纳证明指数律 a^{m+n} = aᵐ · aⁿ。

(提示:定义部分,把递归定理里的 g 取成「乘以 a」。指数律部分,固定 m 对 n 归纳——奠基用 a⁰ = 1 与 m + 0 = m;归纳步把 a^{m+S(n)} 中的 S 往外搬,用 A2 与幂的递归式。)

## 参考解答

(建议先自己写完再看。)

**定义 aⁿ.** 在递归定理中取该结构本身为 X、起点 a₀ := 1（幺元）、步进函数 g(x) := x · a。定理给出唯一的 f : ℕ → X 满足 f(0) = 1、f(S(n)) = g(f(n)) = f(n) · a。记 aⁿ := f(n),即得 a⁰ = 1 与 a^{S(n)} = aⁿ · a。

**指数律 a^{m+n} = aᵐ · aⁿ.** 固定 m,对 n 归纳。

奠基 n = 0:左 = a^{m+0} = aᵐ(因 m + 0 = m);右 = aᵐ · a⁰ = aᵐ · 1 = aᵐ。相等。

归纳步:设 a^{m+n} = aᵐ · aⁿ。则

a^{m+S(n)} = a^{S(m+n)}  （因 m + S(n) = S(m+n)，即 A2）
          = a^{m+n} · a   （幂的递归式）
          = (aᵐ · aⁿ) · a  （归纳假设）
          = aᵐ · (aⁿ · a)  （结合律）
          = aᵐ · a^{S(n)}。 （幂的递归式）

由归纳原理,指数律对一切 n 成立;m 任意,得证。∎

回顾:这道题是「定义靠递归、性质靠归纳」这一套配合的缩影——先用递归定理把对象**造出来**（确保存在），再用归纳法**证明它的性质**。整个数系构造,本质上就是这套配合的反复运用。

## 往前看一步

地基至此真正闭环:逻辑、集合、函数、关系是语言;ℕ→ℤ→ℚ→ℝ 是数系骨架;而支撑「一层层定义」的递归定理,现在也补全了存在性,没有任何悬空的承重点。脚下的实数轴是完备的有序域,每一块砖都经过证明。

下一阶段离开「构造数系」,进入**分析**——研究这条实数轴(以及更一般的空间)上的「无限逼近」。第一个、也是最核心的概念是**极限**:一列数 x₀, x₁, x₂, … 无限靠近某个值意味着什么?这个「靠近」要用「距离」来精确表述,而距离本身又能被公理化成一个独立的结构。这就是分析主干的起点。
