## 补上「角度」

[[an_norma|范数]]给了向量「长度」,赋范空间因此成为[[an_spazio_metrico|度量空间]]。但范数只管长度,**还没有角度**——我们仍不能说「两个向量垂直」「它们夹角多少」。而几何里的垂直、投影、勾股定理,全离不开角度。补上角度的,是一个比范数更强的结构:**内积**。

这一节是分析主干一条长线的终点:从[[an_spazio_metrico|度量空间]]那节起,我们就一直把欧氏 ℝⁿ「留待内积那节」。原因现在清楚了——ℝⁿ 的欧氏距离 ‖x−y‖ = √(Σ(xᵢ−yᵢ)²) 要成为度量,核心难点是它的范数满足**三角不等式**,而这要靠内积的一条关键不等式(Cauchy–Schwarz)才能证。本节就闭合这条链:**内积 → 范数 → 度量**,欧氏 ℝⁿ 终于落地。

为清晰,主要讲**实数情形** 𝕂 = ℝ(此时内积对称、无复共轭);复数情形 𝕂 = ℂ 只需在对称性里加一个共轭,要点完全一样,末尾点明。

## 定义

设 E 是 𝕂 上的[[alg_spazio_vettoriale|向量空间]]。函数 ⟨·,·⟩ : E × E → 𝕂 称 E 上的一个**内积**(inner product / scalar product)，若满足(实情形,x, y, z ∈ E,λ, μ ∈ ℝ):

- **(SP1)** 对称:⟨x, y⟩ = ⟨y, x⟩；
- **(SP2)** 对第一个变元线性:⟨λx + μy, z⟩ = λ⟨x, z⟩ + μ⟨y, z⟩；
- **(SP3)** 正定:⟨x, x⟩ ≥ 0,且 ⟨x, x⟩ = 0 ⟺ x = 0。

配了内积的向量空间 (E, ⟨·,·⟩) 称**内积空间**(inner product space)。

(由 (SP1) 对称 + (SP2),内积对**第二个**变元也线性——所以实内积是「双线性 + 对称 + 正定」。复情形里 (SP1) 改为 ⟨x,y⟩ = 共轭⟨y,x⟩,于是第二变元是「共轭线性」,称「半双线性 Hermite 型」;ℝ 上共轭是恒等,退化回双线性。)

**最重要的例子:𝕂ⁿ 上的欧氏内积(点积).** 对 x = (x₁,…,xₙ), y = (y₁,…,yₙ),定义

⟨x, y⟩ := Σ_{j=1}^{n} xⱼyⱼ = x₁y₁ + ⋯ + xₙyₙ。

（实情形;复情形第二项取共轭 xⱼ·共轭yⱼ。）逐条验证它满足 (SP1)–(SP3)（对称显然;线性来自分配律;正定因 ⟨x,x⟩ = Σxⱼ² 是平方和,非负且为零当且仅当各 xⱼ=0）——这就是中学点积的严格版,称 𝕂ⁿ 上的**欧氏内积**。

## Cauchy–Schwarz 不等式

内积空间最有用的定理,也是闭合「内积→范数」那一环的钥匙。

**定理(Cauchy–Schwarz).** 设 (E, ⟨·,·⟩) 是内积空间。则对一切 x, y ∈ E:

|⟨x, y⟩|² ≤ ⟨x, x⟩·⟨y, y⟩，

且等号成立 ⟺ x 与 y [[alg_span_indipendenza|线性相关]]。

**证明（实情形）.** y = 0 时两边都是 0,成立。设 y ≠ 0。**核心技巧:利用正定性 ⟨v, v⟩ ≥ 0,然后挑一个最优的 α 把不等式榨到最紧。** 对任意 α ∈ ℝ,由 (SP3):

0 ≤ ⟨x − αy, x − αy⟩ = ⟨x,x⟩ − 2α⟨x,y⟩ + α²⟨y,y⟩。

(展开用了双线性与对称。)右边是关于 α 的二次式,对**一切** α 非负。要它最紧,取使右边最小的 α——配方或求导知最小点在 α = ⟨x,y⟩/⟨y,y⟩。代入:

0 ≤ ⟨x,x⟩ − 2·(⟨x,y⟩/⟨y,y⟩)·⟨x,y⟩ + (⟨x,y⟩/⟨y,y⟩)²·⟨y,y⟩ = ⟨x,x⟩ − ⟨x,y⟩²/⟨y,y⟩。

两边乘 ⟨y,y⟩ > 0,移项:⟨x,y⟩² ≤ ⟨x,x⟩⟨y,y⟩,即所证。**等号**当且仅当上面第一行的 ⟨x−αy, x−αy⟩ = 0,由 (SP3) 即 x − αy = 0,即 x = αy——x, y 线性相关。∎

这个「考虑 ⟨x−αy, x−αy⟩ ≥ 0、再选最优 α」的手法极其典型——把一个不等式问题,转化成「一个二次式恒非负」,再用判别式/配方榨出结论。

**写成长度的形式**(用下面就要定义的 ‖x‖ = √⟨x,x⟩),Cauchy–Schwarz 是:

|⟨x, y⟩| ≤ ‖x‖·‖y‖。

在 ℝⁿ 上展开,这就是经典的 **|Σxⱼyⱼ| ≤ √(Σxⱼ²)·√(Σyⱼ²)**——一个纯粹关于实数的、非平凡的不等式,却由内积的三条公理一举证得。

## 内积诱导范数：链条闭合

现在用内积定义长度,并证明它真是范数——三角不等式那一步,正是 Cauchy–Schwarz 的用武之地。

**定理.** 设 (E, ⟨·,·⟩) 是内积空间。则

‖x‖ := √⟨x, x⟩

是 E 上的一个[[an_norma|范数]]（称内积**诱导的范数**）。

**证明.** 根号有意义,因 (SP3) 保证 ⟨x,x⟩ ≥ 0。验[[an_norma|范数三公理]]:
- **(N1)** ‖x‖ = 0 ⟺ ⟨x,x⟩ = 0 ⟺ x = 0（由 (SP3)）。✓
- **(N2)** ‖λx‖ = √⟨λx,λx⟩ = √(λ²⟨x,x⟩) = |λ|√⟨x,x⟩ = |λ|·‖x‖（双线性提出 λ²，开方得 |λ|）。✓
- **(N3) 三角不等式**——这里用 Cauchy–Schwarz:

  ‖x + y‖² = ⟨x+y, x+y⟩ = ⟨x,x⟩ + 2⟨x,y⟩ + ⟨y,y⟩ = ‖x‖² + 2⟨x,y⟩ + ‖y‖²

  ≤ ‖x‖² + 2|⟨x,y⟩| + ‖y‖² ≤ ‖x‖² + 2‖x‖‖y‖ + ‖y‖²（末步用 Cauchy–Schwarz |⟨x,y⟩| ≤ ‖x‖‖y‖）

  = (‖x‖ + ‖y‖)²。

  两边开方:‖x + y‖ ≤ ‖x‖ + ‖y‖。✓

三条齐备,‖·‖ 是范数。∎

**链条至此闭合:内积 →（√⟨x,x⟩）→ 范数 →（‖x−y‖）→ 度量。** 每个内积空间自动是赋范空间,从而自动是[[an_spazio_metrico|度量空间]]——收敛、Cauchy、完备的全套理论一并继承。而三角不等式这块「拦路石」,由 Cauchy–Schwarz 搬开。

## 欧氏空间 ℝⁿ 落地

把上面用在最重要的例子上。

**定义(欧氏空间).** 𝕂ⁿ 配上欧氏内积 ⟨x,y⟩ = Σxⱼyⱼ,及其诱导范数

‖x‖ := √⟨x,x⟩ = √(Σ_{j=1}^{n} xⱼ²)，

称 **n 维欧氏空间**(Euclidean space)。‖x‖ 称**欧氏范数**,它正是「勾股定理给出的长度」——各坐标平方和再开方。诱导的度量

d(x, y) = ‖x − y‖ = √(Σ_{j=1}^{n} (xⱼ − yⱼ)²)

就是 ℝⁿ 上的**欧氏距离**——两点间的直线距离。

这就是分析主干一直缺的那块拼图:**ℝⁿ 现在是一个货真价实的[[an_spazio_metrico|度量空间]]**,其上[[an_convergenza|收敛]]、[[an_cauchy|完备性]]、[[an_bolzano_weierstrass|Bolzano–Weierstrass]] 全部适用(且可证 ℝⁿ 完备,是有限维[[an_cauchy|Banach 空间]])。多元微积分——多元函数的极限、连续、偏导、重积分——就在这个空间上展开。

## 角度与正交

内积比范数多给的,正是**角度**。由 Cauchy–Schwarz,对非零 x, y 有 −1 ≤ ⟨x,y⟩/(‖x‖‖y‖) ≤ 1,所以可以**定义**两向量的夹角 θ ∈ [0, π] 为

cos θ := ⟨x, y⟩ / (‖x‖·‖y‖)。

(Cauchy–Schwarz 保证了右边落在 [−1,1] 内,cos⁻¹ 才有意义——这是「角度能被定义」的前提。)特别地:

**定义(正交).** x 与 y **正交**(orthogonal)，记 x ⊥ y，若 ⟨x, y⟩ = 0（夹角 θ = π/2，即垂直）。

正交是欧氏几何的核心关系。一个立竿见影的收获是**勾股定理**:若 x ⊥ y,则

‖x + y‖² = ‖x‖² + 2⟨x,y⟩ + ‖y‖² = ‖x‖² + ‖y‖²

（中间项 ⟨x,y⟩ = 0 消失）——直角三角形斜边平方等于两直角边平方和。中学的勾股定理,在这里成了内积语言下的一行计算。正交、投影、正交基这些概念,是线性代数后续(谱定理)与分析(傅里叶级数)的基石,这里先立住「正交 = 内积为零」这个定义。

## 一道激活练习

(a) 在 ℝ³ 中设 x = (1, 2, 2),y = (2, −1, 2)。计算 ⟨x,y⟩、‖x‖、‖y‖,判断 x 与 y 是否正交,并验证 Cauchy–Schwarz |⟨x,y⟩| ≤ ‖x‖‖y‖。

(b) 证明**平行四边形恒等式**:在任意内积空间中,

‖x + y‖² + ‖x − y‖² = 2‖x‖² + 2‖y‖²。

(提示:把两个范数平方都用内积展开 ⟨x±y, x±y⟩,相加。)

(c) 用 Cauchy–Schwarz 证明:对任意实数 a₁,…,aₙ,有 (a₁ + ⋯ + aₙ)² ≤ n(a₁² + ⋯ + aₙ²)。(提示:在 ℝⁿ 中取 x = (a₁,…,aₙ)、y = (1,1,…,1),套用 |⟨x,y⟩| ≤ ‖x‖‖y‖ 并平方。)

## 参考解答

(建议先自己写完再看。)

**(a)** ⟨x,y⟩ = 1·2 + 2·(−1) + 2·2 = 2 − 2 + 4 = **4**。‖x‖ = √(1+4+4) = √9 = **3**。‖y‖ = √(4+1+4) = √9 = **3**。因 ⟨x,y⟩ = 4 ≠ 0,**x 与 y 不正交**。Cauchy–Schwarz:|⟨x,y⟩| = 4,‖x‖‖y‖ = 9,确有 4 ≤ 9。✓

**(b)** 展开两项:

‖x+y‖² = ⟨x+y,x+y⟩ = ‖x‖² + 2⟨x,y⟩ + ‖y‖²，
‖x−y‖² = ⟨x−y,x−y⟩ = ‖x‖² − 2⟨x,y⟩ + ‖y‖²。

相加,交叉项 ±2⟨x,y⟩ 抵消:‖x+y‖² + ‖x−y‖² = 2‖x‖² + 2‖y‖²。∎（几何意义:平行四边形两条对角线的平方和 = 四条边的平方和。这个恒等式还能反过来刻画「哪些范数来自内积」——满足它的范数才是 Hilbert 范数,是泛函分析的一个判据。）

**(c)** 在 ℝⁿ 取 x = (a₁,…,aₙ)、y = (1,…,1)。则 ⟨x,y⟩ = Σaⱼ·1 = a₁+⋯+aₙ;‖x‖ = √(Σaⱼ²);‖y‖ = √(Σ1²) = √n。由 Cauchy–Schwarz |⟨x,y⟩| ≤ ‖x‖‖y‖,两边平方:

(a₁+⋯+aₙ)² ≤ (Σaⱼ²)·n = n(a₁²+⋯+aₙ²)。∎

回顾:(c) 是 Cauchy–Schwarz 「造不等式」的典型用法——**把目标不等式的两边,凑成两个向量的内积与范数,再套 |⟨x,y⟩|≤‖x‖‖y‖**。取 y = (1,…,1) 是常用技巧,能把「和的平方」与「平方的和」联系起来(这也证明了算术-平方关系)。Cauchy–Schwarz 是分析中产生不等式的一台「母机」,以后(积分不等式、概率里的相关系数)会反复见到它的身影。

## 多元分析前置就位

到这里,分析主干一直推迟的欧氏 ℝⁿ 彻底落地:它是配了欧氏内积的内积空间,诱导出欧氏范数与欧氏距离,成为一个完整的[[an_spazio_metrico|度量空间]](且完备)。**多元分析的舞台就此搭好。**

回望这条线的完整逻辑:[[alg_spazio_vettoriale|向量空间]]给了「能加能伸缩」的代数骨架,[[alg_base_dimensione|基与维数]]给了「坐标」与「大小」,[[an_norma|范数]]装上「长度」、把空间变成度量空间,本节的[[an_prodotto_interno|内积]]再装上「角度」、并用 Cauchy–Schwarz 落实欧氏 ℝⁿ。代数与分析两条主干,在欧氏空间这里交汇——这正是从一元分析迈向多元分析的门槛。门槛跨过,接下来就是 ℝⁿ 上的函数:多元函数的极限与连续、偏导数与全微分、多重积分——以及它们与你那条物理线真正汇合的地方。
